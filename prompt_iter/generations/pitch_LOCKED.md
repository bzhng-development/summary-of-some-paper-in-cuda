# Scaling LLM Test-Time Compute Optimally can be More Effective than Scaling Model Parameters

A smaller language model can beat one 14× its size if it invests extra computation cleverly at test time. By adapting its inference strategy to the prompt’s difficulty, it squeezes out over 4× more efficiency than standard best-of-N selection—but only on problems where the model already has some clue, not impossibly hard ones.
