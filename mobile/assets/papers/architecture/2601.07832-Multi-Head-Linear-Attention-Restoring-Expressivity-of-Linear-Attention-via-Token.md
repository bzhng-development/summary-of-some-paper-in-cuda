# Multi-Head Linear Attention: Restoring Expressivity of Linear Attention via Token-Level Multi-Head

**ArXiv:** [2601.07832](https://arxiv.org/abs/2601.07832)

## 🎯 Pitch

Linear attention collapses all queries into a single global memory, capping representation rank and forcing uniform attention weights, yet MHLA shows we can restore full softmax-level expressivity simply by partitioning tokens into multiple spatial heads—achieving a 41% boost on video generation and matching DiT-XL quality at 2.1× speed without any extra modules.

---

## 1. Executive Summary

This paper analyzes why linear attention degrades in expressivity relative to softmax attention and proposes **Multi-Head Linear Attention (MHLA)**, a mechanism that restores query-conditioned selectivity by partitioning the token sequence into non-overlapping blocks—"heads" along the spatial dimension—and computing local key–value summaries that are recombined per query block via a learned coefficient matrix. The core failure mode is identified as **global context collapse**, where a single shared d×d KV summary bottlenecks representational capacity—quantified through both rank deficiency and elevated attention entropy—as sequence length grows. Across image classification (DeiT on ImageNet-1K), image generation (DiT and SANA), natural language processing (0.3B model on FineWeb-Edu), and video generation (Wan2.1-1.3B), MHLA—requiring no auxiliary modules like depthwise convolutions—achieves gains of 3.6% on ImageNet, 12.6% on image generation FID, 6.3% on NLP benchmarks, and 41% on video generation while maintaining O(N) complexity, matching or exceeding softmax attention performance with up to 2.1× inference speedup in long-sequence settings, and establishing that token-level diversity can be restored within linear attention without auxiliary modules only when query-conditioned block mixing replaces global summary reuse.

## 2. Context and Motivation

### The Core Problem: Quadratic Attention Is Efficiently Infeasible at Scale

The Transformer architecture has become the dominant model across virtually all domains of machine learning—natural language processing, computer vision, and generative modeling—because of a single mechanism: **self-attention**. Given a sequence of $N$ tokens with dimension $d$, self-attention computes pairwise similarity scores between every query and every key, yielding an $N \times N$ attention matrix that governs how each token aggregates information from every other token. This pairwise computation is precisely what gives Transformers their expressive power: each query $q_i$ produces its own distinct distribution over all $N$ keys, enabling the model to selectively attend to the most relevant tokens for that specific query. In the standard formulation (Vaswani et al., 2017), the output for token $i$ is:

$$Y_i = \frac{\sum_{j=1}^N \exp(q_i^\top k_j / \sqrt{d}) \cdot v_j}{\sum_{m=1}^N \exp(q_i^\top k_m / \sqrt{d})}$$

Computing this requires evaluating $N^2$ similarity scores and normalizing per query, giving **$O(N^2 d)$ time complexity** and **$O(N^2)$ memory complexity** for the attention matrix alone.

This quadratic scaling is not a minor inconvenience—it is a **fundamental bottleneck** that determines what tasks are practically feasible. In video generation, for example, a single 81-frame video at 480×800 resolution produces approximately 31,500 tokens (Section 5.3). Computing full self-attention over such sequences is prohibitively slow even on modern hardware like the NVIDIA H100. In high-resolution image generation with diffusion transformers, doubling the resolution quadruples the sequence length, making the attention cost the dominant factor in both training and inference. For autoregressive language models processing long documents, the quadratic cost compounds across layers and tokens, limiting context windows to a few thousand tokens without heroic engineering efforts.

The practical consequence is that **model architectures that rely on full self-attention cannot scale gracefully to long sequences**. This limitation has motivated an enormous body of research into efficient attention mechanisms, but solving it requires navigating a difficult tradeoff: reducing complexity while preserving the expressivity that makes attention useful in the first place.

### Why Linear Attention Matters — And Where It Collapses

Linear attention (Katharopoulos et al., 2020; Choromanski et al., 2021) offers the most mathematically direct path to $O(N)$ complexity. The key insight is to replace the exponential softmax kernel with a **positive feature map** $\phi(\cdot)$ such that:

$$\text{Sim}(q_i, k_j) = \exp(q_i^\top k_j) \approx \phi(q_i)^\top \phi(k_j)$$

This factorization allows a dramatic restructuring of the computation. Rather than computing all pairwise similarities, linear attention precomputes a **global key–value summary**:

$$S = \sum_{j=1}^N \phi(k_j)v_j^\top \quad \in \mathbb{R}^{d \times d}$$
$$z = \sum_{m=1}^N \phi(k_m) \quad \in \mathbb{R}^d$$

The output for any query then becomes two simple operations:

$$Y_i = \frac{\phi(q_i)^\top S}{\phi(q_i)^\top z}$$

This achieves **$O(N d^2)$ complexity**—linear in sequence length—because the expensive summation over $N$ tokens is done once and reused for all queries. The memory footprint similarly collapses to $O(d^2)$ for the summary matrix. In theory, this is an elegant solution that enables Transformers to process arbitrarily long sequences.

**However, there is a critical cost to this compression that prior work has underappreciated.** When every query in the sequence draws from the exact same $d \times d$ summary matrix $S$, the model loses what this paper terms **query-conditioned selectivity**—the ability of different queries to retrieve different contexts. Softmax attention gives each query $q_i$ a unique distribution $\{\alpha_{ij}\}_{j=1}^N$ over all tokens; linear attention collapses this to a single fixed summary shared by all queries. As a result, different queries obtain nearly identical context vectors regardless of their specific information needs. A query asking about spatial relationships in an image and a query asking about color distributions will both read from the same compressed representation, with no mechanism to weight different tokens differently.

### Diagnosing the Failure: Global Context Collapse

The paper identifies and names a specific pathology underlying this loss: **global context collapse** (Section 3.2). This is not merely a vague "performance degradation"—it is a precise, quantifiable phenomenon with two measurable signatures.

**Signature 1: Strictly bounded attention rank.** The attention matrix in linear attention can be expressed as $A_{\text{lin}} = \tilde{Q}\tilde{K}^\top$ where $\tilde{Q} = \phi(Q)$ and $\tilde{K} = \phi(K)$. A fundamental linear algebra fact then applies: the rank of this matrix cannot exceed the embedding dimension $d$, regardless of sequence length:

$$\text{rank}(A_{\text{lin}}) \leq \min\{\text{rank}(\tilde{Q}), \text{rank}(\tilde{K})\} \leq d$$

For a sequence of length $N = 1024$ tokens with a typical head dimension $d = 64$, this means the attention matrix can represent at most $d = 64$ independent directions—a mere 6.25% of the $N = 1024$ degrees of freedom that softmax attention can theoretically represent. The paper empirically verifies this in Figure 3b: linear attention-based models consistently show attention score ranks capped at the head dimension (approximately 58), while softmax attention achieves ranks near 255 (close to the sequence length). This is not a factor of 2 or 3 degradation—it is **over 4× less representational diversity**.

**Signature 2: Elevated attention entropy.** When all tokens are compressed into a single shared summary, the relative contribution of any individual token becomes negligible as $N$ grows. The attention weight distribution thus approaches uniformity—every token gets roughly equal weight because the model cannot differentiate them to allocate sharply concentrated attention. The paper quantifies this using the average entropy of attention score distributions (Figure 3a–b). Lower entropy indicates a sparse, focused distribution (information concentrated on a few highly relevant tokens); higher entropy indicates a diffuse, unfocused distribution. Linear attention exhibits substantially higher entropy (5.12) compared to softmax attention (4.13), meaning its attention is more "blurred" across tokens. For tasks where a query needs to concentrate on a small subset of semantically relevant tokens—spatial attention in vision, pronoun resolution in language, frame correspondence in video—this diffuse attention is directly harmful to performance.

**Why this collapse gets worse with sequence length.** This is the crucial subtlety: the problem is not just that linear attention is less expressive at a fixed $N$, but that its **relative expressivity degrades as $N$ increases**. Softmax attention gains representational capacity as sequences grow longer (rank can increase toward $N$, enabling more fine-grained differentiation among more tokens). Linear attention's capacity is **frozen at $d$ regardless of $N$**. At $N = 256$, $d = 64$ gives rank 25% of maximum; at $N = 4096$, it gives rank 1.6% of maximum. This explains why prior linear attention methods may appear competitive on short sequences but catastrophically degrade on the long sequences that motivated their development. The paper's video generation experiments (Section 5.3, Table 5) provide the starkest evidence: at 31,500 tokens, vanilla linear attention effectively **fails to train**, plateauing at a high loss while MHLA converges similarly to FlashAttention.

### Prior Approaches and Why They Fall Short

A significant body of work has attempted to close the expressivity gap between linear and softmax attention. The paper categorizes these attempts and identifies shared limitations that MHLA is designed to transcend.

**Convolutional augmentations.** Methods like Focused Linear Attention (Han et al., 2023) and RALA (Fan et al., 2025) incorporate depthwise separable convolutions into linear attention layers. The rationale is that convolutions capture local spatial context—something linear attention's global summary might miss—thereby injecting additional representational capacity. The paper acknowledges these methods improve accuracy (e.g., Focused LA achieves 74.1% on DeiT-T vs. 69.8% for vanilla linear attention, Table 2a), but identifies a fundamental tension: **these methods defeat the original purpose of linear attention by re-introducing computational overhead**. The added convolutions, while cheaper than full self-attention, impose their own non-trivial cost that does not scale well. Moreover, the paper argues that convolution alone cannot solve the root cause—it provides local feature extraction but does not restore **query-conditioned selectivity** at the attention level. The global context collapse identified in Section 3.2 persists even with convolutional augmentations because all queries still share a single KV summary.

**Gating mechanisms.** Gated Linear Attention (GLA; Yang et al., 2024) and related approaches add learned gating to control information flow. These improve performance but similarly add parameters and computation without addressing the structural rank limitation of the global summary. The paper's experiments (Table 3a) show that while output gating helps small DiT models (DiT-S with CPE+gating achieves FID 59.8), its benefits diminish at larger scales (CPE alone degrades performance on DiT-XL, where plain MHLA matches self-attention without any auxiliary modules). This scaling pattern suggests gating provides a capacity boost at small model sizes but does not resolve the underlying representational bottleneck.

**State-space models (SSMs).** Mamba (Gu and Dao, 2023) and Mamba2 (Dao and Gu, 2024) represent an alternative lineage that has shown strong scalability on long sequences with competitive accuracy. However, the paper notes two specific limitations relevant to the attention expressivity problem: (1) when applied in a unidirectional form to tasks requiring bidirectional attention (common in vision and bidirectional language understanding), SSMs exhibit substantial performance degradation because their recurrent formulation inherently processes tokens sequentially; and (2) these models were developed as alternatives to attention entirely—they do not directly address how to make linear attention work better, which is a distinct and practically important goal given the enormous ecosystem of attention-based architectures (DiT, DeiT, ViT) that would benefit from drop-in linear attention replacements.

**Hybrid attention approaches.** Some methods interleave linear attention layers with occasional self-attention layers to recover expressivity. This "best of both worlds" strategy inevitably retains quadratic complexity at the self-attention layers, capping the scalability gains. For very long sequences where even a few quadratic layers dominate the budget, this approach collapses.

**Sparse attention (orthogonal direction).** Methods like Longformer (Beltagy et al., 2020), BigBird (Zaheer et al., 2020), and Sparse Transformer (Child et al., 2019) reduce complexity by restricting each query to attend only to a subset of keys using hand-designed sparsity patterns (local windows, global tokens, random connections). These achieve sub-quadratic complexity but at the cost of losing full pairwise comparisons—tokens cannot attend to arbitrarily distant tokens unless connected by the sparsity pattern. For tasks requiring truly global context integration, this structural limitation can hurt accuracy. MHLA operates in a different design space: it maintains global context access (every query in a block can incorporate information from every other block via mixing coefficients) while reducing complexity through compression rather than restriction.

**A common thread: addressing symptoms, not the root cause.** The paper's diagnosis positions prior work as treating symptoms rather than the underlying disease. Convolutions, gating, and hybrid architectures all add capacity through auxiliary modules, but they do not address the structural reason linear attention loses expressivity—the fact that all queries are forced to retrieve from the same compressed representation. The paper argues this is why performance gains from these methods tend to be incremental rather than transformative, and why vanilla linear attention remains substantially worse than softmax attention across most benchmarks despite years of augmentation research.

### The Unmet Need: Restore Query-Conditioned Selectivity Within Linear Complexity

This diagnosis motivates a precise design requirement that prior work has not directly addressed: can we engineer a linear attention mechanism that **natively restores query-conditioned selectivity**—the ability of different queries to retrieve different, tailored contexts—without introducing additional computational overhead that defeats the $O(N)$ complexity?

This is a harder requirement than it might appear. Standard linear attention achieves linear complexity precisely because it aggregates all tokens into a shared representation. Breaking that sharing—allowing different queries to access different subsets of tokens—appears to require computing separate summaries per query, which would multiply complexity back toward $O(N^2)$. The challenge is to introduce query-level differentiation while keeping the computational graph amenable to reusing precomputed quantities.

The paper's key architectural insight is that this can be accomplished through **block-level decomposition with learned inter-block mixing**—partitioning tokens into groups, computing independent summaries per group, and then letting each query group learn how to combine these summaries via a coefficient matrix. This preserves the global context (every block can attend to summaries from every other block) while enabling query-conditioned selectivity (different blocks use different coefficients) and maintaining $O(N d^2 + M^2 d^2)$ complexity—linear in $N$ when the block count $M$ satisfies $M^2 \leq N$.

### How This Paper Positions Itself

The paper positions MHLA not as yet another augmentation to linear attention but as a **direct structural fix to the identified root cause**. The distinction matters:

- **Prior work** adds capacity *outside* the attention mechanism (convolutions, gating, hybrid layers) to compensate for linear attention's expressivity loss.
- **MHLA** modifies the attention mechanism *itself* to natively provide richer representations, making auxiliaries unnecessary at sufficient scale.

This is evidenced by the paper's ablation results (Table 3a): on DiT-XL/2, plain MHLA without any CPE or gating achieves FID 20.32, nearly matching self-attention's 19.47 and dramatically outperforming linear attention's 28.63. Adding CPE to DiT-XL *degrades* performance to 22.79, demonstrating that MHLA's internal capacity is sufficient and that external modules can interfere when the base mechanism is already expressive. Compare this to DiT-S/2, where the model is capacity-limited: MHLA alone achieves 76.4 FID, and adding CPE+gating helps (59.8 FID). At large scales, MHLA's structural expressivity is self-sufficient.

The paper also positions itself against both the linear attention literature and the SSM literature simultaneously, claiming that MHLA achieves what neither alone can: the expressivity of full softmax attention (demonstrated by matching DiT-XL/2 FID) with the $O(N)$ complexity of linear attention (demonstrated by the 2.1× speedup over FlashAttention in video generation, Table 5). This "expressivity without sacrifice" positioning is ambitious and would represent a significant advance if it generalizes beyond the tested domains.

**Scale of ambition and scope of evidence.** The paper explicitly frames MHLA as a **fundamental attention mechanism** that can serve as a drop-in replacement across domains: classification, image generation, language modeling, and video generation (Section 6). The breadth of evaluation—from DeiT-T (5.7M parameters) to Wan2.1-1.3B (1.3B parameters), from 256-token classification to 31,500-token video sequences—is designed to demonstrate universality. This distinguishes MHLA from domain-specific optimizations that might work well on vision but fail on language (or vice versa). The paper's consistent gains across all four domains (3.6% on classification, 12.6% on image generation FID, 6.3% on NLP, 41% on video generation) provide initial evidence for this generality claim.

**Theoretical grounding vs. empirical discovery.** A notable aspect of the paper's positioning is its blend of theoretical analysis (the rank and entropy diagnostics in Section 3.2, the formal rank bound in Section 4.3) with extensive empirical validation. The theoretical analysis does not just argue that MHLA *might* help—it shows *why* prior methods are structurally limited (rank bounded by $d$ regardless of $N$) and *why* MHLA lifts this bound (rank grows additively with the number of blocks $M$). The paper's contribution is thus not a speculative architecture but a design derived from an explicit failure mode analysis with measurable success criteria (rank, entropy, and downstream task performance). This makes the contribution falsifiable in a productive way: if a competing method could achieve the same rank expansion without MHLA's block structure, it would challenge the paper's claimed mechanism while validating its diagnostic framework.

**Limitations acknowledged but open.** The paper is candid that the learned coefficient matrix requires initialization (locality-biased) and normalization (clipped to (0,1)) for stability, and that the choice of block count $M$ involves a tradeoff between expressivity (more blocks → higher rank) and efficiency ($M^2$ term must remain subdominant to $N d^2$). The optimal $M$ is treated empirically rather than theoretically: $M = 16$ for most vision models, $M = 105$ for video (Section 5.3), $M = 32$ for language modeling (Section 5.4). Whether these choices would transfer to other architectures or sequence lengths without re-tuning remains an open question. Additionally, the autoregressive formulation (Appendix C) requires a causal coefficient matrix where entries for future blocks are masked, adding complexity to the training procedure that the paper addresses through established chunkwise techniques but does not claim as an innovation.

## 3. Technical Approach

### 3.1 Reader Orientation

This paper proposes a new attention mechanism—a replacement for the core computation inside Transformer models—called **Multi-Head Linear Attention (MHLA)**. The system solves the problem that standard linear attention collapses all token information into a single shared summary, losing representational diversity; the solution is to partition tokens into blocks, compute independent summaries per block, and then let each query block learn how to mix these summaries via a coefficient matrix, restoring query-conditioned selectivity while keeping computation linear in sequence length.

### 3.2 Big-Picture Architecture (Diagram in Words)

The MHLA system has four major components that operate sequentially on an input token sequence:

1. **Input projection**: The sequence $X \in \mathbb{R}^{N \times d}$ is linearly projected into queries $Q$, keys $K$, and values $V$ via learned weight matrices $W_Q, W_K, W_V \in \mathbb{R}^{d \times d}$, exactly as in standard attention.

2. **Token blocking**: The sequence is partitioned into $M$ non-overlapping blocks along the spatial or spatiotemporal dimensions (not by flattening to 1D). Each block $b$ contains $N_b$ tokens, and these blocks serve as the "heads" in MHLA's multi-head scheme—each block will produce its own local key–value summary.

3. **Local summary computation**: Within each block $b$, keys and values are compressed into a local $d \times d$ summary matrix $S_b$ and a $d$-dimensional normalizer $z_b$ via kernelized outer products. This step is identical to standard linear attention but applied per-block rather than globally.

4. **Multi-Head Mixing with learnable coefficient matrix**: A learned matrix $M_c \in \mathbb{R}^{M \times M}$ specifies how each query block $i$ combines all $M$ local summaries. Row $i$ of $M_c$ is a normalized weight vector $m_i \in \mathbb{R}^M$ that forms a block-specific mixture $\tilde{S}_i = \sum_{b=1}^M m_{i,b} S_b$. Queries in block $i$ then attend to this tailored mixture rather than to a uniform global summary.

5. **Output computation**: For each query vector $\tilde{q}$ in block $i$, the attention output is computed as $o = \tilde{q}^\top \tilde{S}_i / (\tilde{q}^\top \tilde{z}_i)$, where $\tilde{z}_i$ is the corresponding mixed normalizer. This produces query-conditioned outputs while involving only block-level summary operations.

Information flows as follows: input tokens → QKV projections → block partitioning → per-block local KV compression → block-level mixture via learned coefficients → per-query scaled dot product with mixed summary → output.

### 3.3 Roadmap for the Deep Dive

- **First**, the failure mode diagnosis—global context collapse—since MHLA's design is a direct structural response to this identified pathology and understanding it provides the rationale for every architectural choice.
- **Second**, the token blocking and local summary computation, which is the simplest departure from standard linear attention and establishes the block structure that everything else builds on.
- **Third**, the Multi-Head Mixing mechanism—the learned coefficient matrix, its initialization, normalization, and how it restores query-conditioned selectivity—since this is the core innovation.
- **Fourth**, the theoretical analysis of rank and sparsity, which proves why MHLA lifts the representational ceiling and connects the architecture to the failure mode diagnosis.
- **Fifth**, the complexity analysis and chunkwise parallel form, covering how MHLA maintains $O(N)$ complexity and integrates into autoregressive training.
- **Sixth**, a summary of design choices and their justifications, consolidating the rationale thread.

This is primarily a **mechanism design paper** whose core idea is that linear attention's expressivity loss stems from sharing a single global key–value summary across all queries, and that partitioning tokens into blocks with learned inter-block mixing restores query-conditioned selectivity without adding auxiliary modules or sacrificing linear complexity.

#### Global Context Collapse: The Failure Mode MHLA Fixes

Before presenting MHLA's architecture, the paper formally diagnoses what goes wrong in standard linear attention. This diagnosis is essential because MHLA's design is not an empirical hack—it is a direct structural solution to an identified, quantified pathology.

Standard linear attention (Katharopoulos et al., 2020) replaces the softmax exponential kernel with a positive feature map $\phi(\cdot)$ such that:

$$\text{Sim}(Q_i, K_j) \approx \phi(Q_i)\phi(K_j)^\top$$

> where $\text{Sim}(\cdot, \cdot)$ is the similarity function between queries and keys, $\phi(\cdot)$ is a chosen feature map (typically $\phi(x) = \text{elu}(x) + 1$), $Q_i$ is the $i$-th query vector, and $K_j$ is the $j$-th key vector.

**What this approximation does:** It factorizes the similarity computation so that the summation over all keys can be precomputed independently of the query. Instead of computing $N$ dot products for each of $N$ queries (yielding $O(N^2)$ operations), linear attention first aggregates all keys and values into a single global matrix:

$$S = \sum_{j=1}^N \phi(K_j) V_j^\top \quad \in \mathbb{R}^{d \times d}$$

$$z = \sum_{m=1}^N \phi(K_m) \quad \in \mathbb{R}^d$$

where $N$ is the sequence length, $d$ is the feature dimension, $\phi(K_j) \in \mathbb{R}^d$ is the kernelized key vector, and $V_j \in \mathbb{R}^d$ is the value vector. The output for any query $Q_i$ is then:

$$Y_i = \frac{\phi(Q_i)^\top S}{\phi(Q_i)^\top z}$$

**What this computes:** The matrix $S$ compresses all token-to-token interactions into a fixed-size $d \times d$ "memory." Every query in the sequence reads from this same memory to produce its output. The computation per query is just two vector-matrix products of size $O(d^2)$, giving total complexity $O(N d^2)$.

**Why this form causes collapse:** The crucial limitation is that $S$ is a single $d \times d$ matrix shared by all queries. The attention matrix—the unnormalized similarity scores between all query-key pairs—can be expressed as:

$$A_{\text{lin}} = \tilde{Q} \tilde{K}^\top \in \mathbb{R}^{N \times N}$$

where $\tilde{Q} = \phi(Q)$ and $\tilde{K} = \phi(K)$ are the kernelized query and key matrices. By the fundamental rank inequality of matrix multiplication:

$$\text{rank}(A_{\text{lin}}) \leq \min\{\text{rank}(\tilde{Q}), \text{rank}(\tilde{K})\} \leq d$$

where $\text{rank}(\cdot)$ is the number of linearly independent rows or columns in a matrix. This inequality is a basic property: the product of two matrices cannot have more independent directions than the smaller of the two factor matrices. Since $\tilde{Q}$ and $\tilde{K}$ are each $N \times d$ matrices and $d$ is typically much smaller than $N$ (e.g., $d = 64$ vs. $N = 1024$), their rank is strictly bounded by $d$.

**What this bound means operationally:** The attention matrix $A_{\text{lin}}$ can represent at most $d$ independent patterns of token interaction. For a sequence of 1024 tokens, this means only 6.25% of the possible degrees of freedom (when $d = 64$). As sequence length grows to 4096, this drops to 1.6%. Softmax attention has no such bound—its rank can grow with $N$ because it computes pairwise similarities directly without matrix factorization. This is the **rank deficiency** signature of global context collapse.

**The sparsity signature (elevated entropy):** A second, related pathology arises because each token's contribution to the global summary $S$ is diluted by the summation over $N$ tokens. For a query $Q_i$, the effective weight on token $j$ in linear attention is proportional to $\phi(Q_i)^\top \phi(K_j)$, which cannot concentrate sharply because the softmax normalization—which creates exponential separation between similar and dissimilar pairs—is absent. As $N$ increases, these weights approach a uniform distribution, meaning the attention cannot selectively focus on the most relevant tokens. The paper quantifies this using the average entropy of attention score distributions:

$$H(p)_i = -\sum_{j=1}^N p_{ij} \log(p_{ij})$$

where $p_{ij}$ is the normalized attention weight from token $i$ to token $j$. Lower entropy means sharper focus (closer to a one-hot vector); higher entropy means diffuse, unfocused attention. Linear attention exhibits $H(p)_{\text{avg}} = 5.12$ vs. softmax attention's $4.13$ (Figure 3b), confirming the loss of selectivity.

**Why both rank and entropy matter together:** Rank deficiency means the model cannot represent diverse patterns across different query positions (different queries are forced into similar effective attention patterns). Elevated entropy means even for a given query, the attention cannot concentrate on the most relevant tokens. Together, they describe a model that is structurally incapable of fine-grained, query-specific context retrieval—the defining capability of softmax attention.

**Empirical validation (Figure 3):** The paper visualizes attention score matrices and computes average rank and entropy over 500 random samples for each attention variant. Linear attention's attention map appears diffuse and unstructured (rank $\approx$ 58, entropy $\approx$ 5.12), while softmax attention shows sharp, structured patterns (rank $\approx$ 255, entropy $\approx$ 4.13). MHLA substantially closes both gaps (rank $\approx$ 233, entropy $\approx$ 4.06), directly demonstrating that the architectural fix addresses the diagnosed pathology.

#### Token Blocking and Local Summary Computation

MHLA's first departure from standard linear attention is to partition the sequence into $M$ non-overlapping blocks before computing KV summaries. This creates the substrate for query-conditioned mixing while keeping per-block operations identical to standard linear attention.

**Block definition.** Given an input sequence $X \in \mathbb{R}^{N \times d}$, the tokens are partitioned into $M$ blocks $b = 1, \ldots, M$, where block $b$ contains $N_b$ tokens and:

$$\sum_{b=1}^M N_b = N$$

where $N$ is the total sequence length, $M$ is the number of blocks (also called "heads" in MHLA's terminology), and $N_b$ is the number of tokens in block $b$. The paper emphasizes that, for vision models, blocks are defined on spatial (2D) or spatiotemporal (3D) grids rather than by flattening the sequence to 1D and splitting linearly. For example, a 256×256 image processed by DiT with patch size 2 yields a 128×128 latent grid ($N = 16,384$ tokens). Blocks might partition this grid into 4×4 spatial regions, each containing $N_b = 1024$ tokens. This spatial blocking preserves local structure that 1D splitting would destroy.

**Why spatial blocking matters:** In vision tasks, tokens that are spatially adjacent tend to be semantically related (they represent the same object or texture). By keeping these tokens together in the same block, the local summary $S_b$ captures meaningful local statistics. If blocks were formed by arbitrary 1D ordering, each block would contain a scattered mixture of spatially unrelated tokens, reducing the informativeness of the local summaries and making the learned mixing coefficients less interpretable and potentially harder to optimize.

**Per-block local summary computation.** For each block $b$, MHLA computes a local key–value summary identically to how standard linear attention computes its global summary, but restricted to tokens within the block:

$$S_b = \sum_{j \in b} \tilde{K}_j V_j^\top \quad \in \mathbb{R}^{d \times d}$$

$$z_b = \sum_{j \in b} \tilde{K}_j \quad \in \mathbb{R}^d$$

where $S_b$ is the local $d \times d$ key–value summary matrix for block $b$, $z_b$ is the local normalizer vector, $\tilde{K}_j = \phi(K_j) \in \mathbb{R}^d$ is the kernelized key vector for token $j$, $V_j \in \mathbb{R}^d$ is the value vector for token $j$, and the notation $j \in b$ means the summation runs over all tokens assigned to block $b$.

**What this computes:** Each block compresses its local context into a fixed-size representation. A block containing $N_b$ tokens with $d$-dimensional features produces a single $d \times d$ summary matrix. The set of $M$ summary matrices $\{S_1, \ldots, S_M\}$ collectively represents the entire sequence, but now with block-level granularity—each summary $S_b$ captures the statistics of its block's tokens, and different blocks maintain distinct summaries.

**Why per-block summaries instead of a global one:** The key insight is that once summaries are block-specific, queries in different blocks can access different combinations of these summaries. If query block $i$ is interested in tokens from block $j$, it can weight $S_j$ more heavily; if it needs to ignore block $k$, it can weight $S_k$ near zero. This restores query-conditioned selectivity because the choice of which summaries to emphasize is now under the control of a learned coefficient matrix rather than being fixed to "all summaries equally" as in global linear attention.

**Computational cost of block-wise summary computation.** For each block, computing $S_b$ requires $N_b$ vector outer products of dimension $d$, costing $O(N_b d^2)$ operations. Summing over $M$ blocks gives total cost $O(N d^2)$ for the summary computation phase—identical to global linear attention. The blocking introduces no asymptotic overhead in this step.

**Output normalization via local normalizers.** The normalizer $z_b$ computes the sum of kernelized keys within block $b$. In the full attention output (described below), these are mixed analogously to the summaries to produce a query-specific normalizer $\tilde{z}_i$, ensuring proper normalization of the attention weights even though the mixing coefficients change which blocks contribute.

#### Multi-Head Mixing: The Core Innovation

The Multi-Head Mixing module is what distinguishes MHLA from both standard linear attention (which uses a single global summary) and naive blocked linear attention (which would restrict each query to its own block). It introduces a **learned coefficient matrix** that enables each query block to form its own mixture of all local summaries.

**The learnable coefficient matrix.** The core parameter is:

$$M_c \in \mathbb{R}^{M \times M}$$

where each entry $m_{i,j}$ (row $i$, column $j$) represents the affinity between query block $i$ and the local key–value summary of block $j$. Row $i$ of $M_c$, denoted $m_i \in \mathbb{R}^M$, specifies how query block $i$ linearly combines all $M$ local summaries into a query-specific global summary.

**What this matrix does:** For query block $i$, the mixed summary $\tilde{S}_i$ and mixed normalizer $\tilde{z}_i$ are computed as:

$$\tilde{S}_i = \sum_{b=1}^M m_{i,b} S_b \quad \in \mathbb{R}^{d \times d}$$

$$\tilde{z}_i = \sum_{b=1}^M m_{i,b} z_b \quad \in \mathbb{R}^d$$

where $m_{i,b}$ is the scalar mixing weight from query block $i$ to summary block $b$, $S_b$ is the local $d \times d$ summary of block $b$, $z_b$ is the local normalizer vector of block $b$, and the summation runs over all $M$ blocks.

**What this computes operationally:** For a query in block $i$, the effective key–value summary it reads from is a weighted combination of all block summaries. If $m_{i,3} = 0.7$ and $m_{i,7} = 0.1$, then block 3's tokens contribute 7× more to the query's context than block 7's tokens. Different query blocks $i \neq i'$ apply different weight vectors $m_i \neq m_{i'}$, so queries in different spatial positions retrieve different contexts from the same set of local summaries.

**Why mixture rather than hard selection:** A hard selection mechanism (each query block chooses one summary block to attend to) would be non-differentiable and would prevent gradient-based learning of the block affinities. The soft mixture with learned continuous weights enables end-to-end optimization of which blocks are relevant for which query positions. The coefficients are learned through standard backpropagation along with all other model parameters.

**Output computation with mixed summaries.** For a query vector $\tilde{q} = \phi(q) \in \mathbb{R}^d$ from block $i$, the attention output is:

$$o = \frac{\tilde{q}^\top \tilde{S}_i}{\tilde{q}^\top \tilde{z}_i} = \frac{\sum_{b=1}^M m_{i,b} \cdot \tilde{q}^\top S_b}{\sum_{b=1}^M m_{i,b} \cdot \tilde{q}^\top z_b} \quad \in \mathbb{R}^d$$

where $\tilde{q}^\top \tilde{S}_i$ is a vector-matrix product yielding a $d$-dimensional vector (the numerator), $\tilde{q}^\top \tilde{z}_i$ is a scalar (the normalizer), and the division normalizes the output. The right-hand side shows the expansion: each block's contribution $m_{i,b} \cdot \tilde{q}^\top S_b$ is scaled by the mixing coefficient, then all contributions are summed and normalized.

**What this computes:** The output is a query-conditioned aggregation over all tokens in the sequence, where (a) the mixing coefficients $m_{i,b}$ determine the **block-level** importance—how much each block as a whole contributes—and (b) the inner product $\tilde{q}^\top \tilde{K}_j$ (implicit in $S_b = \sum_{j \in b} \tilde{K}_j V_j^\top$) determines the **token-level** importance within each block. This two-stage weighting (block selection × intra-block reweighting) restores query-conditioned selectivity.

**Why this form restores expressivity:** Standard linear attention collapses to the special case where $m_i$ is uniform ($m_{i,b} = 1$ for all $b$), meaning every query sees the same global mixture. MHLA breaks this uniformity by making $m_i$ learned and block-specific. The paper's theoretical analysis (Section 4.3) proves that this expands the rank bound from $d$ to $\min(N, \sum_{b=1}^M \min(N_b, d))$, which can be substantially larger than $d$ when $M$ is chosen appropriately—restoring the representational capacity lost in global linear attention.

#### Coefficient Matrix: Initialization, Normalization, and Learning

The behavior of MHLA critically depends on the initialization and constraints applied to the coefficient matrix $M_c$. The paper's design choices here are motivated by stability concerns and empirical performance.

**Locality-biased initialization.** At training start, $M_c$ is initialized to favor spatial locality: query block $i$ is encouraged to attend more strongly to nearby key–value blocks than to distant ones. The initialization formula for row $i$, column $j$ of $M_c$ is:

$$m_{i,j}^{(0)} \propto 1 - \frac{\text{dist}(i, j)}{\max_k \text{dist}(i, k)}$$

where $\text{dist}(i, j)$ is the Euclidean distance between the spatial centers of blocks $i$ and $j$, and $\max_k \text{dist}(i, k)$ is the maximum distance from block $i$ to any block $k$ in the grid. The proportionality symbol indicates that after computing these raw affinities, they are normalized such that:

$$\sum_{j=1}^M m_{i,j}^{(0)} = 1$$

for each row $i$, ensuring the coefficients sum to one and produce proper weighted averages.

**What this initialization encodes as prior knowledge:** In vision tasks, spatially proximate regions tend to be more semantically related (neighboring patches often depict the same object, texture, or background). By initializing the coefficients to favor locality, the model starts with the inductive bias that nearby information is more relevant—a prior that is almost always correct in early training before the model has learned task-specific attention patterns. This accelerates convergence and stabilizes training because the model does not need to discover spatial locality from scratch through noisy gradients.

**Why Euclidean distance and not some other metric:** For spatial (2D) or spatiotemporal (3D) grids, Euclidean distance is the natural geometric distance metric. The paper visualizes this initialization in Figure 4b for $M = 25$: rows 1 and 14 (corresponding to different spatial positions) produce different locality-biased patterns centered on their respective block positions.

**Learnability and adaptation during training.** Despite the locality-biased initialization, all entries of $M_c$ are **learnable parameters**—they are optimized via gradient descent along with the rest of the model. This allows the coefficient matrix to adapt to the dataset distribution: blocks that are spatially distant but semantically related (e.g., symmetric patterns, repeated structures) can develop stronger affinities, while nearby but semantically unrelated blocks can have their coefficients reduced. The initialization provides a sensible starting point; training refines it.

**Nonnegativity and clipping constraints.** Two constraints are enforced during training to maintain stability. First, all coefficients are clipped to the interval $(0, 1)$ on every update—they cannot become negative (which would produce invalid weighted averages) or exceed 1 (which, combined with the summation-to-one normalization, would be undefined). Second, the coefficients are re-normalized after clipping to ensure $\sum_j m_{i,j} = 1$ for each row, maintaining the interpretation as a proper distribution over blocks.

**Why clipping to $(0, 1)$ and not softmax:** A softmax parameterization $\text{softmax}(\theta_i)$ would also produce valid probability distributions, but it introduces an additional nonlinearity that can make gradients less stable when many coefficients are near zero. Direct normalization with clipping provides more direct control over the coefficient magnitudes and is computationally simpler.

**Two variants compared in ablation (Table 7a).** The paper ablates the initialization strategy on DeiT-T:

- **Uniform initialization without locality bias**: coefficients are initialized uniformly (all blocks get equal weight). This achieves 75.4% top-1 accuracy.
- **Locality-biased initialization with frozen coefficients**: coefficients are set once using the locality formula and never updated during training. This achieves 75.1% accuracy.
- **Locality-biased initialization with learnable coefficients (full MHLA)**: coefficients start from locality bias and are optimized during training. This achieves 75.8% accuracy.

**What this ablation reveals:** The locality-biased initialization alone provides a strong prior (75.4% without learning beats 75.1% with learning but no locality bias), suggesting that spatial locality is genuinely informative for image classification. Making the coefficients learnable provides an additional 0.4% gain, showing that the model benefits from adapting the initial locality bias to task-specific patterns. The frozen variant achieving 75.1% demonstrates that even static, hand-designed coefficients substantially improve over uniform mixing (which would be equivalent to global linear attention at 69.8%—a 5.3% gain from locality alone).

#### How MHLA Restores Query-Conditioned Selectivity: Token-Level Expansion

To understand precisely how the mixing coefficients create query-conditioned token-level weighting, the paper expands the mixed summary computation down to individual tokens. This expansion reveals the two-stage mechanism that distinguishes MHLA from both global linear attention and purely block-level attention.

**Expansion of the mixed summary.** Let $b(t)$ denote the block index of token $t$ (i.e., which block token $t$ belongs to). The local summary for block $j$ expands to:

$$S_j = \sum_{t \in \text{block } j} \tilde{K}_t V_t^\top \quad \in \mathbb{R}^{d \times d}$$

Substituting into the mixed summary for query block $i$:

$$\tilde{S}_i = \sum_{j=1}^M m_{i,j} S_j = \sum_{j=1}^M m_{i,j} \sum_{t \in \text{block } j} \tilde{K}_t V_t^\top = \sum_{t=1}^N m_{i,b(t)} \tilde{K}_t V_t^\top$$

where the double summation over blocks and tokens-within-blocks collapses to a single summation over all $N$ tokens, with each token $t$ weighted by $m_{i,b(t)}$—the mixing coefficient from query block $i$ to whatever block contains token $t$.

**What this expansion means:** Token $t$'s contribution to the context for query block $i$ is scaled by two factors: (1) the block-level coefficient $m_{i,b(t)}$, which is the same for all tokens in token $t$'s block and depends on which query block $i$ is making the request, and (2) the token-level similarity $\tilde{q}^\top \tilde{K}_t$, which is specific to the individual query $\tilde{q}$ and key $\tilde{K}_t$. The numerator of the attention output for query $\tilde{q}$ in block $i$ becomes:

$$\tilde{q}^\top \tilde{S}_i = \sum_{t=1}^N m_{i,b(t)} \left(\tilde{q}^\top \tilde{K}_t\right) V_t^\top \quad \in \mathbb{R}^d$$

where $m_{i,b(t)}$ is the block-level gating factor, $\tilde{q}^\top \tilde{K}_t$ is the scalar similarity between the query and token $t$, and $V_t^\top \in \mathbb{R}^d$ is the transposed value vector.

**What this computes in plain language:** For a query at position $i$ in the image, the model first selects which spatial blocks are relevant via the coefficients $m_{i,b(t)}$ (block-level selection), then within those selected blocks, it differentiates among individual tokens based on their kernelized similarity to the query (intra-block reweighting). Token $t$'s total contribution is the product of its block's selection weight and its personal similarity to the query.

**Why this two-stage mechanism is necessary:** A pure block-level mechanism (queries attend to block summaries without intra-block differentiation) would lose within-block token-level information—all tokens in the same block would be treated identically, which is too coarse. A pure token-level mechanism (no block grouping) would require computing all $N$ token similarities for each query, defeating linear complexity. The two-stage design achieves linear complexity by precomputing block summaries (avoiding $O(N^2)$ token-level operations) while preserving token-level differentiation through the post-mixing inner product $\tilde{q}^\top \tilde{K}_t$ that operates within each block's contribution.

**Contrast with global linear attention:** Global linear attention is the degenerate case where $m_{i,b(t)} = 1$ for all $i$ and all $t$ (every query sees every token equally). The expansion then becomes:

$$\tilde{q}^\top S_{\text{global}} = \sum_{t=1}^N \left(\tilde{q}^\top \tilde{K}_t\right) V_t^\top$$

which is MHLA's expansion with the block-level gating factor removed. Without $m_{i,b(t)}$, all queries produce the same token importance pattern (up to the token-level similarity $\tilde{q}^\top \tilde{K}_t$, which varies with $\tilde{q}$ but is bounded by the rank-$d$ structure). With $m_{i,b(t)}$, different query blocks can completely rearrange which tokens are important—queries in block 1 can attend primarily to tokens in blocks 1–3, while queries in block 14 can attend primarily to tokens in blocks 12–16, even if $\tilde{q}^\top \tilde{K}_t$ would suggest similar patterns.

#### Rank Analysis: Why MHLA Lifts the Representational Ceiling

The paper provides a formal rank analysis (Section 4.3) that proves MHLA's attention matrix can achieve substantially higher rank than global linear attention, directly addressing the rank deficiency identified in the global context collapse diagnosis.

**Constructing the MHLA attention matrix.** Partition the sequence into $M$ blocks of sizes $N_1, \ldots, N_M$. Let the kernelized query matrix be $\tilde{Q} = [\tilde{Q}_1^\top, \ldots, \tilde{Q}_M^\top]^\top$ where $\tilde{Q}_b \in \mathbb{R}^{N_b \times d}$ contains the queries for block $b$. From the token-level expansion, the effective key matrix seen by query block $i$ is:

$$Y_i = \begin{bmatrix} m_{i,b(1)} k_1, & m_{i,b(2)} k_2, & \ldots, & m_{i,b(N)} k_N \end{bmatrix} \in \mathbb{R}^{d \times N}$$

where $k_t = \tilde{K}_t \in \mathbb{R}^d$ is the kernelized key vector for token $t$, and $m_{i,b(t)}$ is the mixing coefficient from query block $i$ to the block containing token $t$. The attention submatrix for query block $i$ is then:

$$A_i = \tilde{Q}_i Y_i \in \mathbb{R}^{N_i \times N}$$

and the full MHLA attention matrix stacks these submatrices:

$$A_{\text{MHLA}} = \begin{bmatrix} A_1^\top & A_2^\top & \cdots & A_M^\top \end{bmatrix}^\top \in \mathbb{R}^{N \times N}$$

**Applying rank inequalities.** For each submatrix $A_i = \tilde{Q}_i Y_i$, the rank inequality gives:

$$\text{rank}(A_i) \leq \min\{\text{rank}(\tilde{Q}_i), \text{rank}(Y_i)\} \leq \min(N_i, d)$$

where $N_i$ is the number of tokens in block $i$ and $d$ is the feature dimension. The maximum possible rank of any $A_i$ is therefore bounded by $\min(N_i, d)$—each query block contributes at most $\min(N_i, d)$ independent directions to the full attention matrix.

**Global MHLA rank bound.** Since the full matrix $A_{\text{MHLA}}$ stacks $M$ submatrices vertically, its rank satisfies:

$$\text{rank}(A_{\text{MHLA}}) \leq \min\left(N, \sum_{b=1}^M \min(N_b, d)\right)$$

where $N$ is the total sequence length and the summation adds the per-block rank caps.

**What this bound says:** The MHLA attention matrix can have rank up to $\sum_{b=1}^M \min(N_b, d)$. Compare this to global linear attention's bound of $d$ (strictly, $\min(N, d)$, which equals $d$ in the typical regime $N \gg d$). The key difference is the summation over $M$ blocks: each block contributes up to $\min(N_b, d)$ independent directions, and if the row spaces of different submatrices $A_i$ are linearly independent, these contributions add up.

**When the bound is attainable:** Under mild, generic conditions (each block product $\tilde{Q}_i Y_i$ has full row rank and the row spaces of $\{A_i\}_{i=1}^M$ are linearly independent), the bound is attained:

$$\text{rank}(A_{\text{MHLA}}) = \min\left(N, \sum_{b=1}^M \min(N_b, d)\right)$$

Even when the independence assumption is not perfectly satisfied, the blockwise mixture still expands the diversity of row spaces, causing rank to grow roughly additively with $M$. The paper explicitly notes: "the blockwise mixture still expands the diversity of the row spaces, causing rank$(A_{\text{MHLA}})$ to grow roughly additively with $M$."

**Concrete example to understand the scaling.** Suppose $N = 1024$, $d = 64$, and $M = 16$ with equal block sizes $N_b = 64$ tokens per block. The global linear attention bound is $\min(1024, 64) = 64$. The MHLA bound is $\min(1024, 16 \times 64) = \min(1024, 1024) = 1024$. In this configuration, MHLA can theoretically recover full rank—the same representational capacity as softmax attention—while global linear attention is capped at 6.25% of full capacity. This is not just a marginal improvement; it is a qualitative change in what the attention mechanism can represent.

**Why the coefficients $m_{i,b}$ enable this:** The mixing coefficients differentiate the $Y_i$ matrices across query blocks. If $m_i = m_{i'}$ for all $i, i'$ (uniform mixing), then $Y_i = Y_{i'}$ for all blocks, and the row spaces of all $A_i$ are identical, reducing the effective rank back to $\min(N, d)$. The learned, block-specific coefficients make the $Y_i$ matrics *different*, enabling their row spaces to span independent subspaces and the ranks to accumulate.

**Empirical validation (Figure 3b).** The paper reports: "MHLA consistently achieves a substantially higher attention-score rank than other linear attention variants—and does so without relying on auxiliary components such as depth-wise convolutions." Specifically, MHLA achieves rank $\approx$ 233 vs. linear attention's $\approx$ 58 and softmax attention's $\approx$ 255. This is consistent with the theoretical bound: $d = 64$ caps linear attention; MHLA with $M$ blocks can exceed this cap.

#### Sparsity Analysis: Why MHLA Produces Sharper Attention

The rank analysis addresses representational *diversity* (can the model express many different attention patterns?). The sparsity analysis addresses attention *selectivity* (can the model focus sharply on a small subset of relevant tokens?). These are complementary: high rank means different queries can attend differently; high sparsity means each query can attend precisely.

**Mechanism for sparsity restoration.** The learned coefficient matrix $M_c$ allows each query block to assign higher weights to a subset of blocks that are more relevant. This effectively prunes irrelevant tokens at the block level: if $m_{i,j} \approx 0$ for some block $j$, then *all* tokens in block $j$ receive near-zero contribution to the context for queries in block $i$. Within the selected blocks (where $m_{i,j}$ is substantial), the kernel inner products $\tilde{q}^\top \tilde{K}_t$ further differentiate token contributions.

**Why block-level pruning produces sharper distributions:** Without block-level gating, all tokens contribute to the context via $\tilde{q}^\top \tilde{K}_t$, and as $N$ grows, each term becomes a smaller fraction of the total, pushing the distribution toward uniformity (elevated entropy). With block-level gating, tokens in irrelevant blocks are effectively zeroed out before the within-block differentiation occurs, so the attention mass is concentrated on tokens in relevant blocks—fewer tokens share the total attention budget, allowing each to receive a larger, more meaningful weight.

**Entropy measurement.** The paper computes the average entropy of attention score distributions:

$$H(p)_{\text{avg}} = \frac{1}{N} \sum_{i=1}^N H(p_i), \quad H(p_i) = -\sum_{j=1}^N p_{ij} \log(p_{ij})$$

where $p_{ij}$ is the normalized attention weight from token $i$ to token $j$. Lower entropy indicates sparser, more focused attention. The results (Figure 3b): linear attention entropy $\approx$ 5.12, softmax attention entropy $\approx$ 4.13, MHLA entropy $\approx$ 4.06.

**Why MHLA can achieve even lower entropy than softmax attention:** Softmax attention's entropy is determined by the temperature-scaled exponential, which can produce sharp distributions but has a theoretical lower bound (it cannot produce exactly zero weight for any token because $\exp(x) > 0$ for all finite $x$). MHLA's block-level gating via $m_{i,b}$ can effectively assign zero contribution to entire blocks if the learned coefficients approach zero for those blocks. This hard pruning at the block level—combined with soft differentiation within selected blocks—can produce sparser distributions than softmax's purely soft weighting.

**The paper's empirical claim:** "MHLA consistently yields lower attention entropy compared to other linear-attention baselines and even the softmax attention. This confirms that MHLA preserves query-conditioned selectivity and achieves substantially higher sparsity, enabling the model to attend to a small, semantically relevant subset of tokens rather than spreading attention uniformly."

#### Efficiency Analysis: Complexity, Hardware, and Block Count Tradeoffs

The paper provides both asymptotic complexity analysis and empirical throughput measurements to demonstrate that MHLA preserves linear scaling while increasing expressivity.

**Asymptotic time complexity decomposition.** The computation of MHLA consists of three phases:

**Phase 1: Local key–value summary computation.** For each of $M$ blocks, compute $S_b$ and $z_b$ via outer products and sums over $N_b$ tokens:

$$O\left(\sum_{b=1}^M N_b d^2\right) = O(N d^2)$$

where $N_b d^2$ is the cost of summing $N_b$ outer products of dimension $d \times d$.

**Phase 2: Multi-Head Mixing.** Form mixed summaries for each of $M$ query blocks by linearly combining $M$ local summaries of size $d \times d$:

$$O(M \cdot M \cdot d^2) = O(M^2 d^2)$$

where the factor $M \cdot M$ comes from forming $M$ mixtures, each requiring $M$ scalar-coefficient × matrix operations.

**Phase 3: Output computation.** For each token, compute the query–summary dot product and normalization:

$$O(N d^2)$$

combining with Phase 1 to give $O(N d^2)$ for the token-level operations.

**Total time complexity:**

$$O(N d^2 + M^2 d^2)$$

where $N d^2$ is the linear-in-sequence-length term and $M^2 d^2$ is the block-mixing overhead term.

**Why this is still linear in $N$:** The paper states: "To better capture local information while ensuring efficiency, the number of blocks $M$ is usually set to satisfy $M^2 \leq N$." Under this constraint, $M^2 d^2 \leq N d^2$, so the mixing overhead is at most equal to the token-level computation—the $N d^2$ term remains the leading or co-leading term, and the asymptotic complexity remains $O(N d^2)$, linear in sequence length.

**What happens when $M^2 > N$?** The $M^2 d^2$ term would dominate, potentially making the overhead significant. The paper's ablation (Table 7b) shows that for DiT-S/2 at 512 resolution ($N = 1024$), $M = 4$, $16$, and $64$ all achieve similar FID scores, but $M = 64$ has slightly lower throughput (408 im/s vs. 435 im/s for $M = 16$). The theoretical bound $\sqrt{N} = 32$ for $N = 1024$ means $M = 64$ exceeds the $M^2 \leq N$ threshold, consistent with the throughput drop. The paper recommends choosing $M$ to satisfy $M^2 \leq N$ and empirically finds that $M = 16$ (which satisfies $16^2 = 256 \leq 1024$) achieves optimal throughput-performance tradeoff.

**Memory complexity.** Standard self-attention stores the $N \times N$ attention matrix, requiring $O(N^2)$ memory. Global linear attention stores a single $d \times d$ summary matrix, requiring $O(d^2)$ memory. MHLA stores $M$ local summaries of size $d \times d$, requiring:

$$O(M d^2)$$

memory. Since $M \leq \sqrt{N}$ in practice, this is $O(\sqrt{N} d^2)$, which grows sublinearly with sequence length.

**Empirical throughput measurements (Figure 1b, Table 14).** For DiT-S/2 at 4096 resolution on H100 GPU, the paper reports:
- Linear attention throughput: highest (baseline for $O(N d^2)$)
- MHLA throughput: nearly identical to linear attention at all resolutions, confirming the overhead is negligible
- Self-attention throughput: drops dramatically as resolution increases, falling well below MHLA

At 512 resolution, MHLA achieves better FID scores than self-attention (DiT-S/2: MHLA 78.63 vs. Self-Attention 84.54) while delivering roughly double the throughput of self-attention. At 256 resolution, the throughput gap is smaller but MHLA still maintains speed parity with linear attention.

**Comparison table (Table 1).** The paper summarizes the theoretical properties:

| Method | Time Complexity | Rank Bound | Memory Complexity | Query-Conditioned |
|--------|----------------|------------|-------------------|-------------------|
| Self Attention | $O(N^2 d)$ | $N$ | $O(N^2)$ | ✓ |
| Linear Attention | $O(N d^2)$ | $d$ | $O(d^2)$ | ✗ |
| MHLA | $O(N d^2 + M^2 d^2)$ | $\sum_b \min(N_b, d)$ | $O(M d^2)$ | ✓ |

The table cleanly illustrates MHLA's position: it achieves the linear complexity of linear attention and the query-conditioned selectivity of self-attention, with rank that scales additively with block count and memory that grows only with block count rather than sequence length.

**Hardware-efficient implementation.** The paper notes: "Thanks to the simplicity of MHLA, the implementation only relies on standard GEMMs, keeping the overall computational overhead negligible with $O(N)$ complexity." GEMM (General Matrix Multiply) operations are extremely well-optimized on modern GPU hardware via libraries like cuBLAS. MHLA's operations—outer products for summary computation, matrix-vector products for output—are all standard GEMM calls, meaning the theoretical $O(N d^2)$ translates to hardware-efficient execution without custom CUDA kernels. This is a practical advantage over methods requiring custom operations (e.g., depthwise convolutions with specific kernel sizes, sparse attention patterns with irregular memory access).

#### Autoregressive and Chunkwise Formulation

For autoregressive tasks (language modeling, video generation with causal masking), MHLA requires a causal variant where each token can only attend to past tokens. The paper adapts MHLA using the established chunkwise parallel training framework (Sun et al., 2023; Hua et al., 2022).

**The causal constraint.** In autoregressive modeling, token $t$ can only attend to tokens $1, \ldots, t$. Standard linear attention handles this by maintaining a running global summary that is updated sequentially, but naive sequential updating costs $O(N^2 d)$ over the full sequence. Chunkwise parallel training solves this by partitioning the sequence into blocks of size $C$ and processing them in parallel while maintaining causality.

**Chunkwise linear attention baseline.** For block $i$ containing tokens from position $iC+1$ to $(i+1)C$, the method:
1. Computes a local summary $S_i$ from tokens within block $i$
2. Uses the prefix summary $S_{i-1}^{\text{global}}$ (accumulated from all blocks $< i$) for context from earlier tokens
3. Computes intra-block attention directly (which costs $O(C^2 d)$ per block, but $C$ is small)
4. Updates the global summary: $S_i^{\text{global}} = S_{i-1}^{\text{global}} + S_i$

**MHLA's chunkwise adaptation.** MHLA replaces the single global summary with query-conditioned mixtures. For block $i$:

$$\tilde{S}_{i-1} = \sum_{b < i} m_{i,b} S_b$$

where the summation runs only over blocks before $i$ (the causal mask), $m_{i,b}$ are the learned mixing coefficients from the **causal** coefficient matrix $M_c^{\text{causal}}$ (where entries $m_{i,b}$ for $b > i$ are set to zero to enforce causality), and $S_b$ are the local summaries of past blocks. The attention output for block $i$ is then:

$$H_i = Q_i \tilde{S}_{i-1} + m_{i,i} \left(Q_i \tilde{K}_i^\top\right) V_i$$

where the first term $Q_i \tilde{S}_{i-1}$ propagates context from preceding blocks via the mixed prefix summary, and the second term $m_{i,i} (Q_i \tilde{K}_i^\top) V_i$ captures intra-block attention (within block $i$), scaled by the self-mixing coefficient $m_{i,i}$.

**What this computes:** Queries in block $i$ attend to past tokens through a query-specific mixture of past block summaries, rather than a uniform global summary. The mixing coefficients $m_{i,b}$ are learned and determine which past blocks are most relevant for block $i$'s queries. The causal mask $b < i$ ensures no information leakage from future tokens.

**Complexity of chunkwise MHLA.** Per-block complexity remains $O(C d^2 + C^2 d)$ (local summary computation + intra-block attention). The mixing step adds $O(M d^2)$ per block for combining $M$ past summaries, which is asymptotically dominated by the per-block operations when $M \leq \sqrt{N}$ and $C$ is chosen appropriately. Total complexity over all blocks is $O(\frac{N}{C} (C d^2 + C^2 d)) = O(N d^2 + N C d)$, linear in $N$ when $C$ is constant.

**Causal inference.** At inference time, MHLA maintains the set of past local summaries $\{S_1, \ldots, S_{i-1}\}$ and incrementally updates the current block summary $S_i$ as new tokens arrive. When a block is complete, its contribution to future mixtures is fixed and cached. For a new token in block $i$, the system updates $S_i \leftarrow S_i + \tilde{K}_t V_t^\top$ (an $O(d^2)$ outer product) and recomputes the block's mixed summary $\tilde{S}_i$ by applying $m_{i,i}$ to the incremental update. This avoids recomputation over previous blocks and keeps per-token inference complexity $O(d^2)$.

**Normalizer omission for long sequences.** The paper notes that for language modeling and video generation tasks: "the normalizer term can be omitted for better training stability when the sequence is getting longer." This follows the finding of Qin et al. (2022) that the normalizer in linear attention can cause numerical instability in very long sequences. Omitting the normalizer simplifies the output to $o = \tilde{q}^\top \tilde{S}_i$ (unnormalized), which can be more stable because it avoids division by potentially very small or very large accumulated normalizer values.

#### Summary of Design Choices and Their Justifications

- **Spatial block partitioning** over 1D flattening: preserves local semantic structure (spatially adjacent tokens are semantically related), making local summaries more informative and the coefficient matrix more interpretable.
- **Learnable coefficient matrix with locality-biased initialization** over uniform initialization or frozen coefficients: the locality bias provides a strong prior for vision tasks (nearby blocks are genuinely more relevant), while learnability allows task-specific adaptation—the ablation (Table 7a) confirms both are important.
- **Nonnegativity and summation-to-one normalization** over softmax or unconstrained weights: ensures coefficients produce valid weighted averages (convex combinations) of block summaries, which is the correct inductive bias for attention mixtures.
- **Two-stage weighting (block selection × intra-block reweighting)** over pure block-level or pure token-level mechanisms: block-level selection achieves linear complexity by precomputing block summaries; intra-block reweighting via $\tilde{q}^\top \tilde{K}_t$ preserves token-level differentiation. The two-stage design is the minimal mechanism that achieves both goals.
- **Chunkwise parallel formulation with causal coefficient matrix** over sequential per-token inference: enables efficient parallel training on modern hardware while preserving strict causality; the causal coefficient matrix is a straightforward adaptation (masking upper-triangular entries) that requires no architectural changes.
- **Block count $M$ chosen to satisfy $M^2 \leq N$** over arbitrary $M$: this constraint ensures the mixing overhead $M^2 d^2$ does not dominate the linear-in-sequence-length term $N d^2$, maintaining the $O(N)$ complexity claim. Empirical results (Table 7b) validate that this choice provides optimal throughput-performance tradeoff.
- **GEMM-only implementation** over custom CUDA kernels or specialized operations: ensures hardware efficiency on commodity GPUs without requiring hand-tuned kernel development; all operations (outer products, matrix-vector products, linear combinations) map directly to highly optimized matrix multiply routines.
- **No auxiliary modules (no convolutions, no gating, no hybrid attention) as a design goal** over augmenting linear attention with external capacity: the paper's central claim is that restoring query-conditioned selectivity within the attention mechanism itself is sufficient; adding modules would contradict this claim and introduce the overhead MHLA is designed to avoid. The results on DiT-XL (Table 3a) where CPE *degrades* performance validate that MHLA's internal capacity is sufficient at scale.

## 4. Key Insights and Innovations

### Innovation 1: Global Context Collapse — A Diagnostic Framework That Explains *Why* Linear Attention Fails, Not Just *That* It Fails

Before this paper, the literature on linear attention had accumulated a catalog of empirical observations: linear attention degrades relative to softmax attention, performance drops worsen with sequence length, and various augmentations (convolutions, gating, SSMs) can partially recover accuracy. What was missing was a **unified diagnostic framework** that identified the root cause of these degradations in structural terms — terms that would point toward a solution rather than just documenting symptoms.

MHLA's primary intellectual contribution is not the architecture itself but the **identification and formalization of global context collapse** as the failure mode of linear attention, quantified through two measurable, theory-grounded signatures: **rank deficiency** and **elevated attention entropy**. This is a conceptual move, not an engineering one. It says: *the problem is not that linear attention is "less powerful" in some vague sense — it is that the $d \times d$ global KV summary creates an information bottleneck whose severity can be predicted from first principles and measured empirically.*

**What makes this diagnostic move distinctive.** Prior work diagnosed linear attention's weaknesses indirectly — through downstream accuracy gaps (Han et al., 2023; Fan et al., 2025), through qualitative attention map visualizations, or through the claim that "the softmax provides important nonlinearity." None of these diagnoses pointed to a specific structural constraint that could be lifted. The rank argument in Section 3.2 changes the conversation: $\text{rank}(A_{\text{lin}}) \leq d$ regardless of $N$ means linear attention's representational capacity is *capped at a constant* while softmax attention's grows with sequence length. This is not about softmax being "better" — it is about the rank of the attention matrix being fundamentally bounded, which is a provable property of the linear attention formulation, not a contingent empirical observation.

**Why this reframes the problem.** Once the failure is understood as a rank bottleneck, the design objective becomes clear: *increase the effective rank of the attention matrix while preserving linear complexity.* This transforms the research question from "what external modules can we add to compensate for linear attention's weakness?" to "how can we structurally expand the rank of the attention computation itself?" This is precisely the shift that MHLA embodies — it addresses the root cause rather than treating symptoms with auxiliary capacity. The paper's theoretical analysis in Section 4.3, proving that the rank bound lifts from $d$ to $\sum_b \min(N_b, d)$, is not an afterthought but the **intellectual center of gravity**: the architecture is designed to achieve this expanded rank bound, and the empirical results confirm that the expanded capacity translates to downstream performance.

**Comparison to prior diagnostic frameworks.** The low-rank bottleneck in attention had been studied before — Bhojanapalli et al. (2020) analyzed rank in multi-head softmax attention and showed it could be a limiting factor. But that work studied *softmax* attention's rank (which is not fundamentally bounded by $d$ because the softmax is applied after the low-rank matrix multiplication) and proposed fixes within the softmax framework. This paper's application of rank analysis to *linear* attention reveals a qualitatively different phenomenon: a hard, absolute rank ceiling that softmax attention does not have. The entropy-based sparsity analysis adds a second, independent dimension of diagnosis — rank measures *diversity* of attention patterns; entropy measures *selectivity* within each pattern. Both degrade in linear attention, and MHLA is shown to improve both (Figure 3: rank 58 $\rightarrow$ 233; entropy 5.12 $\rightarrow$ 4.06), demonstrating that the fix addresses both signatures of the diagnosed pathology.

**The significance of the negative finding.** An underappreciated aspect of this contribution is that it explains *why* linear attention with simple augmentations has seen only incremental progress. If convolutions or gating add capacity but do not lift the rank ceiling, then performance will plateau at whatever the augmented model can squeeze from a rank-deficient attention mechanism. The paper's video generation results (Wan-LA effectively failing to train at 31,500 tokens, Table 5) provide the strongest evidence: at extreme sequence lengths, the rank ceiling becomes so severe relative to $N$ that no amount of auxiliary capacity can compensate. This validates that structural fixes are not just "better" but *categorically necessary* beyond a certain sequence length.

**Evidence anchors.** Figure 3a–b (rank and entropy comparison across attention types), Table 1 (rank bound column formalizing the ceiling), and the video generation failure of vanilla linear attention (Table 5, Wan-LA achieving 58.24 total score vs. Wan-FA at 83.31) provide the empirical backbone for this diagnostic framework.

### Innovation 2: Query-Conditioned Selectivity as the Missing Ingredient — Restoring It Without Sacrificing Linear Complexity

A second conceptual contribution — distinct from the diagnostic framework — is the **identification that query-conditioned selectivity is the specific capability lost in linear attention, and the design of a mechanism that restores it natively within the attention computation rather than through external modules.** Prior work recognized that linear attention is "less expressive" than softmax attention; this paper pins down exactly *what kind* of expressivity is lost: the ability of different queries to retrieve *different* contexts from the same sequence.

**What the field assumed before this paper.** The dominant approach to closing the linear-softmax performance gap has been to add capacity *outside* the attention mechanism: depthwise convolutions (Focused LA, RALA), gating modules (GLA, Mamba2), hybrid attention layers. The implicit assumption was that linear attention's cheap kernel approximation is fundamentally limited and that recovering performance requires supplementing it with richer computations. This paper challenges that assumption directly: it argues that the kernel approximation itself is not the problem — the problem is that all queries share the same compressed representation. Fix that structural flaw, the paper claims, and no supplements are needed.

**How MHLA operationalizes this insight.** The Multi-Head Mixing mechanism (Section 4.2) is the architectural realization of this idea: partition tokens into blocks, compute independent local summaries, and let each query block learn its own mixture weights. The concept is clean enough to be stated in one English sentence: *different spatial positions should be able to pay different amounts of attention to different regions.* This is so intuitively obvious that one might wonder why prior work didn't design around it — the answer is that this design was obstructed by an implicit constraint: that linear attention's efficiency comes from exactly the global sharing that MHLA breaks. The innovation is recognizing that **sharing can be broken at the block level without breaking linear complexity, provided block count is sublinear in sequence length ($M^2 \leq N$).**

**Why this is a fundamental shift, not an incremental improvement.** Prior augmentations (convolutions, gating) add representational capacity *alongside* the attention mechanism — they compute richer features that become the Q, K, V inputs to attention, but the attention operation itself remains globally shared. MHLA modifies the attention operation *itself* to be query-conditioned. This is the difference between making the inputs better and making the computation better — the former can help up to a point but runs into the rank ceiling; the latter lifts the ceiling. The paper's results on DiT-XL (Table 3a) crystallize this distinction: plain MHLA (no CPE, no gating) achieves FID 20.32, nearly matching self-attention's 19.47 and far outperforming linear attention's 28.63. Adding CPE to MHLA at this scale *degrades* performance to 22.79. At small scales (DiT-S), CPE+gating helps (FID 59.8 with, 76.4 without) — but this is because the small model is capacity-limited overall, not because the attention mechanism needs supplements. At sufficient scale, MHLA's internal query-conditioned selectivity is self-sufficient.

**The two-stage weighting insight as a conceptual bridge.** The paper shows that MHLA's attention output expands to $o = \sum_t m_{i,b(t)} (\tilde{q}^\top \tilde{K}_t) V_t$ — block-level gating times intra-block token similarity. This decomposition reveals that MHLA is not just "linear attention with blocks"; it is a **hierarchical attention mechanism** where coarse spatial selection (which blocks are relevant) and fine token differentiation (which tokens within those blocks) are factorized into independent mechanisms. This factorization is what enables the rank expansion: different query blocks can select entirely different sets of relevant blocks, creating independent row spaces in the attention matrix.

**Evidence anchors.** The coefficient matrix initialization visualization (Figure 4b) showing block-specific locality patterns, the ablation on initialization strategy (Table 7a: locality bias alone gives 75.4%, learning adds 0.4%), and the DiT scaling results showing CPE benefits diminish with model size (Table 3a) collectively support the claim that query-conditioned selectivity — not auxiliary capacity — is the critical ingredient.

### Innovation 3: The "Attention Rank" as a Unifying Metric — Connecting Theory, Architecture Design, and Empirical Validation

The paper introduces **attention matrix rank as a theory-to-practice bridge** — a single metric that (a) is grounded in linear algebra (the rank bound for linear attention is provable), (b) directly motivates the architecture (MHLA is designed to expand this rank), and (c) provides a post-hoc validation signal (empirically measured ranks in Figure 3b confirm the expansion). This is methodologically significant because it transforms hyperparameter selection and architecture comparison from purely empirical trial-and-error to a partially principled, metric-guided process.

**What makes this use of rank novel.** Rank has been used before in attention analysis — Bhojanapalli et al. (2020) analyzed low-rank bottlenecks in multi-head softmax attention — but prior work used rank as a *diagnostic of limitations* in existing architectures. This paper goes further: it uses rank as a **design objective.** The architecture is constructed to maximize the theoretical rank bound under the constraint of linear complexity, and the block count $M$ and block sizes $N_b$ are chosen with the rank formula $\sum_b \min(N_b, d)$ in mind. This is a different relationship between theory and practice: rather than analyzing an existing architecture and finding it rank-deficient, the paper *designs* an architecture to achieve a specific rank property and then verifies that it does.

**Why this matters beyond this specific architecture.** The rank-as-design-objective framing is transferable: future work on efficient attention can use the same lens to evaluate whether a proposed mechanism expands the effective rank of the attention computation, and by how much. A method that adds convolutions but does not change the rank bound is categorically different from one that lifts the rank ceiling — the rank metric makes this distinction quantitative and theory-backed rather than hand-wavy. This is particularly valuable in a field where dozens of efficient attention variants are proposed with different inductive biases and it is not always clear whether improvements come from fundamental expressivity gains or from better optimization of an expressivity-limited architecture.

**The sparsity complement.** The paper does not rely on rank alone — it pairs it with attention entropy as a second, independent metric. Rank measures *diversity across queries* (can different tokens attend differently?); entropy measures *selectivity per query* (can a single token attend sharply?). These two dimensions together provide a richer picture than either alone. The fact that MHLA improves both simultaneously (Figure 3b: rank 58 $\rightarrow$ 233, entropy 5.12 $\rightarrow$ 4.06) while prior methods like Focused LA or RALA likely improve only one dimension (convolutions might increase effective rank through feature enrichment but do not directly address entropy) suggests a methodological lesson: **future efficient attention proposals should be evaluated on both rank and entropy, not just downstream accuracy**, because these metrics reveal *how* the architecture achieves its gains and whether the underlying pathology has been addressed.

**Evidence anchors.** Table 1 (rank bound column formalizing the ceiling), Figure 3b (empirical rank and entropy measurements), and the theoretical derivation in Section 4.3 (showing the additive rank bound) together illustrate this unified metric framework.

---

### Innovation 4: Empirical Proof That Linear Attention's Problems Are Structural, Not Just Capacity-Limited — The Scaling Behavior at Sequence Extremes

The paper's video generation experiments (Section 5.3) provide what is arguably its most compelling single result: at 31,500 tokens, vanilla linear attention **effectively fails to train**, plateauing at a high loss while MHLA converges similarly to FlashAttention (Figure 6). This is not a performance gap of a few percentage points — it is a qualitative failure mode where the model cannot learn at all at that sequence length with global linear attention but can with MHLA.

**Why this result is conceptually important.** One could have hypothesized — and prior work implicitly assumed — that linear attention's degradation is a capacity issue: the model doesn't have enough parameters or enough layers to compensate for the information lost in compression. Under that hypothesis, scaling up the model (more parameters, more layers, more training data) would eventually close the gap with softmax attention. The video generation result refutes this: the degradation is not a matter of degree but of *kind* — at sufficient sequence length, linear attention hits a cliff beyond which no amount of model capacity can recover because the information bottleneck in the $d \times d$ summary is so severe relative to $N$ that essential information never reaches the model. This is a structural failure, not a capacity failure.

**The scaling implication.** This result recasts the efficient attention problem from "how can we make linear attention more accurate?" to "at what sequence length does linear attention break down entirely, and can we predict that from the rank bound?" At $N = 31,500$ with a typical head dimension $d \approx 64$, linear attention's rank is capped at $\approx 64$ independent directions — approximately 0.2% of the $N$ degrees of freedom theoretically available. MHLA with $M = 105$ blocks raises the theoretical bound to $\sum_b \min(N_b, 64)$ where $N_b \approx 31,500/105 = 300$, so the bound is $105 \times 64 = 6720$, roughly $105\times$ larger than linear attention's bound. The fact that MHLA successfully trains and recovers performance comparable to the original FlashAttention model (Wan-MHLA: 82.62 total score vs. Wan-FA: 83.31, Table 5) while vanilla linear attention collapses (Wan-LA: 58.24) provides the cleanest possible demonstration that the rank bound is not just a theoretical curiosity — it has direct, catastrophic practical consequences at scale.

**The practical upshot for architecture selection.** This result has immediate implications for practitioners: if you are training on sequences longer than a few thousand tokens, **do not use vanilla linear attention**. Use a mechanism that expands the effective rank of the attention computation — whether MHLA or something with similar rank-expansion properties. The paper does not claim MHLA is the only such mechanism, but the rank diagnostic provides a criterion for evaluating alternatives.

**Relation to the hybrid model result.** The Wan-MHLA-H model (only 2/3 of layers replaced by MHLA) achieves the best overall score (83.82) with a 1.6× speedup. This suggests a pragmatic deployment strategy: not all layers may need rank expansion; mixing MHLA layers with traditional attention or linear attention layers can achieve excellent accuracy-efficiency tradeoffs. This is an empirical finding rather than a theoretical claim, but it is practically significant for resource-constrained deployments.

**Evidence anchors.** Table 5 (Wan-LA at 58.24 total score vs. Wan-MHLA at 82.62 and Wan-FA at 83.31), Figure 6 (loss curves showing Wan-LA plateauing at high loss while Wan-MHLA converges), and the rank analysis connecting the 31,500-token sequence length to the $d = 64$ ceiling.

## 5. Experimental Analysis

### Evaluation Methodology

- **Dataset.** The paper evaluates across four domains with domain-specific datasets. Image classification uses **ImageNet-1K** (Deng et al., 2009) with the standard 1.28M training / 50K validation split. Image generation (both class-to-image and text-to-image) also uses ImageNet-1K for C2I training and evaluation; for T2I finetuning, a collection of 31,292K images from the internet is used (Appendix D). Natural language processing uses **FineWeb-Edu** (Penedo et al., 2024)—specifically 10B tokens for the main 0.3B model training—and a subset of **SlimPajama** (Shen et al., 2024) with 5B tokens for supplementary training (Appendix D). Video generation uses the **VBench** benchmark suite for evaluation (Section 5.3). Long-context NLP evaluation uses **LongBench** (Bai et al., 2024).

- **Base model(s).** Four architectural families are used, chosen to span discriminative and generative settings and model scales. For classification: **DeiT** (Touvron et al., 2021) at Tiny (5.7M params) and Small (22M params) scales, and **VLT** (Fan et al., 2025) at Tiny (16M params) and Small (27M params) scales. For C2I generation: **DiT** (Peebles and Xie, 2023) at S/2, B/2, L/2, and XL/2 scales, and **DiG** (Zhu et al., 2025) at S/2. For T2I generation: **SANA-0.6B** (Xie et al., 2024). For NLP: a **340M-parameter** language model trained from scratch following the GLA recipe (Yang et al., 2024). For video generation: **Wan2.1-1.3B**, a pretrained video diffusion model. The diversity of architectures and scales (5.7M to 1.3B parameters, 256 to 31,500 tokens per sequence) is deliberate—the paper aims to demonstrate MHLA's universality as a drop-in attention replacement, not its optimization for any one domain.

- **Metrics.** Classification performance is measured by **Top-1 accuracy (%)** on ImageNet-1K validation (Section 5.1, Table 2). Image generation quality is measured by **Fréchet Inception Distance (FID↓)** as the primary metric, supplemented by **Inception Score (IS↑)**, **sFID↓**, **Precision↑**, and **Recall↑** where indicated (Tables 3, 9, 10). Text-to-image generation reports **FID↓**, **CLIP score↑**, and **GenEval↑** (Table 4). NLP performance uses **perplexity (ppl↓)** on WikiText and LAMBADA, **zero-shot accuracy (%)** on commonsense reasoning benchmarks (WinoGrande, PIQA, ARC-easy, ARC-challenge, OpenBookQA, BoolQ), and **MMLU accuracy (%)** (Table 6). Long-context NLP reports per-task accuracy scores on LongBench (Table 8). Video generation reports **Quality↑**, **Semantic↑**, and **Total↑** scores on VBench, plus **latency** per sample in seconds (Table 5). Throughput is reported in **images/second** or **milliseconds** depending on context (Figure 1b, Table 7b, Table 14).

- **Baselines.** For classification (Table 2a): **Self Attention** (standard softmax attention), **Linear Attention** (vanilla kernelized linear attention, Katharopoulos et al., 2020), **Focused Linear Attention** (Han et al., 2023), **Inline Attention** (Han et al., 2024), **MALA** (Fan et al., 2025), and **RALA** (Fan et al., 2025). For classification against state-of-the-art models (Table 2b): **FL-PVT-T, FL-PVTv2-B1** (Han et al., 2023), **MSVMamba-M, MSVMamba-T** (Shi et al., 2024), **NAT-M** (Hassani et al., 2023), **RAVLT-T** (Fan et al., 2025), **MAViT-T, MAViT-S** (Fan et al., 2025), **FAT-B3** (Fan et al., 2023), **Vmamba-T** (Liu et al., 2024), and **MV-T** (Hatamizadeh and Kautz, 2025). For image generation (Table 3a): **Self Attention**, **Linear Attention**, and **GLA** (Yang et al., 2024). For NLP (Table 6): **GLA** (340M, Yang et al., 2024), **Transformer++** (340M, Touvron et al., 2023), **Mamba** (390M, Gu and Dao, 2023), **Mamba2** (340M, Dao and Gu, 2024), and **GDN** (360M, Yang et al., 2025). For video generation (Table 5): **Wan-FA** (pretrained Wan2.1-1.3B with FlashAttention), **Wan-LA** (all layers replaced with vanilla linear attention), and **Wan-MHLA-H** (2/3 of layers replaced with MHLA).

- **Generation budget / compute accounting.** The paper uses multiple compute-equivalence frameworks depending on the domain. For classification and most comparisons, models are matched on **parameter count** and **FLOPs** (Table 2a: all DeiT-T methods use ~5.7M params and ~1.1G FLOPs; Table 2b: models grouped by ~2.5G and ~4.5G FLOP tiers). For C2I generation, throughput is measured on NVIDIA H100 GPUs in **images/second** at varying resolutions (Figure 1b, Table 7b, Table 14). For video generation, latency is measured in **seconds per sample** (Table 5), with speedup factors reported relative to the FlashAttention baseline. For NLP, all models are matched at approximately **340M parameters** and trained on the same **10B tokens** of data (Section 5.4). The paper does not use a single universal compute budget across domains; rather, it ensures fair comparison within each domain by controlling model size, training data, and training steps, then measuring either accuracy-matching-FLOPs or throughput at equal accuracy.

- **Cross-validation / statistical protocol.** The paper does not employ cross-validation for strategy selection (unlike the reference example, which used two-fold CV for compute-optimal policy selection). For image generation results, the paper reports **mean ± standard deviation over three independent runs** for the comparison with LiT (Table 11) to demonstrate result stability: DiT-S/2 with MHLA achieves 59.744 ± 0.100 FID, DiT-B/2 achieves 37.519 ± 0.039, DiT-L/2 achieves 21.426 ± 0.051, and DiT-XL/2 achieves 19.164 ± 0.031. For other tables, no error bars or multiple-seed statistics are reported. The NLP models are trained once from scratch on 10B tokens each; no multiple-seed statistics are provided. Classification models are trained once for 300 epochs. This is standard practice for compute-intensive model training but means the numerical differences for close comparisons (e.g., MHLA-VLT-T at 82.6% vs. MAViT-T at 82.4% in Table 2b) should be interpreted cautiously—they may fall within single-seed variance, which is not quantified.

### Main Quantitative Results

#### Image Classification (Section 5.1)

**Headline result:** MHLA achieves the best accuracy among linear attention variants on DeiT models while introducing the fewest extra parameters. On DeiT-T, MHLA reaches **75.8% Top-1 accuracy** vs. 72.2% for self-attention and 69.8% for vanilla linear attention—a **3.6% absolute gain over self-attention** and **6.0% over linear attention**—at identical parameter count (5.7M) and FLOPs (1.1G) (Table 2a).

**Comparison within the DeiT-T tier (Table 2a):** When matched on parameters and FLOPs, the linear attention baselines span a clear performance range. Vanilla Linear Attn achieves 69.8%—substantially below self-attention's 72.2% (-2.4%). Focused LA partially recovers to 74.1% (+4.3% over linear) by adding depthwise convolutions at a cost of 0.4M extra parameters. Inline Attn pushes to 74.5% with 0.8M extra parameters. MALA reaches 75.1% with 0.6M extra parameters. MHLA reaches 75.8% **without any extra parameters** relative to self-attention—it is the only method that exceeds self-attention while maintaining parameter parity. This is significant because it demonstrates that the performance recovery comes from the attention mechanism itself, not from added capacity.

**Scaling to DeiT-S (Table 2a):** At the Small scale (22M params, 4.2G FLOPs), the pattern holds: self-attention achieves 79.8%, linear attention drops to 77.6% (-2.2%), RALA (with extra modules) recovers to 80.4% (at 24M params, 4.6G FLOPs), MALA achieves 80.3% (24M params, 4.6G FLOPs), and MHLA achieves **81.0%** at 22M params and 4.2G FLOPs—matching self-attention's parameter count and FLOPs while exceeding its accuracy by 1.2%. The gap between MHLA and the next-best augmented method (RALA at 80.4%) is 0.6 percentage points, with MHLA using 2M fewer parameters and 0.4G fewer FLOPs.

**Comparison against state-of-the-art models on VLT architecture (Table 2b):** When ported to the VLT architecture [22] at controlled compute tiers, MHLA consistently achieves best-in-class performance. At the ~2.5G FLOP tier, MHLA-VLT-T achieves **82.6% Top-1** accuracy with 16M parameters and 2.4G FLOPs, outperforming MAViT-T (82.4%, 16M/2.5G), RAVLT-T (82.3%, 15M/2.4G), and NAT-M (81.8%, 20M/2.7G). The margin over the next-best method is 0.2 percentage points at comparable compute. At the ~4.5G FLOP tier, MHLA-VLT-S achieves **84.6%** with 27M parameters and 4.6G FLOPs, outperforming MAViT-S (84.3%, 27M/4.6G), MSVMamba-T (83.0%, 32M/5.1G), and FAT-B3 (83.6%, 29M/4.4G). The margin over MAViT-S is 0.3 percentage points at identical parameter count and FLOPs.

**High-resolution classification (Table 13):** At increased resolutions, MHLA's advantage grows. On DeiT-T at 384×384, MHLA achieves 77.5% vs. self-attention's 74.4% (+3.1%). At 512×512, MHLA achieves 78.3% vs. 75.3% (+3.0%). This scaling behavior is consistent with the paper's diagnostic: as sequence length increases, linear attention's rank deficiency becomes more severe, and MHLA's rank expansion provides proportionally greater benefit.

#### Image Generation: Class-to-Image (Section 5.2)

**Headline result:** MHLA achieves a **12.6% improvement in FID** over linear attention on DiT-S/2 at 256 resolution (59.80 vs. 89.72) and matches or exceeds self-attention performance at larger model scales without auxiliary modules, while maintaining throughput nearly identical to linear attention.

**DiT-S/2 results (Table 3a, Table 10):** This is the smallest DiT scale and the setting where the paper most thoroughly ablates auxiliary modules. At 256 resolution: Self Attention achieves FID 68.40; Linear Attention degrades substantially to 89.72; MHLA with CPE and output gating achieves 59.80—beating self-attention by 8.60 FID points. The plain MHLA (no CPE, no gating) achieves 76.4 FID (Table 12)—better than linear attention's 89.72 but worse than MHLA with gating, indicating that at this small model scale, the capacity boost from gating and CPE is complementary to MHLA's structural benefits. At 512 resolution, throughput measurements (Figure 1b) show MHLA achieving FID 78.63 vs. Self Attention's 84.54, while providing **roughly double the throughput** of self-attention. The full FID/IS/sFID/Precision/Recall breakdown in Table 10 confirms MHLA's advantage across all metrics: MHLA achieves 23.49 IS (vs. self-attention's IS, unreported but implied lower), 10.16 sFID (vs. 21.87 for linear), 0.39 precision (vs. 0.28 for linear), and 0.56 recall (vs. 0.41 for linear).

**DiT-B/2 results (Table 3a):** At the Base scale (256 resolution), Self Attention achieves 43.47 FID, Linear Attention degrades to 60.47, and MHLA (no auxiliary modules mentioned at this scale) achieves **37.47**—a 23.0 point improvement over linear attention and a 6.0 point improvement over self-attention. This is notable because MHLA at this scale is reported without CPE or gating, suggesting that at moderate model sizes, MHLA's internal expressivity is sufficient.

**DiT-L/2 results (Table 3a):** This is where the scaling behavior of auxiliary modules becomes explicit. Self Attention achieves 23.33 FID. Linear Attention achieves 32.35. MHLA with no extra modules achieves 25.37—only 2.04 points behind self-attention. Adding CPE improves to 24.21. Adding both CPE and gating achieves **21.37**, exceeding self-attention by 1.96 points. The trend shows auxiliary modules providing diminishing returns (from 76.4 → 59.8 on DiT-S to 25.37 → 21.37 on DiT-L, with the "plain MHLA" gap to self-attention closing from 8.0 to 2.0 FID points).

**DiT-XL/2 results (Table 3a):** The scaling trend reaches its logical conclusion. Self Attention achieves 19.47 FID. Linear Attention achieves 28.63. **MHLA with no extra modules achieves 20.32**—only 0.85 FID points behind self-attention and effectively matching it given the ±0.031 standard deviation reported in Table 11. Adding CPE **degrades** performance to 22.79 (+2.47 over plain MHLA). Adding CPE+gating recovers to 19.17, marginally better than self-attention (-0.30). This is the paper's most compelling evidence for the claim that MHLA's structural fix is sufficient at scale: at the XL scale, plain MHLA already matches self-attention, and adding auxiliary modules can actively hurt because the attention mechanism itself is no longer the bottleneck and extra parameters simply add optimization difficulty.

**Fast adaptation results (Table 3b, Table 9):** Fine-tuning the pretrained DiT-XL/2 checkpoint for 400K steps with MHLA yields FID 8.34 vs. self-attention's 9.62 without classifier-free guidance (CFG)—MHLA **outperforms** the pretrained baseline. With CFG, MHLA achieves FID 2.54 vs. self-attention's 2.27, a marginal 0.27 FID point gap. The full metrics in Table 9 show MHLA achieves sFID 5.52 (vs. 6.85 for self-attention without CFG), indicating improved sample diversity, and precision/recall tradeoffs similar to self-attention. This fast adaptation ability—starting from a pretrained self-attention checkpoint and replacing attention layers with MHLA—demonstrates that MHLA can be retrofitted into existing models without training from scratch, a practically important property for adoption.

**DiG-S/2 results (Table 3a):** On the DiG architecture (which uses GLA as the default attention), replacing GLA with MHLA yields FID 59.49 at 256 resolution vs. GLA's 62.06—a 2.57 point improvement with no parameter increase. This demonstrates MHLA's effectiveness over another state-of-the-art linear attention variant (GLA, which uses gating) in a direct substitution.

**Comparison with LiT (Table 11):** The paper directly compares against LiT (Wang et al., 2025), a recent linear diffusion transformer, reporting mean ± std over three runs. DiT-S/2 with MHLA achieves 59.744 ± 0.100 vs. LiT-S/2 at 63.21. DiT-B/2 with MHLA: 37.519 ± 0.039 vs. LiT-B/2 at 40.86. DiT-L/2 with MHLA: 21.426 ± 0.051 vs. LiT-L/2 at 24.04. DiT-XL/2 with MHLA: 19.164 ± 0.031 vs. LiT-XL/2 at 20.66. MHLA consistently outperforms LiT across all scales with tight standard deviations, confirming that the gains are reliable and not due to random seed variation.

#### Image Generation: Text-to-Image (Section 5.2)

**Headline result:** Fine-tuning SANA-0.6B by replacing its linear attention with MHLA achieves **FID 5.90** vs. 6.10 for the baseline SANA, **CLIP score 28.26** vs. 28.15, and **GenEval 0.68** vs. 0.64 (Table 4), surpassing not only the baseline but also the PixArt-α and PixArt-Σ series.

#### Video Generation (Section 5.3)

**Headline result:** At 31,500-token sequences (81 frames at 480×800), MHLA achieves a **41% improvement in total VBench score** over vanilla linear attention (82.62 vs. 58.24), while providing a **2.1× inference speedup** over the original FlashAttention-based Wan2.1-1.3B model (81 seconds vs. 166 seconds per sample) (Table 5).

**Full model replacement results (Table 5):** The pretrained Wan-FA model (FlashAttention) achieves Quality 85.23, Semantic 75.65, Total 83.31, with 166 seconds latency. Replacing all attention layers with vanilla linear attention produces Wan-LA, which achieves Quality 69.96 (-15.27), Semantic 11.38 (-64.27), Total 58.24 (-25.07)—a catastrophic collapse, particularly on semantic measures. Replacing all layers with MHLA produces Wan-MHLA, which achieves Quality 84.26 (-0.97 from Wan-FA), Semantic 76.16 (+0.51), Total 82.62 (-0.69), with **81 seconds latency**—effectively matching the FlashAttention model's quality while cutting latency in half.

**Hybrid model results (Table 5):** Replacing only 2/3 of the attention layers with MHLA produces Wan-MHLA-H, which achieves Quality 84.87 (+0.64 vs. Wan-FA), Semantic 79.59 (+3.94), **Total 83.82 (+0.51 vs. Wan-FA)**, with 103 seconds latency—a **1.6× speedup** with **better overall performance** than the original model. This is the paper's best video generation result: the hybrid model exceeds the FlashAttention baseline in both quality and speed simultaneously.

**Training loss curves (Figure 6):** The loss curves are stark: Wan-MHLA converges similarly to Wan-Flash-Attention, its curve tracking the pretrained model's trajectory and approaching a similar final loss. Wan-Linear-Attention plateaus at a high loss (~0.7–0.8 vs. ~0.2 for the other two models), with almost no downward trend after the first few hundred steps. The paper interprets this as direct evidence of global context collapse: at N = 31,500 tokens with d ≈ 64, linear attention's rank is capped at ~64, and the information bottleneck is so severe that the model cannot learn meaningful representations regardless of training duration.

#### Throughput and Efficiency Analysis

**Throughput vs. resolution (Figure 1b):** For DiT-S/2 on H100 GPU, measured across resolutions 256→4096: MHLA's throughput curve closely tracks linear attention's curve at all resolutions, maintaining near-identical images/second. Self-attention's throughput drops sharply as resolution increases, falling well below both linear attention and MHLA at higher resolutions. At 4096 resolution, MHLA maintains 145-148 milliseconds per forward pass vs. approximately 147 for linear attention (Table 14, left)—the $M^2 d^2$ mixing overhead is empirically negligible relative to the $N d^2$ token computation.

**Throughput vs. block count (Table 7b):** On DiT-S/2 at 512 resolution (N = 1024), evaluating $M \in \{4, 16, 64\}$: M=4 achieves FID 79.56 with throughput 435 im/s; M=16 achieves FID 78.63 with throughput 435 im/s; M=64 achieves FID 79.50 with throughput 408 im/s. The optimal throughput-performance tradeoff is at M=16: it achieves the best FID while matching the highest throughput. M=64 (which exceeds the $M^2 \leq N$ threshold since $64^2 = 4096 > 1024$) shows a 6.2% throughput drop, confirming the paper's claim that the overhead becomes non-negligible when M grows beyond $\sqrt{N}$.

**Profiling across N and M (Table 14):** Detailed profiling across sequence lengths N and block counts M for DiT-S/2 (left) and DeiT-S/16 (right) shows that MHLA's overhead relative to linear attention grows with $M^2 d^2$ as predicted. For DiT-S/2 at N=4096 with M=1024 (violating $M^2 \leq N$), latency jumps to 219ms vs. 147ms for M=4, a 49% increase. At N=1024 with M=256 (also violating the constraint), latency is 61ms vs. 52ms for M=4, an 17% increase. For DeiT-S/16 at N=1024 with M=64, throughput drops to 104 im/s vs. 118 for M=16. The empirical scaling confirms the theoretical analysis: when $M^2 \leq N$, the $M^2 d^2$ term is subdominant and overhead is negligible; when $M^2 > N$, overhead becomes measurable.

**Video generation speedup (Table 5):** On Wan2.1-1.3B at 31,500 tokens: Wan-FA (FlashAttention) latency 166s; Wan-MHLA latency 81s (2.05× speedup); Wan-MHLA-H latency 103s (1.61× speedup). The speedup comes from avoiding the quadratic cost of FlashAttention on very long sequences—MHLA's $O(N d^2)$ complexity scales linearly, while FlashAttention, despite hardware optimizations, still computes $O(N^2)$ attention scores (just more efficiently).

### Ablation Studies and Robustness Checks

- **Multi-Head Mixing initialization strategy (Table 7a):** Ablated on DeiT-T with three variants: (1) uniform initialization without locality bias, (2) locality-biased initialization with frozen coefficients, (3) locality-biased initialization with learnable coefficients (full MHLA). The locality-biased initialization alone (no learning) achieves 75.4%, already 5.6 percentage points above vanilla linear attention's 69.8%. Uniform initialization with learning achieves 75.1%. Full MHLA with both locality bias and learning achieves 75.8%. The 0.4% gain from learning over static locality bias is modest but consistent. The key finding: the locality bias provides most of the benefit; learning provides incremental refinement. This implies the strong spatial prior is doing heavy lifting in vision tasks, and the learnable coefficients are fine-tuning rather than learning attention patterns from scratch.

- **Token-level head number M (Table 7b):** Ablated on DiT-S/2 at 512 resolution (N = 1024 tokens) with $M \in \{4, 16, 64\}$. M=4 achieves FID 79.56, M=16 achieves 78.63, M=64 achieves 79.50. Performance is non-monotonic: M=16 is optimal, with both fewer and more heads degrading FID. Throughput is flat at 435 im/s for M=4 and M=16, dropping to 408 im/s for M=64. This validates the paper's recommendation to choose M satisfying $M^2 \leq N$ (here, $16^2 = 256 \leq 1024$) for optimal throughput, while showing that too few heads (M=4) provides insufficient rank expansion and too many heads (M=64) introduces diminishing returns or slight degradation due to optimization difficulty.

- **CPE and output gating on DiT-S/2 (Table 12):** Ablated the effects of auxiliary modules on the smallest DiT. Linear Attention baseline: FID 89.72. MHLA with no auxiliaries: 76.4 (-13.3). MHLA + CPE: 64.0 (-12.4). MHLA + Gating: 68.5 (-7.9). MHLA + CPE + Gating: 59.8 (-8.7, -16.6 from MHLA alone, -29.9 from linear attention). Both CPE and gating provide substantial independent benefits at this small scale, and their combination is synergistic (59.8 is better than either alone). This confirms the paper's claim that auxiliary modules help when model capacity is limited, but the key finding is in the contrast with DiT-XL (Table 3a), where these same auxiliaries provide no benefit or hurt performance.

- **Scaling of auxiliary module benefits (Table 3a):** Moving from DiT-S through DiT-L to DiT-XL, the FID gap between MHLA (no auxiliaries) and MHLA (with auxiliaries) shrinks: DiT-L: gap from 25.37 to 21.37 (+4.0 from CPE+gating); DiT-XL: gap from 20.32 to 19.17 (+1.15 from CPE+gating), with CPE alone actually hurting (20.32 → 22.79). This ablation across scales—not just across configurations at a single scale—is crucial for the paper's claim that MHLA is self-sufficient at sufficient model capacity. The paper could have strengthened this by including DiT-B in the auxiliary module ablation, but the trend from S→L→XL is clear.

- **High-resolution classification robustness (Table 13):** DeiT-T with MHLA evaluated at 384×384 and 512×512 resolutions shows consistent gains over self-attention: +3.1% at 384, +3.0% at 512. This confirms that MHLA's benefits are not specific to the 224/256 training resolution and that the rank expansion becomes more valuable (not less) as sequence length increases—consistent with the theoretical analysis that relative expressivity of global linear attention degrades with N.

- **LiT comparison with standard deviations (Table 11):** Across four DiT scales (S, B, L, XL), MHLA is compared against LiT over three independent runs. Standard deviations are tight: ±0.100, ±0.039, ±0.051, ±0.031 respectively. The mean differences vs. LiT (3.47, 3.34, 2.61, 1.50 FID points) all exceed 10× the standard deviation, confirming statistical reliability. The diminishing gap with scale (from 3.47 at S to 1.50 at XL) echoes the auxiliary module scaling pattern: at larger model scales, the gap between methods narrows because the model's base capacity partially compensates for attention expressivity differences.

- **Fast adaptation with and without CFG (Table 9):** Fine-tuned DiT-XL/2 with MHLA evaluated without CFG achieves FID 8.34 (vs. self-attention 9.62), sFID 5.52 (vs. 6.85), precision 0.69 (vs. 0.67), recall 0.65 (vs. 0.67). With CFG (guidance scale not specified), MHLA achieves FID 2.54 (vs. self-attention 2.27), sFID 4.67 (vs. 4.60), precision 0.83 (tied), recall 0.56 (vs. 0.57). Without CFG, MHLA clearly outperforms self-attention; with CFG, performance is comparable with a slight FID disadvantage (-0.27). This suggests that CFG's amplification of the score function benefits self-attention's richer attention patterns slightly more than MHLA's approximation, though the difference is small.

- **MHLA on DiG architecture (Table 3a):** Replacing GLA with MHLA in DiG-S/2 at 256 resolution: MHLA achieves FID 59.49 vs. GLA's 62.06. This is an important ablation because GLA already incorporates gating—a commonly used augmentation for linear attention. MHLA without gating outperforms GLA with gating, showing that structural rank expansion provides benefits orthogonal to and exceeding those of gating mechanisms.

- **Training stability and convergence (Figures 5, 6):** The SANA-MHLA fine-tuning loss curve (Figure 5) shows smooth convergence matching the pretrained model within 2K steps and continuing to a lower final loss. The Wan2.1 training curve (Figure 6) shows Wan-MHLA tracking Wan-FA closely while Wan-LA plateaus—this is both a main result and an implicit ablation: replace MHLA with vanilla linear attention at extreme sequence length, and training fails. This confirms that the failure is attributable to the attention mechanism, not other components of the model.

- **Normalizer omission in long sequences (Section 5.3, not experimentally ablated):** The paper mentions that "the normalizer term can be omitted for better training stability when the sequence is getting longer" for language modeling and video generation, citing Qin et al. (2022). However, no ablation is provided showing MHLA performance with and without the normalizer on these tasks. The reader cannot know whether the normalizer omission is necessary for video generation training stability or merely a safe choice inherited from prior work.

- **Causal coefficient matrix ablation:** Not performed. The autoregressive formulation (Appendix C) introduces a causal coefficient matrix where entries $m_{i,b}$ for $b > i$ are masked. No ablation compares this against a non-causal MHLA variant in autoregressive settings, or against alternative ways to enforce causality. The chunkwise training approach is inherited from prior work (Sun et al., 2023; Hua et al., 2022) without modification.

- **Feature map φ choice:** Not ablated. The paper states that a "kernelized formulation" is used with a "chosen feature map φ(·)" but does not specify which feature map (likely ELU+1, the standard from Katharopoulos et al., 2020) or compare alternatives (ReLU, softmax approximations, etc.). This is a minor omission since the feature map choice is orthogonal to the block-mixing mechanism, but for practitioners implementing MHLA, knowing the specific feature map and any sensitivity to this choice would be valuable.

### Critical Assessment

The experiments are broad in domain coverage (classification, C2I generation, T2I generation, NLP, video generation) and scale (5.7M to 1.3B parameters, 256 to 31,500 tokens), providing substantial evidence that MHLA's benefits transfer across architectures and tasks. The paper's central diagnostic—global context collapse, quantified via rank and entropy—is empirically validated (Figure 3) and the architecture is shown to address both metrics. The core claims about performance gains are supported with appropriate baselines, controlled compute matching, and in one case (Table 11) explicit multi-seed statistics. However, several weaknesses and unaddressed questions temper the strength of the evidence.

**Claim: "MHLA restores query-conditioned selectivity without auxiliary modules."** The experiments demonstrate this claim with an important qualification: it holds **at sufficient model scale**. On DiT-XL/2 (Table 3a), plain MHLA (20.32 FID) matches self-attention (19.47) within the reported standard deviation (±0.031), and auxiliary modules degrade performance (CPE: 22.79). This is strong evidence. On DiT-S/2 (Table 12), plain MHLA (76.4 FID) is far from self-attention (68.40), and auxiliaries are needed to close the gap (CPE+gating: 59.80). This means the "without auxiliary modules" claim is conditional on model capacity—at small scales, auxiliaries still help. The paper is transparent about this scaling pattern, but the headline claim oversimplifies: for practitioners using small models, MHLA still benefits from CPE/gating. The video generation results (Table 5) show plain MHLA (no auxiliaries mentioned) matching FlashAttention on Wan2.1-1.3B, consistent with the scaling claim.

**Claim: "MHLA achieves a 41% improvement over vanilla linear attention in video generation."** The 41% figure compares Wan-MHLA's total score 82.62 to Wan-LA's 58.24 (Table 5). This is genuine: the ratio is 82.62/58.24 ≈ 1.42, a 42% relative improvement. However, the more relevant baseline is the original FlashAttention model Wan-FA (83.31), which MHLA slightly underperforms (-0.69). The headline 41% number is therefore framed against the weakest baseline; the more honest framing is "MHLA recovers 98.0% of FlashAttention performance at 2.1× speedup." The hybrid model Wan-MHLA-H (83.82 total, 1.6× speedup) actually outperforms FlashAttention, which is the stronger result.

**Claim: "MHLA achieves a 6.3% improvement on NLP."** This figure compares MHLA's commonsense reasoning average (47.1) to GLA's (46.0) in Table 6, yielding 47.1/46.0 ≈ 1.024—a 2.4% improvement, not 6.3%. Re-checking: the paper states "6.3% improvement on natural language processing tasks" in the abstract. If the comparison is against vanilla Linear Attention (not GLA) and the number is computed differently: the abstract says "a 6.3% gain on NLP." Looking at Table 6, all baselines except vanilla Linear Attention are shown. The 6.3% figure cannot be verified from Table 6 alone because vanilla linear attention results are not reported for the NLP experiments. This is a transparency issue: the abstract's 6.3% figure corresponds to a baseline not shown in the main NLP table. The closest comparison would be Transformer++ (46.8 CSR avg) vs. MHLA (47.1), which is 0.6% relative improvement—not 6.3%. The 6.3% may refer to perplexity or a different metric, but this is unclear. For a reader verifying the abstract's claims against the paper's tables, this discrepancy is problematic.

**Missing baselines and experiments.** (1) The NLP experiments (Tables 6, 8) do not include a vanilla linear attention baseline. The abstract and introduction claim gains over linear attention, but the NLP tables compare against GLA, Transformer++, Mamba, Mamba2, and GDN—all of which are advanced architectures. Vanilla linear attention results are absent, making the claimed improvement unverifiable in the language domain. (2) The paper does not compare MHLA against sparse attention methods (Longformer, BigBird, Sparse Transformer) in any domain, despite these being the primary alternative to linear attention for long-sequence efficiency. The Related Work (Appendix A) discusses sparse attention but no experimental comparison is provided. (3) The video generation experiments (Table 5) report VBench scores without decomposition into sub-metrics beyond Quality and Semantic; per-dimension scores would help identify where MHLA helps most (motion consistency? temporal coherence? object permanence?). The training curve (Figure 6) shows loss but not any quality metric during training, making it harder to assess when MHLA catches up to FlashAttention. (4) No experiment evaluates MHLA on tasks requiring bidirectional attention in NLP (e.g., BERT-style masked language modeling), which would test the claim that SSMs degrade in bidirectional settings—a claim made in Appendix A but never experimentally validated in this paper.

**Statistical reporting inconsistencies.** Only the LiT comparison (Table 11) reports standard deviations; all other tables report single numbers. For classification (Table 2b), the margin between MHLA-VLT-T (82.6%) and MAViT-T (82.4%) is 0.2 percentage points on a 50K-image validation set. Without standard errors, the reader cannot judge whether this difference exceeds typical training variance at a single seed. ImageNet-1K validation accuracy on 50K samples has a binomial standard error of approximately ±0.07% at 82% accuracy, so the 0.2% difference corresponds to roughly 2.8 standard errors—potentially significant, but this is not stated. For NLP, training on only 10B tokens means the 340M models are significantly undertrained (Chinchilla-optimal would be ~7B tokens), and single-seed results at this scale are particularly sensitive to initialization and data order.

**The perplexity-accuracy tradeoff in NLP (Table 6).** MHLA achieves higher perplexity (worse) on both WikiText (38.31 vs. 34.57 for Transformer++) and LAMBADA (71.64 vs. 58.51 for Mamba2) while achieving competitive or superior downstream accuracy. This pattern is notable but unexplained. It could indicate that MHLA's sparser attention (lower entropy) helps for tasks requiring precise retrieval but hurts for dense next-token prediction. Alternatively, it could indicate an optimization issue—MHLA might require different hyperparameters or longer training to reach comparable perplexity, and the 10B-token budget was insufficient. Without a training curve showing perplexity over steps, the reader cannot distinguish these explanations. This is a genuine limitation: if MHLA requires more training tokens to match perplexity, the reported 10B-token comparison may understate MHLA's downstream potential while overstating its efficiency (since catching up on perplexity would consume additional compute).

**The $M^2 \leq N$ constraint is empirical, not theoretically required.** The paper states that M is "usually set to satisfy $M^2 \leq N$" to keep complexity $O(N d^2)$. However, for very long sequences (video at N = 31,500), satisfying $M^2 \leq 31,500$ requires M ≤ 177, which is loose—the paper uses M = 105 for video. The question is whether even larger M would help. The rank bound for MHLA is $\sum_b \min(N_b, d)$, which increases with M until $N_b < d$, at which point adding more blocks does not increase the bound. For N = 31,500 and d = 64, the optimal M to maximize the bound is approximately N/d = 492, far exceeding the $\sqrt{N} \approx 177$ constraint. An experiment exploring whether M larger than $\sqrt{N}$ improves accuracy at the cost of throughput would clarify whether the $\sqrt{N}$ heuristic is a computational convenience or a genuine performance optimum.

**Domain generality vs. domain-specific tuning.** The paper uses different M values for different tasks: M = 16 for DeiT (classification), M = 16 for DiT at 256/512 resolution (C2I generation), M = 105 for video (N = 31,500), M = 32 for NLP (context length 2048). These choices appear to follow $M \approx \sqrt{N}$ (M = 16 for N=1024; M = 32 for N=2048; M = 105 for N=31,500, where $\sqrt{31500} \approx 177$, close to 105). However, the optimal M was only ablated for DiT-S/2 (Table 7b), not for classification, NLP, or video. The reader cannot know whether M = 32 is genuinely optimal for NLP or simply a reasonable default. This matters because the rank expansion depends on M, and suboptimal M would underestimate MHLA's potential in those domains.

**Video generation: does the 2.1× speedup account for the FLOPs of MHLA's mixing?** The latency measurements in Table 5 (81s for Wan-MHLA vs. 166s for Wan-FA) are end-to-end generation times. The paper should confirm, but does not explicitly state, whether these measurements include all MHLA overhead (the $M^2 d^2$ mixing step, the chunkwise causal masking, the maintaining of per-block summaries). The throughput measurements in Figure 1b and Table 14 for image generation do account for this, and they show negligible overhead at $M^2 \leq N$—suggesting the video latency similarly includes all overhead. However, an explicit statement in Section 5.3 would be reassuring.

**Strengths that deserve acknowledgment.** Despite these criticisms, the experimental section has genuine strengths. The breadth of evaluation—four domains, multiple model scales per domain, controlled FLOP-matched comparison within each domain—is unusual for an architecture paper and significantly strengthens the generality claim. The scaling analysis of auxiliary modules (auxiliaries help at small scale, hurt at large scale) is a non-obvious and practically important finding that would not be visible from single-scale experiments. The video generation result at N = 31,500 tokens, showing that vanilla linear attention effectively fails to train while MHLA succeeds, is a striking demonstration that the diagnosed pathology (global context collapse) has catastrophic real-world consequences at sufficient scale—not just incremental accuracy differences. The dual metric framework (rank + entropy, Figure 3) provides interpretable validation that MHLA's mechanism works as intended, connecting theory to measurement. The fast adaptation experiments (DiT-XL/2 fine-tuning, SANA fine-tuning) demonstrate practical deployability—MHLA can be retrofitted into existing pretrained models, which is essential for adoption.

## 6. Limitations and Trade-offs

### The Difficulty Estimation Cost Is Unaccounted For — And It's Larger Than the Inference Budget

**The assumption and its consequence.** MHLA's block structure introduces a hyperparameter—the number of token-level heads $M$—that controls the expressivity-efficiency tradeoff. The paper determines $M$ empirically per task: $M = 16$ for DeiT and DiT at 256/512 resolution, $M = 32$ for NLP with context length 2048, $M = 105$ for video generation at $N = 31,500$ tokens. The paper also recommends the constraint $M^2 \leq N$ to keep the $M^2 d^2$ mixing term subdominant to the $N d^2$ token computation (Section 4.3, Table 1). However, **no method is provided for selecting $M$ a priori**—the paper sweeps values for DiT-S/2 (Table 7b: $M \in \{4, 16, 64\}$) to find the optimum, but treats $M$ as a fixed hyperparameter for all other experiments without reporting whether these values were selected through similar sweeps or chosen heuristically.

The consequence: a practitioner deploying MHLA on a new task with a different sequence length or architecture must either (a) run their own $M$-sweep experiments, which adds a potentially substantial hyperparameter search cost not accounted for in any efficiency or accuracy comparison, or (b) guess $M \approx \sqrt{N}$ and hope this heuristic transfers. The paper provides no evidence that $\sqrt{N}$ is universally optimal—only that $M = 16$ is best among $\{4, 16, 64\}$ for $N = 1024$ (DiT-S/2, 512px), where $\sqrt{1024} = 32$. The optimum ($M = 16$) is notably not $\sqrt{N}$—it is $\sqrt{N}/2$. For longer sequences, the gap between the $\sqrt{N}$ heuristic and the true optimum could widen, and the cost of finding the optimum grows with sequence length and model size.

**Evidence in the paper.** The only $M$ ablation is Table 7b for DiT-S/2 at 512 resolution. No $M$ ablation exists for classification (Table 2), NLP (Tables 6, 8), or video generation (Table 5). The paper states $M$ is "usually set to satisfy $M^2 \leq N$" (Section 4.3) and that "MHLA can reach best performance with a relatively small M" (Section 5.5), but provides no guidance beyond these qualitative statements. The scaling analysis in Appendix F.4 (Table 14) measures throughput at various $(N, M)$ pairs but does not measure accuracy at those pairs—it is a pure efficiency profile, not a performance profile.

**Mitigation status.** Not addressed. Section 6 (Conclusion) does not mention the $M$ selection problem. The paper frames $M$ as an architecture design choice analogous to the number of attention heads in standard Transformers, but standard multi-head attention's head count primarily affects per-head dimension ($d_h = d / h$) and is typically set by convention (e.g., 8 or 12 heads) rather than requiring per-task optimization. MHLA's $M$ additionally controls sequence partitioning and the rank bound, making it a more consequential hyperparameter whose optimal value depends on sequence length, feature dimension, and task structure. The paper does not propose an automatic $M$-selection method, a theoretical optimal $M$ formula, or even a rule of thumb beyond $\sqrt{N}$ (which the one available ablation does not confirm as optimal).

---

### The Perplexity-Accuracy Tradeoff in Language Modeling Is Unexplained and Potentially Limiting

**The constraint and its consequence.** On the 340M-parameter NLP model trained on 10B tokens, MHLA achieves higher (worse) perplexity than Transformer++ and Mamba2 on both WikiText (38.31 vs. 34.57 and 35.40) and LAMBADA (71.64 vs. 60.46 and 58.51), while simultaneously achieving competitive or superior downstream task accuracy (Table 6). This pattern—worse language modeling loss but better or comparable downstream performance—is unusual and unexplained.

The practical consequence is ambiguous. If MHLA genuinely underperforms on next-token prediction density estimation, it will be a worse base model for pretraining, even if downstream fine-tuning recovers the gap. Language modeling perplexity is correlated with emergent capabilities and is the primary optimization objective during pretraining; a method that degrades this objective while improving downstream metrics may be overfitting to the downstream evaluation or exploiting a beneficial inductive bias that does not generalize to other tasks. Conversely, if the perplexity gap is an artifact of insufficient training (10B tokens is well below Chinchilla-optimal for a 340M model, which would require ~7B tokens), then training longer might close the gap—but this is not demonstrated. A practitioner choosing between MHLA and Mamba2 for a language model pretraining run cannot know from this paper whether MHLA's perplexity deficit is fundamental (MHLA's sparser attention discards information needed for dense next-token prediction) or transient (MHLA converges slower but would catch up with more training).

**Evidence in the paper.** Table 6 reports perplexity alongside accuracy. The CSR average favors MHLA (47.1 vs. 46.0–47.0 for baselines), but WikiText ppl is 38.31 vs. 34.57–38.32, and LAMBADA ppl is 71.64 vs. 58.51–62.43. No training curve for perplexity is shown, so the reader cannot see whether MHLA's perplexity is still improving at 10B tokens or has plateaued. No ablation varies training duration to test whether the gap closes with more tokens. The long-context results (Table 8) show MHLA achieving the highest LongBench average (7.41), further reinforcing the pattern: MHLA appears strong on tasks requiring selective context retrieval (summarization, QA) but weaker on dense next-token prediction.

**Mitigation status.** Not addressed. The paper does not discuss the perplexity-accuracy discrepancy anywhere in the main text, Section 5.4, or Appendix. The NLP experiments are framed as demonstrating MHLA's competitiveness ("MHLA shows a comparable performance with Transformer++ and the state-of-the-art linear models"), which is true for downstream accuracy but misleading for perplexity. A reader focused on pretraining language models would find the omission significant—perplexity is the training objective, and a 10–20% degradation is substantial.

### Block Definition on Spatial Grids Limits Application to Non-Euclidean or Irregular Token Sequences

**The assumption and its consequence.** MHLA partitions tokens into blocks along spatial (2D) or spatiotemporal (3D) grids. The paper explicitly states: "In practice on vision models, blocks are defined on spatial (2D) or spatiotemporal (3D) grids rather than by flattening to 1D" (Section 4.1). The locality-biased initialization (Section 4.2) uses Euclidean distance between block centers, assuming a regular grid geometry. This design couples MHLA's effectiveness to the existence of a meaningful spatial structure in the token layout.

For vision tasks (images, videos), this assumption holds naturally—tokens correspond to image patches arranged on a 2D grid, and spatial proximity strongly correlates with semantic relevance. For language tasks, the assumption is more tenuous. Language tokens are arranged in a 1D sequence where position encodes word order, not spatial proximity. The paper applies MHLA to NLP (Section 5.4) with $M = 32$ at context length 2048, but does not describe how blocks are defined for 1D text sequences (presumably by splitting the 1D sequence into contiguous segments). The locality-biased initialization, which uses Euclidean distance in 2D space, does not naturally transfer to 1D sequences—what does "spatial proximity" mean for text tokens? The paper does not specify whether the NLP experiments use the same locality-biased initialization, a modified 1D version, or uniform initialization.

The consequence: MHLA's benefits may be primarily attributable to spatial structure in vision data rather than the general mixing mechanism. If the 2D spatial prior is doing substantial work (as the ablation in Table 7a suggests—locality-biased initialization alone achieves 75.4% vs. 75.8% with learning, a 0.4% gap), then applying MHLA to domains without grid-structured tokens (speech, point clouds, molecular graphs, code with irregular AST structures) may not reproduce the vision results. The paper's claim of universality (Section 6: "a fundamental attention mechanism that can benefit a wide range of downstream applications") would overstate the evidence if the mechanism's effectiveness depends on a spatial prior that only some domains provide.

**Evidence in the paper.** The NLP results (Tables 6, 8) show competitive but not dominant performance—MHLA's gains over baselines are smaller in NLP than in vision. The 6.3% improvement claimed in the abstract for NLP cannot be verified against the paper's own tables (as noted in Section 5). The paper does not report whether the NLP experiments used spatial grid blocking (which is nonsensical for 1D text) or 1D sequential blocking, making the NLP setup ambiguous. No experiment evaluates MHLA on a non-grid-structured task (e.g., processing point clouds, working with graph-structured inputs, or modeling tabular data).

**Mitigation status.** Not addressed. The paper does not discuss the spatial grid assumption or its implications for domain transfer. Section 4.1's description of blocking is vision-centric, and the NLP section does not clarify how blocking was adapted. The locality-biased initialization is described in terms of "Euclidean distance" and visualized for a 2D grid (Figure 4b); no 1D analogue is shown. A reader seeking to apply MHLA to non-vision domains is left without guidance on how to define blocks or initialize the coefficient matrix.

### No Comparison Against Sparse Attention — The Primary Alternative for Long-Sequence Efficiency

**The assumption and its consequence.** The paper positions MHLA in the landscape of efficient attention mechanisms, discussing sparse attention in the Related Work (Appendix A) and noting that sparse methods "introduce trade-offs in terms of accuracy, especially in tasks requiring full token interactions." However, **no experimental comparison against any sparse attention method is provided** in any domain. Baselines are limited to linear attention variants (GLA, Focused LA, MALA, RALA), state-space models (Mamba, Mamba2, GDN), and standard self-attention.

The consequence: the paper's central claim—that MHLA achieves "the expressivity of full softmax attention with the linear complexity of linear attention"—is evaluated only against other methods that share linear attention's kernelized compression paradigm. Sparse attention methods (Longformer, BigBird, Sparse Transformer) achieve sub-quadratic complexity via a different mechanism: restricting which token pairs can interact based on hand-designed or learned sparsity patterns. For many long-sequence tasks, the relevant engineering decision is not "kernelized linear attention vs. MHLA" but "linear attention vs. sparse attention vs. a hybrid." A practitioner choosing an efficient Transformer variant for, say, long-document NLP or high-resolution image processing would want to know whether MHLA outperforms sparse attention at comparable compute budgets—and this paper provides no evidence either way.

The omission is particularly relevant for video generation, where the paper's strongest result (2.1× speedup, near-parity with FlashAttention) is measured against the FlashAttention baseline. A sparse attention method that restricts each token to a local spatiotemporal window plus global tokens could also achieve substantial speedups with potentially different accuracy tradeoffs. Without this comparison, the reader cannot assess whether MHLA is genuinely the best choice or simply better than other kernelized methods.

**Evidence in the paper.** None. No sparse attention baseline appears in any of Tables 2–8. The Related Work (Appendix A) recognizes sparse attention as an alternative approach but relegates it to a literature review without experimental engagement. The paper's experiments demonstrate MHLA's superiority over *linear* attention variants, but the framing often elides the distinction: "state-of-the-art performance on both discriminative and generative tasks" (Section 1) is true within the linear attention family, not necessarily across all efficient attention methods.

**Mitigation status.** Not addressed. The paper does not claim experimental comparison with sparse attention, so this is an omission rather than a misleading claim. However, the abstract and conclusion frame the contribution broadly ("a fundamental attention mechanism") without qualifying that the evaluation is restricted to linear and recurrent attention variants. Adding even one sparse attention baseline (e.g., sliding-window attention, which is simple to implement and widely used) on image classification or language modeling would substantially strengthen the paper's generality argument.

### The Rank Bound Improvement Depends on Independence Assumptions That Are Not Empirically Verified

**The assumption and its consequence.** The paper's theoretical analysis (Section 4.3) proves that MHLA's attention matrix rank is bounded by $\min(N, \sum_{b=1}^M \min(N_b, d))$, and claims that this bound is **attainable** under "mild, generic conditions: if each block product $\tilde{Q}_b Y_b$ has full row rank $r_b = \min(N_b, d)$ and the row spaces of $\{\tilde{Q}_b Y_b\}_{b=1}^M$ are linearly independent" (Section 4.3). The paper then reports empirical rank measurements (Figure 3b: MHLA rank ≈ 233 vs. linear attention ≈ 58) as validation that the mechanism works as intended.

However, the gap between the **achievable** bound (attainable under ideal conditions) and the **empirically realized** rank matters for understanding how much headroom remains. For the DeiT-T configuration used in Figure 3b, with typical parameters (sequence length, feature dimension, block count), the theoretical bound can be computed. If $N = 256$ (typical for DeiT-T with 16×16 patches) and $d = 64$ and $M = 16$ with equal block sizes $N_b = 16$, the bound is $\min(256, 16 \times 16) = 256$. The empirical rank of 233 is 91% of the bound—close but not saturated. The paper does not report whether this gap is due to the independence assumption being partially violated (some row spaces overlapping) or due to optimization failing to fully utilize the available capacity. If the former, stacking more blocks would yield diminishing returns as row spaces increasingly overlap; if the latter, better training recipes might close the gap.

The consequence: a practitioner reading the rank analysis might conclude that increasing $M$ will increase effective rank proportionally, but the paper provides no evidence that rank scales linearly with $M$ in practice. The single $M$ ablation (Table 7b) measures FID, not rank—the reader cannot know whether $M = 64$ produced higher attention matrix rank than $M = 16$ even though FID was slightly worse. The theoretical bound is an upper limit; the empirical scaling of realized rank with $M$ is unmeasured.

**Evidence in the paper.** Figure 3b reports rank for exactly one configuration (DeiT-T—model scale and M value specified in the caption or appendix, though the exact M is not stated in the main Figure 3 caption). No rank measurements are provided at different M values or sequence lengths, so the scaling behavior of realized rank cannot be assessed. The attention score visualizations (Figure 3a) are qualitative and from a single example.

**Mitigation status.** Not addressed. The paper treats the empirical rank measurement (Figure 3b) as confirmation of the theoretical analysis and does not investigate the gap between theoretical bound and realized rank. A more thorough analysis would measure rank at multiple M values and sequence lengths to empirically validate the additive scaling predicted by the theory. No future work is proposed on analyzing or closing the rank gap.

### Single-Seed Training for Large-Scale Experiments Limits Statistical Reliability

**The constraint and its consequence.** With the exception of the LiT comparison (Table 11), which reports mean ± standard deviation over three runs for DiT image generation, **all other experimental results are reported from single training runs**—classification models (Tables 2a, 2b), NLP models (Tables 6, 8), video generation models (Table 5), and most image generation results (Tables 3a, 3b, 4). Single-seed results conflate method performance with training variance, making it impossible to determine whether small differences between methods are reliable.

This affects several key comparisons. On classification (Table 2b), MHLA-VLT-T achieves 82.6% vs. MAViT-T at 82.4%—a 0.2 percentage point margin. Without standard errors, the reader cannot assess whether this difference is statistically meaningful or within single-seed noise. On ImageNet-1K validation (50K samples), the binomial standard error at ~82% accuracy is approximately ±0.17%, so 0.2% corresponds to roughly 1.2 standard errors—suggestive but not conclusive. On NLP (Table 6), MHLA achieves MMLU 23.7 vs. Mamba at 23.5—a 0.2 point margin on a benchmark where training variance for 340M models on 10B tokens is unknown. The paper's headline claim that MHLA achieves the highest MMLU would be undermined if repeat runs showed overlapping distributions.

The consequence is most acute for the NLP experiments, where models are trained on only 10B tokens—well below the Chinchilla-optimal ~7B tokens for a 340M model. Small-model, limited-data training runs are known to have high variance across seeds due to sensitivity to initialization, data order, and optimization noise. Single-seed results at this scale provide weak evidence for method ranking.

**Evidence in the paper.** The paper recognizes this issue for the LiT comparison (Table 11), providing three-run statistics. The introduction of multi-seed reporting in exactly one table—and its absence from all other tables—suggests the authors were aware of variance concerns but did not apply the same standard uniformly, likely due to computational cost (training DiT-XL/2 multiple times is expensive). The paper does not state why only the LiT comparison received multi-seed treatment.

**Mitigation status.** Partially addressed for one comparison (Table 11), not addressed for the rest. The Conclusion (Section 6) does not acknowledge single-seed limitations. In fairness, single-seed reporting is standard practice for compute-intensive experiments (training 1.3B video models, 340M language models from scratch), and the paper's breadth of evaluation partially compensates—consistent gains across four domains are less likely to be pure noise than gains in a single domain. However, for close comparisons within a domain (classification margins of 0.2–0.3%, NLP MMLU margins of 0.2–0.4 points), the absence of variance estimates means these rankings should be treated as suggestive rather than definitive.

## 7. Implications and Future Directions

### How This Work Changes the Landscape

This paper does not introduce a fundamentally new computational primitive—it still does attention, still uses kernelized feature maps, still operates at $O(N d^2)$ complexity. What it changes is **how the field diagnoses and addresses expressivity failures in efficient attention mechanisms.** The shift is from "linear attention is less powerful, so let's add capacity" to "linear attention suffers a specific, measurable structural bottleneck, and fixing *that* restores expressivity." This is a diagnostic reframing, not a paradigm shift, but it is a reframing with practical teeth: it explains *why* prior augmentations saw diminishing returns and *predicts* where linear attention will fail entirely.

**The rank-and-entropy diagnostic framework is the most transferable contribution.** Before this paper, if a linear attention variant underperformed on some task, the default explanation was "the kernel approximation loses information" or "softmax nonlinearity matters." These explanations are vague and do not point toward solutions. The paper's identification of $\text{rank}(A_{\text{lin}}) \leq d$—a hard, provable ceiling—as *the* limiting factor changes the conversation. It tells researchers: if you want to improve linear attention, you must expand the effective rank of the attention computation. Convolutions, gating, and SSM hybrids may improve feature quality, but they do not lift the rank ceiling—and at sufficient sequence length, that ceiling becomes catastrophic, as the video generation experiments (Wan-LA at 58.24 total score vs. Wan-FA at 83.31 at $N = 31,500$, Table 5) demonstrate. Future work on efficient attention can now be evaluated through this lens: does a proposed method increase the rank bound, or does it just add capacity within the same bound?

This reframing also makes certain research directions less attractive. **Methods that treat linear attention as a black-box building block and attempt to compensate for its weaknesses through external modules are now revealed as fundamentally limited.** The paper's scaling analysis of auxiliary modules—CPE and gating help at DiT-S scale (FID 59.8 with, 76.4 without; Table 12) but hurt at DiT-XL scale (FID 22.79 with CPE, 20.32 without; Table 3a)—shows that the returns from external capacity diminish as the base model grows, because the bottleneck is structural, not capacity-related. This implies that the research program of augmenting linear attention with convolutions, gating, or hybrid attention layers (which has been dominant since Focused Linear Attention, Han et al., 2023) may be approaching a point of diminishing returns. The more promising direction is **structural modifications to the attention mechanism itself that lift the rank ceiling—exactly what MHLA does via block partitioning and learned inter-block mixing.**

**The paper reconciles a latent contradiction in the efficient attention literature.** On one side, linear attention advocates claimed that kernelized approximations could match softmax attention with sufficient augmentation. On the other side, practitioners working with long sequences (video generation, long-document NLP) found that linear attention models simply did not train well at scale, regardless of augmentation. The global context collapse diagnosis resolves this: at modest sequence lengths ($N \approx 256$–$1024$), the rank ceiling $d \approx 64$ is not severely limiting—it still provides 6–25% of the theoretically available degrees of freedom—so augmentations can compensate. At extreme sequence lengths ($N \approx 31,500$), the ceiling is 0.2% of available degrees of freedom, and no amount of auxiliary capacity can recover the lost information. This explains why different papers (testing on different sequence lengths) reached opposite conclusions about linear attention's viability. The diagnostic framework tells us *when* linear attention will work (short-to-medium sequences) and *when* it will fail (very long sequences), turning a contradiction into a boundary condition.

**The "attention rank as design objective" framing is methodologically significant.** Prior work used rank as a *post-hoc* diagnostic of limitations in existing architectures (Bhojanapalli et al., 2020). This paper goes further: it **designs an architecture to maximize rank under a complexity constraint**, then verifies that the realized rank matches the theoretical prediction (Figure 3b: theoretical bound $> 64$, empirical rank $\approx 233$). This inverts the typical relationship between theory and architecture design—theory leads, architecture follows, and metrics validate. Future efficient attention proposals can (and arguably should) adopt the same framework: state the theoretical rank bound of the proposed mechanism, show that it lifts the ceiling relative to global linear attention, and verify empirically that realized rank scales as predicted. This is a higher standard of evidence than "our method achieves X% on benchmark Y," and it provides explanatory power for *why* gains occur.

### Follow-Up Research This Work Enables

**Directly measuring the causal impact of attention rank on downstream task performance.** The paper shows a correlation between rank expansion and accuracy improvement (Figure 3b: rank 58→233, entropy 5.12→4.06, classification accuracy 69.8%→75.8% for DeiT-T), but correlation is not causation. A targeted experiment would manipulate the effective rank of MHLA's attention matrix while holding all other model properties constant—for example, by constraining the coefficient matrix $M_c$ to have reduced rank (via a low-rank factorization $M_c = U V^\top$ with varying intermediate dimension $r$) or by freezing selected blocks to share the same mixture weights. If downstream accuracy degrades monotonically with constrained rank, that establishes the causal link. If accuracy plateaus above some rank threshold, that identifies the "sufficient rank" for a given task and sequence length—a practically useful finding. The paper's theoretical analysis (Section 4.3) provides the formula $\sum_b \min(N_b, d)$ for the bound; a controlled experiment could test whether realized rank tracks this formula as $N_b$, $d$, and $M$ vary.

**Training a verifier-free difficulty estimator for block count selection.** The paper's most significant deployment obstacle is the need to choose $M$ per task. The $\sqrt{N}$ heuristic is convenient but was not confirmed as optimal—the one ablation (Table 7b) found $M = 16$ optimal for $N = 1024$, not $\sqrt{1024} = 32$. A specific follow-up project would train a lightweight predictor that maps sequence statistics ($N$, $d$, task type) to an estimated optimal $M$, using the paper's existing $M$-sweep data as training labels. The predictor could be as simple as a linear regression on log-transformed features or as sophisticated as a small neural network trained on meta-learning data from multiple tasks. The training data would come from running $M$-sweeps on a diverse set of sequence lengths and model sizes—exactly the kind of experiment the paper performed for DiT-S/2 (Table 7b) but only at one scale. If the predictor generalizes to held-out tasks, it solves the $M$-selection problem; if it fails, that reveals that $M$ depends on task-specific semantic properties (e.g., spatial coherence in images, syntactic structure in text) that sequence statistics alone cannot capture—an informative negative result.

**Stress-testing MHLA on tasks where the spatial prior is invalid or misleading.** The paper's strongest results are on vision tasks where spatial blocking and locality-biased initialization encode a genuine inductive bias (nearby patches are semantically related). An important follow-up would apply MHLA to a task where the natural token ordering does not correspond to a Euclidean grid with locality structure: code generation with abstract syntax tree structure, protein sequence modeling (where 1D proximity is weaker than 3D contact map proximity), or tabular data with permuted column orders. If MHLA with spatial-grid blocking performs worse than global linear attention in these settings, that would reveal that the spatial prior—not the mixing mechanism—is the primary driver of MHLA's gains, significantly narrowing the claimed scope of the method. If MHLA can be adapted (e.g., by learning an optimal token permutation to induce a favorable block structure, or by replacing Euclidean-distance initialization with a task-specific similarity metric) and still outperforms baselines, that would strengthen the universality claim. Either outcome is scientifically valuable.

**Combining MHLA with learned sparsity patterns for dual rank-and-sparsity expansion.** MHLA's block-level mixing provides coarse spatial selectivity (which blocks are relevant); within-block, the mechanism still computes dense attention via kernelized inner products. A natural extension would replace within-block linear attention with a sparse attention pattern—for example, each token in a block attends to a learned subset of tokens within the same block, rather than all tokens. This would combine MHLA's block-level rank expansion (from inter-block mixing) with token-level sparsity (from within-block pruning), potentially achieving both higher rank and lower entropy than either method alone. The paper's sparsity analysis (Figure 3b: MHLA entropy 4.06 vs. softmax 4.13) already shows MHLA produces sharper distributions; adding learned sparsity could push this further, particularly for very long sequences where even within-block dense attention becomes a bottleneck (e.g., video at $N = 31,500$ with $N_b = 300$ tokens per block—300 token comparisons per query per block is still non-trivial). The experiment would compare MHLA variants with dense, sliding-window, and learned-sparse within-block attention on video generation and long-context NLP.

**Measuring the scaling of realized rank with $M$, $N$, and $d$ to validate the theoretical bound empirically.** The paper's theoretical rank bound (Section 4.3) is stated as $\min(N, \sum_b \min(N_b, d))$, with a claim that it is attainable under mild conditions. The empirical rank is measured at exactly one configuration (Figure 3b, presumably DeiT-T with some $M$). A systematic study would measure the realized attention matrix rank for MHLA models across a grid of $M \in \{4, 8, 16, 32, 64\}$, $N \in \{256, 512, 1024, 2048, 4096\}$, and $d \in \{32, 64, 128\}$, and compare the measured rank to the theoretical bound. This would answer: (a) how close does realized rank get to the bound in practice? (b) does rank grow additively with $M$ as predicted, or does it saturate due to row space overlap? (c) at what $M$ does the rank improvement from additional blocks become negligible (the "effective rank saturation point")? The paper already provides throughput profiling at various $(N, M)$ pairs (Table 14); adding accuracy and rank measurements at the same grid points is a straightforward extension.

**Testing whether MHLA's mixing coefficients recover interpretable attention patterns.** The learned coefficient matrix $M_c$ determines which spatial blocks each query block attends to. For vision tasks with known spatial structure (e.g., objects in images, motion trajectories in video), one could visualize the learned coefficients and check whether they correspond to interpretable attention patterns—do blocks containing object parts attend more to other blocks containing the same object? Do blocks on motion boundaries attend along the direction of motion in video? If the coefficients are interpretably structured, this suggests MHLA is learning genuine spatial attention, not just a distributed capacity boost. If they are diffuse and unstructured despite good downstream performance, it suggests the mechanism works primarily through rank expansion (providing more degrees of freedom for the model to use as it sees fit) rather than through inducing meaningful spatial selectivity—still valuable, but a different mechanism than the paper's "query-conditioned selectivity" framing implies. Either finding would refine our understanding of *how* MHLA achieves its gains.

**A thorough training-budget ablation for the NLP perplexity-accuracy discrepancy.** The paper's 340M-parameter NLP model trained on 10B tokens shows MHLA achieving worse perplexity but better downstream accuracy than Transformer++ and Mamba2 (Table 6: WikiText ppl 38.31 vs. 34.57, CSR avg 47.1 vs. 46.8). A straightforward follow-up would train MHLA, Transformer++, and Mamba2 models at multiple token budgets (e.g., 1B, 5B, 10B, 25B, 50B tokens) and plot both perplexity and downstream accuracy as a function of training tokens. If the perplexity gap closes with more training, MHLA's disadvantage is transient—it simply converges slower but would match or exceed baselines given sufficient compute. If the gap persists, MHLA genuinely sacrifices some next-token prediction fidelity for improved selective retrieval, which would make it a specialized architecture for tasks requiring focused attention (QA, summarization, retrieval-augmented generation) rather than a general-purpose language model backbone. This experiment directly addresses the most significant unexplained result in the paper and would substantially clarify MHLA's role in the NLP ecosystem.

### Practical Applications and Downstream Use Cases

**High-resolution image and video generation at reduced inference cost.** The paper's video generation results (Table 5) are the most immediately actionable: replacing FlashAttention with MHLA in Wan2.1-1.3B yields a 2.1× inference speedup (81s vs. 166s per sample) while recovering 98% of the original model's quality (Total score 82.62 vs. 83.31). The hybrid variant (replacing only 2/3 of layers) achieves a 1.6× speedup with *better* quality (83.82 vs. 83.31). For video generation services where inference cost dominates—generating a single high-quality video clip can require minutes on expensive GPU instances—a 1.6–2.1× speedup translates directly to serving more users per GPU-hour or reducing user-facing latency. The paper's SANA-MHLA fine-tuning result (Table 4: 40K steps to surpass the pretrained baseline) shows that MHLA can be retrofitted into existing production models without training from scratch, lowering the barrier to deployment. The practical recipe: take a pretrained diffusion transformer with self-attention or linear attention, fine-tune with MHLA for a fraction of the original training budget, and deploy with the hybrid configuration that balances speed and quality for the target resolution and frame count.

**On-device or edge deployment of vision transformers for classification and detection.** For image classification at resolutions above the standard 224×224, MHLA's throughput advantage over self-attention grows with sequence length (Figure 1b). At 512×512 resolution on DiT-S/2, MHLA achieves FID 78.63 vs. self-attention's 84.54 while providing roughly double the throughput. For a mobile device running a vision transformer at high resolution—for document scanning, medical image analysis, or augmented reality—this translates to either faster inference at equal accuracy or higher accuracy within a latency budget. The DeiT-T results at 512×512 (Table 13: MHLA 78.3% vs. self-attention 75.3%) show the accuracy benefit directly. Since MHLA adds no extra parameters relative to self-attention (Table 2a: both use 5.7M parameters at DeiT-T scale), it can be deployed as a drop-in replacement with no increase in memory footprint—important for memory-constrained edge devices. The GEMM-only implementation (Section 4.3) means MHLA runs efficiently on commodity mobile GPU hardware via standard libraries (e.g., Core ML, TensorFlow Lite) without custom kernels.

**Cost-efficient batch inference for long-document NLP.** The paper's LongBench results (Table 8) show MHLA achieving the highest average score (7.41 vs. 6.62–6.97 for baselines) at 340M scale trained on 10B tokens, with particular strength on summarization and code understanding tasks. For organizations running batch inference over large document collections—summarizing legal documents, analyzing code repositories, extracting structured information from scientific papers—replacing self-attention or FlashAttention with MHLA could substantially reduce compute cost per document while maintaining or improving extraction quality. The $O(N d^2)$ complexity means cost scales linearly with document length rather than quadratically, which is transformative for processing very long documents (10K+ tokens) where self-attention becomes prohibitively expensive. The caveat is the perplexity gap (Table 6): if the batch task requires high-fidelity language modeling (e.g., perplexity-based filtering) rather than selective extraction, MHLA may underperform.

**Fine-tuning pretrained models with MHLA for domain-specific long-sequence tasks.** The fast adaptation results—DiT-XL/2 fine-tuned for 400K steps achieving FID 8.34 vs. baseline 9.62 without CFG (Table 3b), SANA-0.6B fine-tuned for 40K steps surpassing the baseline (Table 4, Figure 5)—establish a practical workflow that does not require training from scratch. A practitioner with a pretrained self-attention or linear attention model for a long-sequence task (satellite imagery time series, genomic sequence modeling, long-form video understanding) can replace the attention layers with MHLA, fine-tune for a fraction of the original training budget, and expect the model to rapidly adapt—matching the baseline within the first few thousand steps and continuing to a lower final loss (Figures 5, 6). This "fine-tune to upgrade" pattern lowers the adoption barrier compared to methods requiring full retraining, which for large models (DiT-XL/2, Wan2.1-1.3B) is computationally prohibitive for most users.

### When to Prefer This Method

The paper does articulate a clear tradeoff against alternatives, grounded in the scaling behavior of auxiliary modules (CPE, gating) across model sizes and the failure of vanilla linear attention at extreme sequence lengths. The decision rule is:

- **Prefer plain MHLA (no auxiliary modules) when:** The model scale is large enough that the attention mechanism itself is expressive enough to saturate task performance, and sequence length is large enough that standard linear attention's rank ceiling becomes a bottleneck. This is the DiT-XL/2 scenario (Table 3a: plain MHLA achieves FID 20.32, matching self-attention's 19.47, while adding CPE degrades performance to 22.79) and the Wan2.1-1.3B scenario (Table 5: plain MHLA achieves 82.62 total score, recovering 98% of FlashAttention performance). The practical indicator: if your model is already at a scale where expressive capacity is not the primary limitation, MHLA's structural fix is sufficient and auxiliary modules are unnecessary at best, harmful at worst.

- **Prefer MHLA with auxiliary modules (CPE, gating) when:** The model scale is small-to-medium and the additional capacity from auxiliary modules complements MHLA's structural rank expansion. This is the DiT-S/2 scenario (Table 12: MHLA alone achieves FID 76.4, adding CPE+gating reaches 59.8) and DiT-L/2 scenario (Table 3a: MHLA alone achieves 25.37, adding CPE+gating reaches 21.37). The practical indicator: if your model's parameter count or FLOP budget is constrained, the auxiliary modules provide capacity that MHLA alone cannot supply, and the combination is synergistic.

- **Prefer a hybrid MHLA configuration (mixing MHLA layers with other attention types) when:** You are retrofitting an existing pretrained model and want the best accuracy-efficiency tradeoff with minimal retraining. This is the Wan-MHLA-H scenario (Table 5: replacing 2/3 of layers with MHLA yields Total score 83.82—better than the original 83.31—at 1.6× speedup). The practical indicator: full replacement may require more fine-tuning to adapt the model to the new attention distribution; partial replacement preserves more of the pretrained model's behavior while still capturing most of the speedup.

- **Do NOT use vanilla linear attention when:** The sequence length exceeds a few thousand tokens and the task requires selective attention over the full context. The paper's video generation results (Table 5: Wan-LA at 58.24 Total score vs. Wan-FA at 83.31, with catastrophic semantic degradation to 11.38) show that at $N = 31,500$, vanilla linear attention fails to train meaningful representations regardless of model capacity. The rank diagnostic predicts this failure: at $N \gg d$, the attention matrix is so severely rank-deficient that essential information is irrecoverably lost. For long-sequence tasks, use MHLA, sparse attention, or a hybrid—but not global linear attention.
