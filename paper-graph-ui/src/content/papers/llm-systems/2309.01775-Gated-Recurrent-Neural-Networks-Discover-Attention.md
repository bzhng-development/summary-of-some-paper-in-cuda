# Gated Recurrent Neural Networks Discover Attention

**ArXiv:** [2309.01775](https://arxiv.org/abs/2309.01775)

## 🎯 Pitch

Gated linear RNNs can exactly implement linear self-attention using a finite number of neurons—and gradient descent spontaneously discovers this construction when training on in-context learning tasks. Under the hood, these supposedly distinct architectures end up running the same attention-based algorithm.

---

## 1. Executive Summary

This paper studies how gated recurrent neural networks with multiplicative interactions can exactly implement linear self-attention, establishing a functional equivalence through a constructive proof and then verifying empirically that gradient descent discovers this construction in practice. The authors train gated diagonal linear RNNs on teacher-student mimicry tasks and on in-context linear regression, showing that trained networks implement the same **attention-based in-context learning algorithm** — specifically, one step of gradient descent (matching an optimal linear self-attention layer's behavior) — that prior work has identified in Transformers. The key finding is that gated RNNs can functionally replicate linear self-attention using only finite neurons, with the number of required recurrent units scaling quadratically in the input dimension for full-rank attention matrices but compressing to the rank when the attention weights are low-rank, establishing that RNNs and attention-based models share a deeper computational equivalence than previously recognized — though the equivalence requires O(d⁴) parameters in the worst case and the most common nonlinear gated architectures (LSTMs, GRUs) show weaker or absent inductive bias toward attention-compatible configurations when trained.

## 2. Context and Motivation

### The Core Problem: We Don't Understand the Computational Relationship Between RNNs and Attention

The fundamental question this paper addresses is deceptively simple: **can recurrent neural networks implement attention mechanisms, and if so, does gradient descent actually discover such implementations during training?** This matters because, despite attention-based models (particularly Transformers) having largely displaced RNNs as the dominant architecture for sequence modeling, RNNs retain critical practical advantages that make understanding their computational capabilities valuable.

The landscape the paper enters is characterized by a sharp divide. On one side of this divide sit **Transformers**, which have become the state-of-the-art architecture across most sequence modeling tasks since Vaswani et al. (2017). Their core innovation — the softmax self-attention mechanism — enables each token to attend to all previous tokens with dynamically computed importance weights, providing a powerful inductive bias for tasks requiring flexible context-dependent processing. However, this capability comes at a cost: the standard softmax attention mechanism has **unbounded memory requirements** during autoregressive inference, since it must maintain access to all previous key-value pairs to compute the attention weights for each new token. The memory cost grows linearly with sequence length, making Transformers expensive — and sometimes infeasible — for very long sequences.

On the other side sit **recurrent neural networks**, which process sequences through a fixed-size hidden state that is updated at each timestep. This architecture provides a compelling alternative: inference can proceed for arbitrarily long sequences at **constant memory cost**, since only the fixed-dimensional hidden state needs to be maintained, not the entire history. This property makes RNNs theoretically attractive for deployment on memory-constrained devices, for processing extremely long sequences (such as those in the Long Range Arena benchmark; Tay et al., 2020), and for applications where inference efficiency is paramount.

The tension between these two architectural families has driven recent research in two seemingly unrelated directions, and it is precisely this apparent divergence that the paper seeks to reconcile.

### Two Parallel Research Trends That Appear Unrelated

The first trend, which the paper characterizes as one line of work, is the development of **deep linear RNN architectures** that significantly improve upon classical RNNs. These modern RNNs — including variants based on structured state-space models (Gu et al., 2022; Smith et al., 2023; Gu & Dao, 2023) and the Linear Recurrent Unit or LRU (Orvieto et al., 2023b) — have achieved remarkable results, in some cases outperforming Transformers on challenging long-sequence tasks and on certain language modeling benchmarks. A prominent design pattern across these architectures is the use of **linear recurrent layers interconnected by feedforward paths with multiplicative gating**. Specifically, these models often employ diagonal linear recurrence (which simplifies the dynamics and facilitates gradient-based learning) combined with elementwise multiplicative interactions — either as explicit gating mechanisms (e.g., GLU layers; Dauphin et al., 2017) or as input-dependent modulation of the recurrent state update.

The second trend is the development of **efficient linearized attention models**. These models — including Performers (Choromanski et al., 2021), linear Transformers (Katharopoulos et al., 2020), and various kernel-based attention approximations (Tsai et al., 2019; Schlag et al., 2021) — reformulate the attention computation so that it can be executed in an RNN-like fashion during inference. The key insight is that by removing the softmax nonlinearity and working with linearized attention, the computation can be reorganized: rather than storing all previous key-value pairs explicitly, the model maintains a running "fast weight" matrix that accumulates outer products of keys and values, and queries this matrix at each timestep. This reduces inference memory to constant, exactly matching the RNN's advantage.

These two lines of work — making RNNs more powerful and making attention more efficient — have progressed largely independently. Yet both converge on architectures that feature **linear recurrence coupled with multiplicative interactions**. The paper's central observation is that this convergence is not coincidental: these architectural elements are precisely what is needed for RNNs to implement attention-like computations.

### Prior Work: What We Knew and What We Didn't

Before this paper, the relationship between RNNs and attention was understood primarily through two lenses, both of which the authors argue are insufficient.

**Universality arguments provide existence guarantees but miss the practical picture.** Classical results in dynamical systems theory established that linear recurrent networks with nonlinear readouts can approximate a wide class of nonlinear operators, including those with fading memory (Boyd & Chua, 1985; Grigoryeva & Ortega, 2018). More recently, Orvieto et al. (2023a) proved that linear recurrences followed by nonlinear projections are universal approximators for sequence-to-sequence maps. However, as the authors explicitly note in Section 3:

> "our construction only requires a finite number of neurons to exactly match the desired function, therefore providing a much stronger equivalence result than more general universality of linear recurrent networks theorems [...], which hold in the limit of infinitely many recurrent neurons."

Universality tells us that with enough neurons, an RNN *could* approximate attention. It does not tell us **how many neurons are needed**, **what specific weight configurations achieve this**, or — crucially — **whether gradient-based learning actually discovers such configurations in practice**. These are the gaps the paper fills.

**Prior work recognized connections between fast weights and attention but didn't characterize the mapping precisely.** The observation that linear self-attention resembles a fast-weight memory — where the outer product of keys and values acts as a Hebbian-like weight update — dates back to Schmidhuber (1992) and was developed further by Schlag et al. (2021). The connection is that in a linear self-attention layer:

$$W^{\text{ff}}_t = \sum_{t' \leq t} v_{t'} k_{t'}^\top \quad \text{and} \quad y_t = W^{\text{ff}}_t q_t$$

the matrix $W^{\text{ff}}_t$ is updated through an additive rule $W^{\text{ff}}_t = W^{\text{ff}}_{t-1} + v_t k_t^\top$ that is structurally analogous to Hebbian synaptic plasticity. This perspective was primarily used to motivate efficient implementations of attention and to draw conceptual parallels. However, it did not provide an **exact constructive mapping** between the weight space of a specific RNN architecture and the weight space of a linear self-attention layer. Nor did it establish which architectural elements are necessary and sufficient for the equivalence.

**Empirical studies of in-context learning identified gradient descent as the algorithm Transformers learn, but didn't extend to RNNs.** A separate but highly relevant line of work studied what algorithms Transformers learn when trained on in-context learning tasks. For the specific case of in-context linear regression, von Oswald et al. (2023) showed that a linear self-attention layer learns to implement **one step of gradient descent** on the least-squares loss, with the weight update expressed as:

$$\Delta W_0 = \frac{\eta}{T} \sum_{t=1}^T (y_t - W_0 x_t) x_t^\top$$

This finding was subsequently refined and proven optimal by Mahankali et al. (2023), Ahn et al. (2023), and Zhang et al. (2023). However, these results were specific to Transformers and linear self-attention layers. Whether RNNs trained on the same task would discover the same algorithm — or something entirely different — was unknown. The present paper bridges this gap by showing that gated RNNs not only *can* implement attention but *do* learn the same gradient-descent-based in-context learning strategy when trained on the same data.

### Where Existing RNN Architectures Fall Short

The paper explicitly motivates its study by examining the gap between classical gated RNNs (LSTMs, GRUs) and the requirements for implementing attention. This analysis, presented in Section 3.3 and Appendix B, reveals important architectural constraints:

**LSTMs can theoretically implement attention, but the configuration is highly constrained.** The LSTM's sophisticated gating structure — with separate forget, input, and output gates — provides the necessary multiplicative interactions. The cell state can be configured to perfectly integrate key-value outer products (by setting the forget gate $f_t = 1$), and the output gate can encode the query. However, as the authors note, this requires linearizing the tanh and sigmoid nonlinearities, which demands specific weight regimes (small weights in certain matrices compensated by large decoder weights). The construction is possible in theory with a single LSTM layer, but the **inductive bias toward this solution may be extremely weak**, since it requires the network to settle into a very specific corner of its parameter space where all the nonlinearities are effectively linear.

**GRUs cannot implement attention at all.** Despite sharing many computational elements with LSTMs, GRUs lack a mechanism to multiply keys and values. The paper's analysis shows that stacking multiple GRU layers does not enable the implementation of linear self-attention, because the GRU's gating structure — specifically, the update gate $z_{t+1}$ and the reset gate $r_{t+1}$ — cannot simultaneously compute multiplicative interactions between two transformations of the input while isolating the result from the influence of the previous hidden state. This is a strong negative result that highlights the specific architectural requirements for attention compatibility.

**Modern deep linear RNNs have the right ingredients but the connection hadn't been made explicit.** Architectures like the LRU and Mamba feature the combination of linear recurrence and multiplicative gating that the paper identifies as sufficient for implementing attention. However, prior work on these architectures focused on their empirical performance and training dynamics (Orvieto et al., 2023b; Zucchet et al., 2023b), not on their theoretical relationship to attention mechanisms. The paper's contribution is to **make this connection explicit and constructive**, and then to test whether it manifests in practice.

### A Fundamental, Unanswered Question

The paper frames all of this around a question that, surprisingly, had not been systematically addressed: **if you take a gated RNN and train it to match the outputs of a linear self-attention layer, does it discover a solution that implements the same function — not just approximately, but exactly?** And, more broadly, **does the inductive bias of different RNN architectures align with the computational structure needed to implement attention?**

This is not merely an academic exercise. If gated RNNs can implement attention efficiently, then the boundary between these two architectural families blurs significantly. An RNN that learns to implement attention under the hood would combine the **representational power** of attention mechanisms with the **inference efficiency** of recurrent processing. Conversely, if certain widely-used RNN architectures (like GRUs) structurally cannot implement attention, this provides a principled explanation for their limitations on tasks where attention-based processing is beneficial.

### How This Paper Positions Itself

The paper positions itself as **bridging the gap** between two architectural paradigms that are typically viewed as mutually exclusive. Rather than arguing that RNNs are "as good as" Transformers or vice versa, the paper provides a precise characterization of the conditions under which equivalence holds:

**It provides a constructive proof with explicit weight values.** Unlike universality arguments that guarantee existence in the limit, the paper's Section 3 provides concrete matrix values for every parameter in the gated RNN — the input gating matrices $W^{\text{in}}_m$ and $W^{\text{in}}_x$, the recurrent decay factors $\lambda$, the output gating matrices $W^{\text{out}}_m$ and $W^{\text{out}}_x$, and the readout matrix $D$ — that exactly reproduce any specified linear self-attention layer. Figure 1 visually depicts this construction, showing how key-values are accumulated in recurrent units with $\lambda = 1$ (perfect memory) and queries are passed through units with $\lambda = 0$ (no memory), with the output gating and readout performing the matrix-vector multiplication between accumulated key-values and current queries.

**It quantifies the cost of the equivalence.** The paper is explicit about the price of implementing attention in an RNN: $O(d^2)$ neurons and $O(d^4)$ parameters are required for the naive construction, where $d$ is the input dimension. This is significantly more than the $3d^2$ parameters of the attention layer itself. However, the paper identifies compression opportunities — when the attention matrices are symmetric or low-rank, the required neuron count drops substantially — and shows empirically that trained networks discover these compressed representations (Figures 3A, 3B).

**It empirically tests which architectures actually learn attention-like solutions.** Rather than stopping at the existence proof, the paper trains a range of recurrent architectures — the simplified gated RNN of Equation 2, LSTMs, GRUs, LRUs with various gating configurations, and a modified LRU with input gating (LRU+) — on a teacher-student task where the goal is to reproduce the output of a randomly initialized linear self-attention layer. The results (Figure 4A) reveal a clear hierarchy: the simplified gated RNN succeeds with low loss; the LRU (which has only output gating) performs significantly worse; adding input gating to create LRU+ dramatically improves performance; and LSTMs and GRUs perform at chance level, even though LSTMs theoretically can implement attention. This disconnect between theoretical capability and empirical learnability is a key insight.

**It extends to in-context learning, connecting to the Transformers literature.** By showing that gated RNNs trained on in-context linear regression discover the same gradient descent algorithm that Transformers learn (Section 5, Table 2, Figure 3C), the paper establishes that the connection is not just a theoretical curiosity but manifests in **the algorithms that networks acquire through training**. The polynomial analysis in Table 2 is particularly compelling: the coefficients of the degree-4 polynomial that describes the trained RNN's instantaneous processing are virtually identical to those of one optimal gradient descent step, with only the $x_i^2 y_j$ terms having non-negligible magnitude and a residual norm near zero.

**It challenges standard narratives while remaining measured.** The paper does not claim that RNNs are universally superior or that attention is unnecessary. Instead, it provides a nuanced picture: attention-like computation is possible in RNNs but requires specific architectural ingredients (multiplicative gating), comes with a parameter cost, and is not equally discoverable by all recurrent architectures. This positions the work as a **clarifying contribution** that explains when and why different architectures succeed or fail, rather than as a proposal for a new architecture or training method.

The paper also connects to neuroscience, suggesting that recurrent neural circuits with multiplicative gating — akin to the dendritic and circuit-level multiplication mechanisms identified in biological neurons (Silver, 2010) — might implement attention-like computations in working memory. This provides a broader intellectual motivation beyond machine learning: understanding the computational capabilities of recurrent circuits with multiplicative interactions may illuminate how biological brains process sequential information.

## 3. Technical Approach

This is primarily a **theoretical and empirical analysis paper** whose core idea is that gated recurrent neural networks with multiplicative interactions can exactly implement linear self-attention through a specific, constructive weight configuration, and that gradient descent discovers such configurations when training these networks.

### 3.1 Reader Orientation (Approachable Technical Breakdown)

The "system" being analyzed is a **gated diagonal linear recurrent neural network** — a specific architectural formula where the hidden state evolves through elementwise decay and elementwise-gated input addition, and the output is a linear readout of elementwise-gated hidden state activations. The paper solves the problem of **establishing whether RNNs can functionally replicate linear self-attention** not just approximately in the limit of infinite neurons (which universality theorems guarantee), but **exactly with a finite number of neurons and explicit weight values** — and then tests whether this equivalence emerges naturally through training.

### 3.2 Big-Picture Architecture (Diagram in Words)

The overall framework has two parallel investigative tracks that share a common architectural foundation:

1. **The simplified gated RNN** — defined by Equation 2 — which serves as the primary object of study. It consists of: **(a)** an input gating module `$g^{\text{in}}$` that produces elementwise products of two linear transformations of the current input `$x_t$`, **(b)** a hidden state `$h_t$` that accumulates these products with per-neuron decay factors `$\lambda$`, and **(c)** an output gating module `$g^{\text{out}}$` that applies another elementwise product to the hidden state, followed by a linear readout matrix `$D$` that produces the final output `$y_t$`.

2. **The teacher linear self-attention layer** — defined by Equation 1 — which serves as the target function. It computes `$y_t = (\sum_{t'\leq t} v_{t'}k_{t'}^\top) q_t$` where `$v_t = W^V x_t$`, `$k_t = W^K x_t$`, and `$q_t = W^Q x_t$` are the values, keys, and queries derived linearly from the input.

3. **The investigative pipeline**: In the **teacher-student experiments** (Section 4), a student gated RNN is trained to minimize the squared error between its outputs and those of a randomly initialized teacher attention layer on random input sequences. In the **in-context learning experiments** (Section 5), the gated RNN is trained directly on the task of in-context linear regression, without a teacher, and its learned algorithm is compared to the gradient descent solution that an optimal linear self-attention layer would implement.

4. **The reverse-engineering toolkit**: To determine whether a trained RNN has learned an attention-equivalent function, the paper employs **(a)** pruning of zero-weight neurons, **(b)** identification of which recurrent units have `$\lambda = 1$` (perfect memory) versus `$\lambda = 0$` (no memory), **(c)** linear regression to check whether the activations of these neuron groups can reconstruct the key-values and queries, and **(d)** polynomial coefficient comparison between the instantaneous input-output mapping of the RNN and that of the target attention layer.

### 3.3 Roadmap for the Deep Dive

- **First, the mathematical definitions** of the two architectures being equated — the gated RNN (Equation 2) and linear self-attention (Equation 1) — since the entire paper is about establishing and testing the connection between them.
- **Second, the constructive proof** of how a gated RNN can exactly implement any linear self-attention layer, including the explicit weight values, the role of each architectural component (input gating, recurrent accumulation, output gating, readout), and the number of neurons required.
- **Third, the compression story** — how the required neuron count can be reduced when the attention matrices have structure (symmetry, low rank), and why this matters for what networks actually learn.
- **Fourth, the extension to nonlinear RNN architectures** (LSTMs, GRUs, LRUs, Mamba), specifically analyzing which can and cannot implement attention, and why.
- **Fifth, the reverse-engineering methodology** used to determine whether a trained network has actually learned an attention-equivalent function, including the polynomial coefficient analysis.
- **Sixth, the experimental setup** for both the teacher-student mimicry task and the in-context learning task, including architectures, hyperparameters, and evaluation protocols.

### 3.4 Detailed, Sentence-Based Technical Breakdown

The paper develops a constructive equivalence between gated RNNs with multiplicative interactions and linear self-attention, then studies whether gradient descent discovers this equivalence. The analysis proceeds from theoretical construction to empirical verification, with careful attention to which architectural ingredients are necessary versus merely helpful.

#### Mathematical Definition of the Gated RNN

The paper defines the class of gated recurrent networks under study through a set of update equations that isolate the essential computational mechanisms. The recurrence is defined as:

$$h_{t+1} = \lambda \odot h_t + g^{\text{in}}(x_t)$$

where `$h_t \in \mathbb{R}^n$` is the hidden state at time `$t$`, `$\lambda \in \mathbb{R}^n$` is a vector of per-neuron decay factors, `$x_t \in \mathbb{R}^d$` is the input vector at time `$t$`, and `$g^{\text{in}}$` is the input gating function. The `$\odot$` operator denotes elementwise (Hadamard) multiplication — meaning each hidden neuron `$i$` independently decays its previous value by factor `$\lambda_i$` and then adds the output of `$g^{\text{in}}$`.

The gating functions are bilinear forms that multiply two linear projections of the input elementwise:

$$g^{\text{in}}(x_t) = (W^{\text{in}}_m x_t) \odot (W^{\text{in}}_x x_t)$$

$$g^{\text{out}}(h_t) = (W^{\text{out}}_m h_t) \odot (W^{\text{out}}_x h_t)$$

where `$W^{\text{in}}_m, W^{\text{in}}_x \in \mathbb{R}^{n \times (d+1)}$` are the input gating weight matrices and `$W^{\text{out}}_m, W^{\text{out}}_x \in \mathbb{R}^{m \times n}$` are the output gating weight matrices. The `$+1$` in the input gating dimension accounts for an appended constant 1, which allows one branch of the gating to compute purely linear (rather than bilinear) functions when needed — for instance, the query pathway uses this to generate `$W^Q x_t$` without multiplying by another transformation.

The final output is produced through a linear readout of the output-gated hidden state:

$$y_t = D \cdot g^{\text{out}}(h_t)$$

where `$D \in \mathbb{R}^{d \times m}$` is the readout matrix.

**What this architecture computes:** At each timestep, the input `$x_t$` is transformed through two parallel linear projections `$W^{\text{in}}_m x_t$` and `$W^{\text{in}}_x x_t$`, which are then multiplied elementwise to produce bilinear terms in the input. These bilinear terms are added into the decaying hidden state, allowing the network to accumulate products of linearly transformed inputs over time. The hidden state is then passed through a second bilinear gating (the output gating) that multiplies stored values by query-like transformations, and finally a linear readout `$D$` sums across gated outputs to produce the final prediction.

**Why this form:** The paper argues this simplified architecture captures the essential computational mechanisms of modern deep linear RNNs while remaining analytically tractable. The diagonal recurrence (`$\lambda$`) is motivated by three considerations: **(1)** it is the recurrence structure used in recent powerful deep linear RNNs such as the LRU (Orvieto et al., 2023b), S5 (Smith et al., 2023), and S4 variants (Gupta et al., 2022); **(2)** diagonal recurrence has been shown to facilitate gradient-based learning by avoiding the vanishing/exploding gradient pathologies of dense recurrent matrices (Orvieto et al., 2023b; Zucchet et al., 2023b); and **(3)** diagonal structure makes the analysis tractable — the evolution of each hidden neuron is independent, and setting `$\lambda_i = 1$` creates a perfect integrator while `$\lambda_i = 0$` creates a perfect forgetter. The multiplicative gating `$(W_m z) \odot (W_x z)$` is a linearized version of the Gated Linear Unit (GLU; Dauphin et al., 2017) widely used in modern architectures; it enables the network to compute products of two learned features, which is essential for representing outer products (as attention requires).

#### Mathematical Definition of Linear Self-Attention

The linear self-attention layer that serves as the target function processes input sequences `$(x_t)_{t}$` with `$x_t \in \mathbb{R}^d$`. The output at time `$t$` is:

$$y_t = \left(\sum_{t' \leq t} (W^V x_{t'})(W^K x_{t'})^\top \right) (W^Q x_t)$$

where `$W^V \in \mathbb{R}^{d \times d}$` is the value matrix, `$W^K \in \mathbb{R}^{d \times d}$` is the key matrix, and `$W^Q \in \mathbb{R}^{d \times d}$` is the query matrix. The vectors `$v_t = W^V x_t$`, `$k_t = W^K x_t$`, and `$q_t = W^Q x_t$` are called the values, keys, and queries respectively.

**What this equation computes:** At each timestep `$t$`, the layer maintains an implicit memory matrix `$W^{\text{ff}}_t = \sum_{t' \leq t} v_{t'} k_{t'}^\top$` that is the sum of outer products of all previous value and key vectors. This matrix captures pairwise associations between value dimensions and key dimensions, accumulated over the entire history. To produce the output, this memory matrix is multiplied by the current query vector `$q_t$`, which extracts the stored values weighted by how well their associated keys match the query. The output is causal (only depends on `$t' \leq t$`), and the memory matrix grows additively with each new input through the update rule `$W^{\text{ff}}_t = W^{\text{ff}}_{t-1} + v_t k_t^\top$`.

**Why this form:** Linear self-attention is the version of the standard softmax attention mechanism (Bahdanau et al., 2015; Vaswani et al., 2017) obtained by removing the softmax nonlinearity while keeping the core query-key-value structure. Two properties make it the natural target for the paper's equivalence analysis: **(1)** the additive memory update `$W^{\text{ff}}_t = W^{\text{ff}}_{t-1} + v_t k_t^\top$` is structurally analogous to a linear recurrence, suggesting that RNNs might be able to implement it by storing the matrix entries in their hidden state; and **(2)** linear self-attention has been studied extensively in the in-context learning literature, with von Oswald et al. (2023) showing it learns to implement gradient descent, making it a bridge to understanding RNN in-context learning behavior. The paper focuses on square `$d \times d$` weight matrices for simplicity but notes the construction extends to rectangular ones. Multiple attention heads, common in practice, are omitted — the analysis treats a single head.

#### The Constructive Proof: Exact RNN-to-Attention Mapping

The paper's central theoretical contribution is an **explicit construction** — a set of concrete numerical values for every parameter in the gated RNN that makes it compute exactly the same function as any specified linear self-attention layer.

**The three-component decomposition.** The construction decomposes attention into three functionally distinct computations, each implemented by a different part of the RNN:

1. **Input gating generates key-value outer products and queries.** The input gating matrices `$W^{\text{in}}_m$` and `$W^{\text{in}}_x$` are configured so that the elementwise product `$(W^{\text{in}}_m x_t) \odot (W^{\text{in}}_x x_t)$` simultaneously computes, in parallel across different neurons: **(a)** for the first `$d^2$` neurons, all pairwise products `$(W^V x_t)_i \cdot (W^K x_t)_j$` — that is, the `$(i,j)$` entry of the outer product `$v_t k_t^\top$`; and **(b)** for the last `$d$` neurons, the individual query components `$(W^Q x_t)_i$`. This is achieved by setting the rows of `$W^{\text{in}}_x$` to extract value and query components (Equation 9 in the appendix), and the rows of `$W^{\text{in}}_m$` to extract key components and pass through the constant `$1$` for query-only neurons (Equation 10).

2. **Recurrent neurons accumulate key-values or relay queries.** The decay vector `$\lambda$` is set to `$\lambda_i = 1$` for the first `$d^2$` neurons (perfect integration of key-value products) and `$\lambda_i = 0$` for the last `$d$` neurons (instantaneous relay of the current query). This means that after processing `$t$` timesteps, neuron `$i$` (for `$i \leq d^2$`) contains `$\sum_{t' \leq t} (W^V x_{t'})_{\lfloor i/d \rfloor} \cdot (W^K x_{t'})_{i \text{ mod } d}$` — exactly the accumulated key-value matrix entries — while neuron `$i$` (for `$i > d^2$`) contains just the current query component `$(W^Q x_t)_{i-d^2}$`.

3. **Output gating and readout multiply accumulated key-values by current queries.** The output gating matrices `$W^{\text{out}}_m$` and `$W^{\text{out}}_x$` are configured as selector matrices (Equations 12-13 in the appendix). Specifically, `$W^{\text{out}}_x$` selects, for each of its `$d^2$` output units, the corresponding key-value entry from the memory neurons via identity connections: `$(W^{\text{out}}_x h_t)$` retrieves the stored key-value matrix. Meanwhile, `$W^{\text{out}}_m$` selects the appropriate query component: `$(W^{\text{out}}_m h_t)$` extracts `$q_t$` and tiles it so that the `$(i,j)$` key-value entry is paired with the `$j$`-th query component. The elementwise product in `$g^{\text{out}}$` thus computes all terms of the form `$(\text{accumulated KV})_{i,j} \cdot q_{t,j}$`. Finally, the readout matrix `$D$` sums over `$j$` (Equation 14) to produce the `$i$`-th output component `$\sum_j (\text{KV})_{i,j} \cdot q_{t,j} = (W^{\text{ff}}_t q_t)_i$`.

**Why the constant 1 is appended to the input:** The appendix clarifies that the input vector `$x_t$` is augmented with a constant `$1$` to produce `$[x_t; 1] \in \mathbb{R}^{d+1}$`. This is essential for the query neurons: their output must be purely linear in the input (degree 1), not bilinear (degree 2). By setting the query-related rows of `$W^{\text{in}}_m$` to have weight 1 on the constant dimension and zero on all input dimensions, the elementwise product becomes `$1 \cdot (W^{\text{in}}_x x_t) = (W^Q x_t)$`, delivering a linear query without multiplying two input-dependent terms. Without the appended constant, every neuron would receive a bilinear input and pure linear processing would be impossible.

**Figure 1 visual summary.** The paper's Figure 1 provides a visual depiction of this construction with explicit matrix values for a small example. The figure uses bars to separate different kinds of inputs and outputs, uses `repeat(A, n)` to denote row-wise repetition, and shows how the readout matrix `$D$` appropriately sums the elementwise products computed after the output gating.

**Parameter count cost.** The construction requires `$n = d^2 + d$` hidden neurons (storing all key-value entries plus the query), and `$m = d^2$` output gating neurons. The input gating matrices have size `$(d^2 + d) \times (d+1)$`, the output gating matrices have size `$d^2 \times (d^2 + d)$`, and the readout has size `$d \times d^2$`. The total parameter count is therefore `$O(d^4)$` — specifically, dominated by the output gating matrices which each have roughly `$d^4$` entries. This is substantially more than the `$3d^2$` parameters of the linear self-attention layer itself. This is the "negative result" the paper acknowledges: implementing attention in an RNN exactly requires quadratically more parameters than the attention layer being implemented, though the paper shows compression is possible under additional structure.

#### Compressing the Construction: Symmetric Key-Value Matrices

The naive construction stores all `$d^2$` entries of the key-value matrix `$\sum_{t'} v_{t'} k_{t'}^\top$`. However, the paper identifies an invariance of linear self-attention that enables compression.

**The invariance argument.** The paper observes (in Section 3.2 and Appendix A.3) that the output of a linear self-attention layer depends on the key and query matrices only through their product `$W^{K\top} W^Q$`. This is because:

$$y_t = W^V \left(\sum_{t' \leq t} x_{t'} x_{t'}^\top \right) W^{K\top} W^Q x_t$$

Any pair of key and query matrices that yield the same product `$W^{K\top} W^Q$` will produce identical outputs. Therefore, without loss of generality, one can assume the key and value matrices are **equal** — specifically, by replacing the original key matrix with `$W^V$` and adjusting the query matrix to `$W_V^{-\top} W^{K\top} W^Q$`, the function of the attention layer is preserved.

**Consequence: symmetry of the accumulated matrix.** When key and value matrices are equal, the outer product `$v_t k_t^\top = (W^V x_t)(W^V x_t)^\top$` is **symmetric**. Its `$(i,j)$` and `$(j,i)$` entries are identical. Therefore, only the upper triangular part (including the diagonal) needs to be stored — that is, `$d(d+1)/2$` entries rather than `$d^2$`.

**Minimum neuron count.** With this symmetry exploitation, the required number of hidden neurons drops from `$d^2 + d$` to `$d(d+1)/2 + d$`. For example, with `$d=4$`, the naive construction needs `$20$` memory neurons while the compressed version needs only `$10$` memory neurons plus `$4$` query neurons. This is exactly what the paper observes in the trained networks (Section 4.1, Figure 2, Table 1): the learning process discovers that only `$d(d+1)/2$` neurons with `$\lambda=1$` are needed, matching the theoretical minimum.

**Why this matters:** The symmetry-based compression is not just a theoretical curiosity — it demonstrates that the network can discover more efficient representations than the literal "store every entry" construction. This provides a concrete prediction: if the RNN learns to implement attention, its effective neuron utilization (how many memory neurons actually influence the output) should reflect the structure of the attention matrices.

#### Compressing for Low-Rank Attention Matrices

A second, more powerful compression opportunity arises when the attention weight matrices `$W^V$`, `$W^K$`, and `$W^Q$` are **low rank** — a scenario of practical relevance since real-world attention heads often operate in a lower-dimensional subspace.

**The singular value decomposition approach** (Appendix A.4). The paper introduces SVD decompositions of the key matrices:

$$W^V = U_V \Sigma_V V_V^\top$$

$$W^{K\top} W^Q = U_{KQ} \Sigma_{KQ} V_{KQ}^\top$$

where `$\Sigma_V$` and `$\Sigma_{KQ}$` are diagonal matrices whose number of non-zero entries equals the ranks `$r_V = \text{rank}(W^V)$` and `$r_{KQ} = \text{rank}(W^{K\top} W^Q)$`. The output can be rewritten as:

$$y_t = U_V \left(\sum_{t' \leq t} (\Sigma_V V_V^\top x_{t'}) (\Sigma_{KQ} U_{KQ}^\top x_{t'})^\top \right) V_{KQ}^\top x_t$$

**Reduced neuron requirement.** In this transformed coordinate system, only the first `$r_V$` rows and first `$r_{KQ}$` columns of the accumulated key-value matrix contain non-zero information. The required number of key-value storage neurons drops to `$r_V \cdot r_{KQ}$`, and the number of query relay neurons drops to `$r_{KQ}$`. The total is `$r_{KQ}(r_V + 1)$` — which can be dramatically smaller than `$d(d+1)/2 + d$` when the ranks are low.

**Empirical confirmation (Figure 3A, 3B).** The paper tests this prediction by training gated RNNs with varying numbers of hidden neurons on teachers with either full-rank or low-rank attention matrices. In the full-rank case (Figure 3A, `$d=4$`), the transition from poor to good teacher identification occurs around 14 hidden neurons, matching the `$d(d+1)/2 + d = 4 \cdot 5 / 2 + 4 = 14$` requirement of the symmetric construction. In the low-rank case (Figure 3B, `$d=12$`, ranks set to 6), the transition occurs around `$r_{KQ}(r_V + 1) = 6 \cdot 7 = 42$` neurons — as predicted by the low-rank construction. This provides strong evidence that the trained networks are not merely approximating attention through some generic function approximation but are specifically leveraging the structure of the attention computation.

#### Alternative Construction with Side Gating

Recognizing that `$O(d^4)$` parameters is impractically expensive, the paper presents an alternative construction using **side gating** rather than output gating (Appendix A.2), which reduces the parameter cost to `$O(d^3)$`.

**The side gating architecture.** In this variant, the output is computed as:

$$y_t = D \cdot g^{\text{side}}(x_t, h_t)$$

with the side gating function defined as:

$$g^{\text{side}}(x_t, h_t) = (W^{\text{side}} x_t) \odot h_t$$

where `$W^{\text{side}} \in \mathbb{R}^{n \times d}$` is the side gating matrix and `$h_t$` is the hidden state from the same recurrence as before (but without the query-only neurons, since queries are now injected through the side gating).

**What changes:** The key insight is that queries no longer need to be relayed through dedicated recurrent neurons. Instead, the query transformation is applied directly to the current input `$x_t$` via `$W^{\text{side}} x_t$`, and then multiplied elementwise with the accumulated key-value matrix stored in `$h_t$`. This eliminates the `$d$` query neurons and — more importantly — eliminates the need for the output gating to have size `$d^2 \times (d^2 + d)$`, replacing it with a side gating matrix of size `$n \times d$` where `$n = d^2$`. The total parameter count drops from `$O(d^4)$` to `$O(d^3)$`.

**Connection to existing architectures.** The paper notes that this side gating mechanism is featured in the recently proposed Mamba layer (Gu & Dao, 2023) and, indirectly, in LSTMs — where the output gate `$o_t$` multiplies the cell state (which can store accumulated key-values) by an input-dependent gating signal. The side gating construction thus provides a principled explanation for why these architectures have a stronger inductive bias toward attention-like computation.

**Why the paper focuses on input-output gating despite the parameter cost:** The main construction with input and output gating is arguably simpler and more common in the architectures the paper aims to analyze (particularly the LRU with its GLU-based output gating). The side gating variant is presented to show that the equivalence does not fundamentally require the `$O(d^4)$` scaling and to connect to architectures like Mamba.

#### What Classical RNN Architectures Can and Cannot Implement

The paper extends its analysis to determine whether widely-used nonlinear gated RNN architectures (LSTMs, GRUs, the LRU, and Mamba) can implement linear self-attention. This analysis (Section 3.3, Appendix B) identifies necessary conditions and specific architectural constraints.

**LRU requires two layers; a modified LRU needs one.** The standard LRU layer (Orvieto et al., 2023b) features a complex-valued diagonal linear recurrence combined with a GLU serving as nonlinear output gating. To implement the simplified gated RNN of Equation 2: **(1)** linearizing the sigmoid in the GLU requires small weights in `$W_m$` so that `$\sigma(W_m x) \approx 1/2 + W_m x$` (assuming `$W_m x$` stays near zero); **(2)** with this linearization, the output gating of the first layer can serve as input gating for the second layer. Two stacked LRU layers can therefore implement the construction. The paper also introduces a modified variant **LRU+** (called LRU In+Out in the appendix) that adds an explicit input gating GLU before the recurrence, enabling a single layer to implement the full construction.

**Mamba requires one layer for attention, two for the simplified gated RNN.** The Mamba block (Gu & Dao, 2023) features input-dependent recurrence through state-space matrices that depend on the input. The paper observes that the input-dependent `$B(x_t) x_t$` term can implement a gating mechanism where one branch acts as identity and the other as a learned transformation — this serves as an implicit input gating when preceded by a linear layer. The output already features a side gating via `$\sigma(W^{\text{side}}(x_t)) \odot C(x_t) h_t$`, which can implement the side gating construction of Appendix A.2 after linearizing the sigmoid. Thus, one Mamba layer can implement linear self-attention directly. Since Mamba lacks an explicit output gating (the side gating does not have the `$(W^{\text{out}}_x h_t) \odot (W^{\text{out}}_m h_t)$` form of Equation 2), two Mamba layers would be needed to implement the simplified gated RNN class exactly.

**LSTMs can implement attention in one layer — in theory.** The LSTM's architecture (detailed in Equations 34-39 and Appendix B.3) provides the necessary computational elements: **(1)** the cell state update `$c_{t+1} = f_{t+1} \odot c_t + g_{t+1} \odot \tilde{c}_{t+1}$` can be configured with `$f_t = 1$` (perfect memory) to accumulate key-values, by setting the forget gate bias `$b_f$` to a large positive value such that `$\sigma(b_f) \approx 1$`; **(2)** the candidate cell state `$\tilde{c}_{t+1}$` and the input gate `$g_{t+1}$` together can compute the key-value outer product — after linearizing the tanh and sigmoid nonlinearities; and **(3)** the output gate `$o_{t+1}$` can encode the query, multiplying the accumulated key-values (stored in `$c_{t+1}$`) by the query transformation. The crucial difference from the simplified gated RNN is that the LSTM's output gating is a **side gating** — it multiplies the cell state (not a separate linear transformation of it) by an input-dependent gate signal — which is why a single LSTM layer suffices where the simplified RNN requires two.

**However, the LSTM construction requires a very specific, fragile configuration.** The paper notes three practical obstacles: **(1)** the tanh in `$\tilde{c}$` and the sigmoid in `$g$` must be effectively linear, which constrains the weights to a small regime; **(2)** the forget gate must be exactly 1 to achieve perfect integration, but the sigmoid saturates and gradients vanish in this regime; and **(3)** the construction requires coordinating multiple gates (forget, input, output) with precise relationships. The paper conjectures that this creates a very **weak inductive bias** toward attention-compatible solutions — the LSTM *can* implement attention, but gradient descent is unlikely to find the extremely constrained weight configuration needed.

**GRUs cannot implement attention — period.** The GRU (Cho et al., 2014) updates its hidden state through:

$$h_{t+1} = (1 - z_{t+1}) \odot h_t + z_{t+1} \odot \tilde{h}_{t+1}$$

where `$z_{t+1}$` is the update gate and `$\tilde{h}_{t+1} = \tanh(U_h x_{t+1} + V_h(r_{t+1} \odot h_t) + b_h)$` is the candidate update. The paper argues that even with stacked layers, GRUs cannot implement the `$g(x) = (W_m x) \odot (W_x x)$` gating form required for key-value computation. The reason: using `$z_{t+1}$` and `$\tilde{h}_{t+1}$` to implement the two branches of a multiplicative gate would necessarily involve `$h_t$` (the previous hidden state) in the output, since `$z_{t+1} \neq 0$` is required for `$\tilde{h}_{t+1}$` to contribute. There is no mechanism to compute a pure input-dependent bilinear form isolated from the recurrent state. This is a **strong negative result**: among the four architectures compared, only the GRU is structurally incapable of implementing attention, providing a principled explanation for any performance gaps on attention-intensive tasks.

**Summary Table 3 (in the appendix).** The paper summarizes the minimum number of layers needed: LRU requires 2 layers for both the simplified gated RNN and linear self-attention; LRU In-Out requires 1 layer for both; Mamba requires 2 layers for the simplified gated RNN and 1 for linear self-attention; LSTM requires 2 layers for the simplified gated RNN and 1 for linear self-attention; GRU cannot implement either.

#### Reverse-Engineering Methodology: How the Paper Determines What a Trained RNN Learned

Training an RNN to produce the same outputs as a teacher attention layer is not sufficient to conclude it has learned to *implement* attention — it could have learned some other function that merely approximates the teacher on the training distribution. The paper employs a multi-step reverse-engineering pipeline to establish functional equivalence.

**Step 1: Pruning non-contributing neurons.** After training, many weights in the input gating, output gating, and readout become zero. The paper prunes: **(1)** hidden neurons whose input gating weights are entirely zero (they receive no input), **(2)** pre-readout neurons whose output gating weights are entirely zero, and **(3)** readout connections that are zero. This pruning is **exact** — it does not change the network's function because the removed weights are literally zero. In the experiment of Section 4.1 (`$d=4$`, 100 hidden neurons, 100 pre-readout neurons), pruning removes 86 out of 100 hidden neurons and 87 out of 100 pre-readout neurons, leaving a remarkably compact network of only 14 memory neurons and 4 query neurons — matching the theoretical minimum `$d(d+1)/2 + d = 14$`.

**Step 2: Classifying neurons by their `$\lambda$` values.** The recurrence dynamics are inspected to identify which neurons contribute to temporal processing. The paper finds that only two types of recurrent units influence the output: those with `$\lambda_i = 1$` (perfect integrators that accumulate inputs over time) and those with `$\lambda_i = 0$` (instantaneous relays that only respond to the current input). Neurons with intermediate `$\lambda$` values, if they exist, have been pruned away because their output gating weights are zero. This binary classification is the first check for the construction: the construction requires exactly `$d(d+1)/2$` integrators and `$d$` relays.

**Step 3: Linear reconstruction of key-values and queries.** Having identified integrator and relay neurons, the paper tests whether their activations encode the expected quantities. For each timestep, the paper takes the activations of the pruned integrator neurons and attempts to linearly reconstruct the true key-value matrix entries `$\sum_{t'\leq t} v_{t'} k_{t'}^\top$` from these activations. Similarly, it attempts to linearly reconstruct the query `$q_t$` from the relay neurons' activations. The reconstruction quality is measured using the R² score of a linear regression. The reported **Score KV** of `$4.52 \times 10^{-8}$` and **Score Q** of `$2.06 \times 10^{-10}$` (Table 1) indicate essentially perfect reconstruction — the integrator neurons contain a linear encoding of the full key-value matrix, and the relay neurons contain a linear encoding of the query. This is strong evidence that the temporal processing matches the construction.

**Step 4: Visual inspection of weight structure.** The paper permutes rows in the gating matrices (exploiting the inherent permutation invariance of elementwise products) and reorders neurons to reveal block structure in the weight matrices. Figure 2B shows the results: the weight matrices exhibit the block-diagonal structure characteristic of the construction, with clear separation between key-value-related and query-related pathways.

**Step 5: Polynomial coefficient comparison — the definitive test.** The instantaneous processing of both the linear self-attention layer and the gated RNN can be expressed as polynomials in the current input `$x_t$`. For linear self-attention:

$$y_{t,i} = \sum_{j,k,l} \left[\sum_{t'} (W^V x_{t'})_i (W^K x_{t'})_j\right] (W^Q)_{j,k} x_{t,k}$$

which is a **degree-3 polynomial** in `$x_t$` (since `$v_{t'}$` and `$k_{t'}$` for `$t'<t$` are treated as coefficients, and the only `$x_t$`-dependent terms are in `$q_t$`). For the gated RNN, the instantaneous computation `$g^{\text{out}}(g^{\text{in}}(x_t))$` is a **degree-4 polynomial** (each gating is bilinear in the input, and composing them yields degree 4). For these two polynomials to represent the same function, the coefficients of the degree-4 terms in the RNN must be zero (since the attention layer has maximum degree 3), and the coefficients of terms up to degree 3 must match those of the attention layer.

The paper computes the coefficients for all output dimensions and calculates the **normalized Euclidean distance** between the coefficient vectors of the two functions. The reported **polynomial distance** of `$3.73 \times 10^{-4}$` (Table 1, averaged over 4 output units) indicates near-perfect match. This test goes beyond the training distribution because it compares the functional forms themselves — if the polynomials match globally, the networks compute the same function on all possible inputs, not just those seen during training.

**Step 6: Compressing output gating redundancies.** The three anomalous rows in the output gating (rows 11-13 in Figure 2B) that don't match the expected block structure are shown to be functionally equivalent to a single row. The contribution of these rows to output `$i$` can be written as:

$$\sum_{j=11}^{13} D_{i,j} g^{\text{out}}(h)_j = x_t^\top \left(\sum_{j=11}^{13} D_{i,j} W^{\text{out}}_{m,j} W^{\text{out},\top}_{x,j} \right) x_t$$

The kernel of this quadratic form is a weighted sum of rank-1 outer products of the three row pairs. The paper finds this combined kernel is **rank-1** for all four output units and is **proportional across output units**, as shown in Figure 2C. Therefore, the three rows can be merged into one without changing the function, and the resulting single row matches the expected block structure. This illustrates a general invariance: the output gating is invariant under linear combinations of its rows that preserve the effective quadratic kernel per output dimension.

#### Teacher-Student Experimental Setup (Section 4)

This section describes the experimental configuration used to test whether gated RNNs learn to mimic linear self-attention.

**Architecture specification.** The student gated RNN is configured with input dimension `$|x| = 4$`, hidden state dimension `$|h| = 100$`, and output dimension `$|y| = 4$`. This represents significant overparameterization — the construction requires only `$d(d+1)/2 + d = 14$` memory neurons for this input size, but the student has 100, providing room for the network to discover the solution or find alternatives.

**Teacher generation.** The teacher linear self-attention layer has weight matrices `$W^V$`, `$W^K$`, and `$W^Q$` sampled i.i.d. from a normal distribution. The specific distribution parameters are not stated in the main text (they are standard Gaussian or similar), but the key point is that the teacher is randomly initialized — not hand-designed to be easy to mimic.

**Training data.** Each training sequence is of length 32 timesteps. At each timestep, the input `$x_t \in \mathbb{R}^4$` is sampled i.i.d. from a normal distribution. The target output at each timestep is the teacher attention layer's output on the same sequence. The sequences are **single-pass** — each sequence is presented only once, meaning the student must learn the teacher's function from randomly generated examples rather than memorizing specific sequences.

**Training hyperparameters.** Optimization uses AdamW (Loshchilov & Hutter, 2019) — the Adam optimizer with decoupled weight decay — with a cosine annealing learning rate scheduler. The initial learning rate is `$10^{-3}$`, annealing down to `$10^{-6}$` by the end of training. Weight decay of `$10^{-4}$` is applied to all parameters except the recurrent decay factors `$\lambda$`. Training proceeds for approximately **one million iterations** (50000 training examples per epoch, 1000 epochs) with batch size 64.

**Recurrent parameter constraint.** To prevent hidden state explosion, the `$\lambda$` parameters are constrained to `$[0, 1]$` using the exponential parameterization described in Appendix B.1: `$\lambda = \exp(-\exp(\nu_{\text{log}}))$` (the complex-valued phase parameter `$\theta_{\text{log}}$` from the LRU parameterization is omitted since `$\lambda$` is real-valued here). This ensures each `$\lambda_i$` is positive and less than or equal to 1.

**Evaluation metrics beyond training loss.** The paper reports multiple metrics that go beyond simple test-set MSE. The loss on held-out in-distribution data is reported (`$4.97 \times 10^{-8}$` in Table 1), confirming the student's outputs match the teacher's to high precision. However, the far more stringent tests are the Score KV, Score Q, and Polynomial Distance described in the reverse-engineering methodology above.

**Architecture variations for the comparison experiment (Figure 4A).** For the comparison between different recurrent architectures:
- **Linear Embedding + Recurrent + Linear Readout** is the common structure: a linear embedding projects the input to a latent space, the recurrent layer processes the sequence, and a linear readout produces the output.
- The recurrent layer is repeated either once or twice — corresponding to the minimum number of layers needed for each architecture to implement attention (as determined in the theoretical analysis).
- All recurrent layers (LSTM, GRU, LRU) have their input, output, and hidden dimensions set to the same value for fair comparison. No layer normalization, dropout, or skip connections are included — the architecture is minimal to isolate the effect of recurrence structure.
- **LRU+** (LRU In+Out) adds a nonlinear input gating (GLU) before the standard LRU's recurrence. This modification is directly motivated by the constructive proof: the input gating is needed to compute key-value outer products. The appendix compares multiple LRU variants: LRU Out (standard, output gating only), LRU In+Out (both input and output gating), and LRU In+Out (MLP) where the GLUs are replaced by 1-hidden-layer MLPs with matched parameter count — testing whether multiplicative interactions specifically are crucial or whether any nonlinearity suffices.

**Low-rank teacher experiment (Figure 3B).** For the experiment testing whether networks learn compressed low-rank representations: the input dimension is set to `$d=12$`, and the teacher's key, query, and value matrices are constructed by sampling random matrices and then **removing 6 singular values** (setting them to zero), creating matrices of rank 6. The effective required neuron count for the low-rank construction is `$r_{KQ}(r_V + 1) = 6 \cdot 7 = 42$`. The number of hidden neurons in the student is varied as a control parameter to identify the transition point where the loss drops.

#### In-Context Linear Regression Experimental Setup (Section 5)

The in-context learning experiments test whether gated RNNs discover attention-based algorithms when trained on tasks where attention is known to be a beneficial inductive bias.

**Task definition.** Each training "episode" corresponds to a unique linear regression problem defined by a weight matrix `$W^* \in \mathbb{R}^{d_y \times d_x}$` with `$d_x = d_y = 3$`, so `$d = d_x + d_y = 6$` (the input concatenates `$[x_t, y_t]$` into a single vector). The entries of `$W^*$` are sampled i.i.d. from `$\mathcal{N}(0, 1/3)$` (variance `$1/3$`). A sequence of `$T = 12$` observation pairs `$(x_1, y_1), \ldots, (x_T, y_T)$` is presented, where each `$x_t$` is sampled i.i.d. from the uniform distribution `$\mathcal{U}(-\sqrt{3}, \sqrt{3})$` (chosen to have variance 1, matching the variance scaling in the analytical derivation) and `$y_t = W^* x_t$`. At time `$T+1$`, a query input `$x_{T+1}$` is presented alongside a zero placeholder `$[x_{T+1}, 0]$`, and the network must predict `$\hat{y}_{T+1}$`. The loss is the squared error `$\|\hat{y}_{T+1} - W^* x_{T+1}\|^2$`, averaged over tasks.

**Validation distribution shift.** To test generalization beyond the training distribution, the validation set uses `$W^*$` matrices with entries sampled from `$\mathcal{N}(0, 2/3)$` — double the training variance. This tests whether the learned algorithm generalizes to regression problems with different weight magnitudes.

**Network configuration.** The gated RNN uses 80 hidden neurons by default. The input dimension is 6 (concatenation of `$x_t$` and `$y_t$`) and the output dimension is 3 (the predicted `$\hat{y}_{T+1}$`).

**Training details.** The optimization scheme is the same as the teacher-student experiment (AdamW, cosine annealing, `$\lambda$` parametrization) but with fewer total iterations — 300,000. The batch composition is not explicitly quantified in terms of number of tasks per batch, but the training loop processes sequences of length 13 (12 observations + 1 query).

**Baseline: one optimal step of gradient descent.** The paper analytically derives the optimal learning rate `$\eta^*$` for one-step gradient descent on the in-context linear regression task (Appendix D.2). The derivation yields:

$$\eta^* = \frac{1}{\sigma_x^2 (T + d_x - 1/5)}$$

where `$\sigma_x^2 = 1$` is the variance of the inputs (by construction, since `$x \sim \mathcal{U}(-\sqrt{3}, \sqrt{3})$` has variance 1), `$T = 12$` is the number of training examples, and `$d_x = 3$` is the input dimension. Plugging in: `$\eta^* = 1 / (1 \cdot (12 + 3 - 1/5)) = 1 / 14.8 \approx 0.0676$`. The corresponding loss with this optimal learning rate, averaged over the task distribution, is `$0.0947$`. This serves as the **optimality benchmark** — no linear self-attention layer can achieve lower loss on this task (Mahankali et al., 2023), so if the gated RNN approaches this loss, it has found the optimal attention-based solution.

**The gradient descent algorithm being implemented.** Starting from `$W_0 = 0$`, one step of gradient descent on the least-squares loss `$\frac{1}{2T} \sum_{t=1}^T \|y_t - W x_t\|^2$` yields the weight update:

$$\Delta W_0 = \frac{\eta}{T} \sum_{t=1}^T (y_t - W_0 x_t) x_t^\top = \frac{\eta}{T} \sum_{t=1}^T y_t x_t^\top$$

With `$W_0 = 0$`, the prediction is simply:

$$\hat{y}_{T+1} = \frac{\eta}{T} \sum_{t=1}^T y_t x_t^\top x_{T+1} = \frac{\eta}{T} \sum_{t=1}^T y_t \langle x_t, x_{T+1} \rangle$$

**Polynomial analysis to verify learned algorithm (Table 2).** To determine whether the trained RNN implements gradient descent, the paper analyzes the polynomial coefficients of its instantaneous function (as in Section 4.1). For the in-context regression task, the function implemented by the RNN at the query timestep is a polynomial of degree 4 in the variables `$\{x_{t,i}, y_{t,j}, x_{T+1,k}\}$`. The paper identifies the coefficients in front of terms of the form `$x_{T+1,i}^2 y_{T+1,j}$` (among all degree-3 and degree-4 monomials) and compares them to the coefficients that would arise from the optimal gradient descent solution.

The critical finding (Table 2): for the first output neuron of the trained RNN, the only terms with non-negligible coefficients are `$x_{T+1,1}^2 y_{t,1}$`, `$x_{T+1,2}^2 y_{t,1}$`, and `$x_{T+1,3}^2 y_{t,1}$`, all with coefficient approximately `$6.81 \times 10^{-2}$`. The optimal gradient descent coefficient is `$6.76 \times 10^{-2}$` (the analytically derived `$\eta^*/T$` value). The **residual norm** — the magnitude of all other polynomial coefficients — is `$1.35 \times 10^{-3}$`, essentially zero. This means the trained RNN has learned to compute **exactly** the gradient descent prediction, with the optimal learning rate, and with no other systematic structure.

**Transition experiment for low-rank discovery (Figure 3C).** The paper varies the number of hidden neurons in the gated RNN from small values to large values and measures the difference between the training loss achieved and the optimal gradient descent loss (`$0.0947$`). A sharp transition occurs: below approximately 18 neurons, the loss is substantially above optimal; above approximately 30 neurons, the loss drops to near-optimal. The paper notes this transition corresponds to the number of neurons prescribed by the low-rank construction for this specific attention configuration — though the exact expected neuron count for this task is not stated explicitly (it depends on the rank of the gradient-descent attention matrices, which in turn depends on `$d_x$`, `$d_y$`, and the data distribution).

## 4. Key Insights and Innovations

### Innovation 1: An Explicit, Finite-Neuron Constructive Equivalence Between Gated RNNs and Linear Self-Attention — Not Just Another Universality Result

The paper's most fundamental conceptual contribution is providing a **constructive proof** that gated recurrent neural networks can exactly implement linear self-attention using a finite number of neurons, with explicit weight values for every parameter. This may sound like a narrow theoretical result, but its intellectual significance lies in what it replaces and what it enables.

**What the field had before.** The theoretical relationship between RNNs and attention was governed by two classes of results, both insufficient for understanding whether practical RNNs actually implement attention-like computation. First, classical **universality theorems** (Boyd & Chua, 1985; Grigoryeva & Ortega, 2018) established that linear recurrent networks with nonlinear readouts can approximate broad classes of sequence-to-sequence maps — but only in the limit of infinitely many neurons. More recently, Orvieto et al. (2023a) proved universality for linear recurrences followed by nonlinear projections. These results tell you that attention *could in principle* be approximated by an RNN, but they provide no guidance on how many neurons are needed, what weight configurations achieve this, or — critically — whether gradient-based learning would ever discover such configurations. They are **existence theorems without constructive content**.

Second, a separate literature recognized **conceptual parallels between fast-weight memories and attention**. Schmidhuber (1992) proposed fast-weight controllers where one network generates weight changes for another, and Schlag et al. (2021) explicitly framed linear Transformers as "secretly fast weight programmers," noting that the outer-product update `$W^{\text{ff}}_t = W^{\text{ff}}_{t-1} + v_t k_t^\top$` resembles Hebbian learning in a synaptic weight matrix. This perspective was productive for motivating efficient attention implementations (Katharopoulos et al., 2020; Choromanski et al., 2021) and for drawing high-level analogies between architectures. However, it remained a **metaphor** — it did not provide a precise mapping between the parameter space of a specific RNN architecture and the parameter space of a linear self-attention layer.

**What makes this contribution distinctive.** The paper's construction provides something categorically different: for any specified linear self-attention layer with weight matrices `$W^V$`, `$W^K$`, and `$W^Q$`, it gives **concrete numerical values** for every weight in the gated RNN (Equations 9–14 in Appendix A.1) such that the two networks compute exactly the same output for all input sequences. The construction is not an approximation, not a limit, and not an asymptotic argument. It is exact, it uses `$O(d^2)$` neurons (not infinite), and every parameter has a defined value. This transforms the relationship from "RNNs might be able to approximate attention given enough capacity" to "here is precisely how an RNN encodes attention in its weights."

**Why this is more than a parlor trick.** The constructive proof serves as a **diagnostic instrument** for the rest of the paper. Because the construction is explicit, it makes specific, falsifiable predictions about what a trained network should look like if it has learned attention: (1) only neurons with `$\lambda = 1$` (perfect integrators) and `$\lambda = 0$` (perfect forgetters) should influence the output; (2) the integrator neurons should encode key-value outer products in a linearly decodable format; (3) the forgetter neurons should encode queries linearly; (4) the number of integrator neurons actually used (after pruning zero-weight connections) should match the theoretical minimum `$d(d+1)/2$` for the symmetric construction, not the naive `$d^2$`; and (5) when attention matrices are low-rank, the neuron count should compress accordingly. These are **strong, quantitative predictions** that the paper verifies in Section 4 — and none of them would follow from a mere universality argument or conceptual analogy.

The polynomial coefficient comparison (Table 1) is a direct consequence of this constructive mindset. Rather than asking "does the RNN approximate the teacher's outputs?", the paper asks "does the RNN implement the same polynomial function as the teacher?" — a question that makes sense only because the construction shows exactly what polynomial the RNN *should* implement if it has converged to the attention solution. The near-zero polynomial distance (`$3.73 \times 10^{-4}$`) is evidence not just of successful mimicry but of successful *structural convergence* to the specific weight configuration described by the construction.

**Assessment.** This is a **fundamental theoretical advance** rather than an incremental improvement. It provides something the field lacked: a precise, mechanistic understanding of how one architectural family (gated RNNs) can encode the computations of another (linear self-attention). The construction simultaneously explains *why* multiplicative gating and diagonal linear recurrence are the critical ingredients (they map to key-value outer product computation and memory accumulation, respectively) and *why* the equivalence is expensive (you need to explicitly store `$O(d^2)$` matrix entries in the hidden state). This dual role — as a bridge between architectures and as a diagnostic tool for interpreting trained networks — makes the construction the intellectual backbone of the entire paper.

### Innovation 2: Recurrent-to-Attention Equivalence Is Learnable — But Only for Architectures with the Right Inductive Bias, and the Most Common Architectures Largely Fail

The paper's second major insight is that **theoretical capability and empirical learnability are sharply decoupled** for different recurrent architectures. The constructive proof shows that RNNs *can* implement attention. The training experiments in Section 4 reveal which RNNs actually *do* — and, more importantly, which ones don't despite having the theoretical capacity.

**What the field assumed.** The dominant implicit assumption in architecture comparison research is that if an architecture is universal (can approximate any function given enough capacity), then differences between architectures are matters of statistical efficiency, sample complexity, or optimization dynamics — not fundamental barriers to representing certain functions. Under this view, one would expect that giving any sufficiently expressive architecture enough parameters and training time would allow it to learn attention. The question would be *how many samples are needed*, not *whether it's possible at all*.

**What the paper shows instead.** The architecture comparison in Figure 4A reveals a stark and non-obvious hierarchy. The simplified gated RNN of Equation 2 succeeds with very low loss. The standard LRU (which has only output gating via a GLU) performs substantially worse. Adding input gating to create LRU+ — a modification directly motivated by the construction, which shows input gating is needed to compute key-value outer products — dramatically improves performance. LSTMs, which the paper shows can theoretically implement attention in a single layer (Appendix B.3), perform at essentially the same poor level as GRUs, which **cannot** implement attention at all (Appendix B.4). Replacing the multiplicative GLU gating in the LRU with a 1-hidden-layer MLP of matched parameter count significantly degrades performance, confirming that multiplicative interactions specifically — not just nonlinearity in general — are essential.

**The conceptual significance.** This hierarchy tells us something deeper than "some architectures are better at this task." It reveals that **the inductive bias of an architecture toward a particular weight configuration can be effectively zero, even when that configuration exists in its parameter space**. The LSTM *has* a set of weights that would make it implement linear self-attention (Table 4 in Appendix B). But that weight configuration requires: (1) the forget gate bias to be large enough that `$\sigma(b_f) \approx 1$`, which saturates the sigmoid and kills gradients; (2) the tanh and sigmoid nonlinearities in the input and candidate gates to be effectively linear, which requires small weights in some matrices compensated by large weights in downstream matrices; and (3) precise coordination between the forget, input, and output gates. Training an LSTM with gradient descent to find this specific corner of its parameter space is, empirically, essentially impossible — the optimization landscape doesn't guide the network there, and the network finds other (inferior) solutions instead.

This is a **negative result with positive implications**. It tells architecture designers that **not all gating is created equal**: the specific placement and form of multiplicative interactions matters enormously for what functions the network can easily learn. Input gating before the recurrence and output or side gating after it create a strong inductive bias toward attention-like computation. Gating that is entangled with the recurrent state (as in LSTMs, where the gates depend on `$h_{t-1}$`) or that lacks the right multiplicative structure (as in GRUs) creates a much weaker or absent bias. This provides a principled explanation for the empirical success of architectures like Mamba and the LRU on tasks where attention-like processing is beneficial, and it suggests concrete architectural modifications (like adding input gating to the LRU, as the paper does with LRU+) to strengthen this bias.

**Evidence anchoring.** The claim is anchored in Figure 4A, which provides the loss comparison across architectures in the teacher-student task, and Table 3 (Appendix B), which summarizes the theoretical layer requirements. Figure 6 in the appendix extends the comparison to account for parameter counts, confirming that the differences are not an artifact of model size. The fact that the LRU+ modification (adding input gating) closes much of the gap to the simplified gated RNN is the cleanest single demonstration of the architectural claim: the theoretical construction identifies *which* component is missing, and adding that component empirically fixes the problem.

**Assessment.** This contribution reframes the question from "can architecture X implement attention?" (a binary, capability-focused question) to "does architecture X have the inductive bias to discover attention-like solutions through gradient-based learning?" (a graded, learnability-focused question). It introduces **inductive bias toward specific weight configurations** as a concept that sits between theoretical universality and empirical performance — a concept that future architecture design can explicitly optimize. This is a fundamental conceptual move with direct practical implications for architecture development, even though the paper itself does not propose a new architecture.

### Innovation 3: Trained RNNs Discover Optimal In-Context Learning Strategies Matched to Those of Attention — Providing a Unified Mechanistic Account Across Architectures

The paper's third insight bridges the gap between its theoretical equivalence results and the broader literature on what algorithms Transformers learn during in-context learning. The finding that gated RNNs trained on in-context linear regression converge to **exactly one step of gradient descent with the optimal learning rate** — the same algorithm that linear self-attention layers are provably constrained to implement (von Oswald et al., 2023; Mahankali et al., 2023) — demonstrates that the RNN-to-attention connection manifests not just in mimicry experiments but in **the algorithms that emerge from task-driven learning**.

**What prior work established.** A significant line of research studied in-context learning in Transformers and linear self-attention layers. von Oswald et al. (2023) showed that a linear self-attention layer trained on in-context linear regression learns to implement one step of gradient descent, with the prediction expressed as a weighted sum of training outputs:

$$\hat{y}_{T+1} = \frac{\eta}{T} \sum_{t=1}^T y_t \langle x_t, x_{T+1} \rangle$$

Mahankali et al. (2023) subsequently proved that this is not just what Transformers happen to learn, but the **provably optimal strategy** for a single layer of linear self-attention on this task — no other strategy achievable by the architecture can attain lower loss. Ahn et al. (2023) and Zhang et al. (2023) extended these results to preconditioned gradient descent and other variants.

However, these results were architecture-specific. They characterized what *linear self-attention layers* can and do learn, but they left open the question of whether recurrent architectures trained on the same task would discover the same algorithm or something entirely different. If RNNs converged to a different strategy — perhaps one that leveraged their recurrent state differently — that would suggest that in-context learning is fundamentally architecture-dependent. If they converged to the same gradient descent algorithm, that would suggest the algorithm is a more universal consequence of the task structure, discoverable by any architecture with the right computational primitives.

**What the paper establishes.** Section 5 provides multiple converging lines of evidence that gated RNNs learn the gradient descent algorithm:

- **Loss convergence (Section 5.2):** The trained RNN achieves a training loss of 0.0945, virtually identical to the 0.0947 optimal loss achievable by one gradient descent step. The RNN cannot be doing something meaningfully different from gradient descent, because if it were, it would either underperform the optimal (if its strategy were suboptimal) or outperform it (if its strategy were strictly more powerful — but that's impossible since gradient descent is provably optimal for the linear self-attention architecture, and the RNN is limited to similar polynomial computations).

- **Polynomial coefficient match (Table 2):** The instantaneous function of the trained RNN, expressed as a degree-4 polynomial in the inputs, has coefficients that match the optimal gradient descent coefficients to within `$10^{-4}$`. The only non-negligible coefficients are the `$x_{T+1,i}^2 y_{t,j}$` terms, and their values (`$6.81 \times 10^{-2}$`) match the analytically derived optimal `$\eta^*/T$` value (`$6.76 \times 10^{-2}$`). The residual norm (`$1.35 \times 10^{-3}$`) confirms that no other systematic structure is present.

- **Neuron count transition (Figure 3C):** The sharp transition in loss as the number of hidden neurons increases — from high loss with too few neurons to near-optimal loss with sufficient neurons, matching the transition predicted by the low-rank construction for this specific attention configuration — provides structural evidence that the RNN is not just achieving the right outputs but is organizing its internal representations according to the attention blueprint.

**The conceptual move.** This finding changes the narrative around in-context learning from "Transformers implement gradient descent" to "gradient descent is the natural algorithm that emerges when any architecture with the capacity to represent and accumulate outer products is trained on this task." It suggests that in-context learning research should focus less on the specific architectural instantiation (softmax attention vs. linear attention vs. RNNs) and more on the **computational primitives** that enable gradient-descent-like weight updates — specifically, the ability to store and update a matrix of input-output correlations and to query that matrix with new inputs.

This reframing has downstream implications. If the algorithm discovered is determined by the task structure and the available computational primitives rather than by architectural details, then the choice between RNNs and Transformers for in-context learning should be driven by efficiency considerations (inference memory, training cost) rather than by beliefs about which architecture is "capable" of in-context learning. The paper's FLOPs analysis is not in the in-context section, but the conceptual point carries forward: for tasks within the capability range, the architecture matters less than whether it has the right primitive operations.

**Connecting teacher-student and in-context results.** The paper's two experimental tracks — teacher-student mimicry and in-context task learning — are not independent. They form a coherent argument: the teacher-student experiments show that gated RNNs *can* learn to implement attention (the constructive proof is learnable); the in-context experiments show that gated RNNs *do* learn attention-based algorithms when the task calls for them (the equivalence manifests in natural learning scenarios, not just artificial mimicry). Together, they establish that attention-like computation is both architecturally possible and ecologically relevant for gated RNNs.

**Evidence anchoring.** Table 2 is the central piece of evidence, providing the coefficient-level comparison that rules out alternative algorithms. Figure 3C provides the structural evidence that the network's internal organization matches the attention blueprint. The analytical derivation of `$\eta^*$` in Appendix D.2 provides the benchmark against which the trained network is compared.

**Assessment.** This is a **conceptual integration** — it connects two previously separate literatures (RNN theory and Transformer in-context learning) by showing they are studying the same underlying phenomenon from different architectural perspectives. The contribution is not a new algorithm or architecture, but a **unified mechanistic account** of in-context learning across recurrent and attention-based models.

### Innovation 4: Verifying the Construction Requires a Novel Reverse-Engineering Methodology That Combines Pruning, Polynomial Analysis, and Neuron Classification

While the constructive proof and the empirical findings are the headline contributions, the paper also introduces a **reverse-engineering methodology** that is itself an intellectual contribution — one that enables the paper's empirical claims and provides a template for future mechanistic interpretability work on recurrent networks.

**What made this methodology necessary.** Determining whether a trained neural network implements a specific algorithm is a notoriously difficult problem. Standard evaluation metrics (test loss, accuracy) tell you whether the network's outputs match the target, but they cannot distinguish between a network that has genuinely learned the target function and one that has learned a different function that happens to approximate the target on the training distribution. This is the classic **identifiability problem** in mechanistic interpretability: many different internal mechanisms can produce the same input-output behavior on a finite dataset.

For the specific question at hand — does this trained RNN implement linear self-attention? — the challenge is compounded by several factors. First, the RNN's parameter space is highly redundant: the paper identifies multiple invariances (permutation of rows between the two gating matrices, multiplication-division of row pairs by constants, invertible transformations of `$W^Q$` compensated by the readout) that make direct weight comparison impossible. You cannot simply check whether the trained weights match the construction's weights, because many equivalent weight configurations exist. Second, many trained parameters become zero or near-zero, meaning only a subset of neurons actually contributes to the output — but identifying which subset requires careful analysis. Third, the RNN could implement a function that matches attention on the training distribution of random Gaussian inputs but diverges elsewhere, meaning distribution-level evaluation is insufficient.

**The components of the methodology and why they're non-obvious.**

**Pruning by exact zeros (not magnitude).** The paper's first step — pruning neurons whose input or output gating weights are *exactly* zero — is conceptually distinct from standard magnitude-based pruning. Most pruning methods remove small-but-nonzero weights based on a threshold or a target sparsity level, which changes the network's function. The paper's approach exploits a specific property of their experimental setup: the AdamW optimizer with weight decay drives many weights to exactly zero (a known phenomenon with decoupled weight decay), and the bilinear gating structure means that a neuron with all-zero input gating weights or all-zero output gating weights contributes nothing regardless of other parameters. This pruning is **function-preserving by construction** — it removes dead neurons without any approximation.

**Classification by `$\lambda$` value.** The observation that only `$\lambda = 0$` and `$\lambda = 1$` neurons influence the output is not a generic property of trained RNNs — it is a specific prediction of the attention construction, which requires perfect integrators and perfect forgetters. Finding that the trained network exhibits this binary `$\lambda$` distribution is evidence for the construction, but more importantly, it enables the subsequent analysis: knowing which neurons are integrators versus forgetters allows the paper to check whether integrators encode key-values and forgetters encode queries.

**Linear reconstruction of intermediate quantities.** Rather than trying to directly interpret individual neuron activations, the paper asks a simpler question: can the key-value matrix and query vector be *linearly decoded* from the activations of the appropriate neuron groups? If the integrator neurons contain an encoding of the key-value matrix, then some linear combination of their activations should exactly recover each matrix entry. The near-perfect reconstruction scores (`$4.52 \times 10^{-8}$` for key-values, `$2.06 \times 10^{-10}$` for queries) provide strong evidence without requiring the paper to identify *which* linear combination — the existence of the linear readout is sufficient.

**Polynomial coefficient comparison as a functional test.** This is the most novel component and the one that most clearly distinguishes the methodology from standard evaluations. Both the target attention layer and the gated RNN can be expressed as polynomials in the current input. For attention, the polynomial has degree 3; for the RNN, it has degree 4 (bilinear gating composed with bilinear gating). The paper compares the coefficient vectors of these two polynomials. This comparison is **distribution-independent**: if the degree-4 coefficients in the RNN are zero and the degree-0-through-3 coefficients match those of attention, then the two networks compute the same function for **all possible inputs**, not just those sampled from the training distribution. This is a much stronger claim than low test loss and directly addresses the identifiability problem.

**Kernel analysis for output gating compression.** The observation that three anomalous rows in the output gating (Figure 2B, rows 11–13) can be merged into one by analyzing the effective quadratic kernel they produce is a clever exploitation of the bilinear structure. The contribution of neuron `$j$` in the output gating to output dimension `$i$` is a quadratic form in the hidden state with kernel `$D_{i,j} W^{\text{out}}_{m,j} W^{\text{out},\top}_{x,j}$`. The paper shows that three neurons with different weight patterns can be functionally equivalent to a single neuron if the sum of their kernels is rank-1 — and that this merged neuron then matches the expected block structure. This illustrates a general invariance that future work could exploit.

**What makes this a contribution beyond this paper.** The methodology is not just a tool for verifying the paper's own claims — it is a general approach for reverse-engineering trained networks with bilinear multiplicative interactions. The combination of **(1)** exact zero-based pruning to identify functionally relevant neurons, **(2)** classification of neurons by their dynamical role (integrator vs. forgetter), **(3)** linear decoding of intermediate computational quantities, and **(4)** polynomial coefficient comparison to establish functional equivalence beyond the training distribution provides a template that could be applied to other architectures and tasks. The polynomial analysis in particular is underutilized in mechanistic interpretability, and this paper demonstrates its power for networks where the computation can be expressed as a low-degree polynomial.

**Assessment.** This is an **incremental but important methodological advance** — the individual techniques (pruning, linear probing, polynomial regression) exist in the literature, but their combination into a coherent pipeline for establishing functional equivalence between networks of different architectures is novel and enables the paper's core empirical claims. The methodology's value is demonstrated by its application: without it, the paper could only report that the RNN achieves low test loss, not that it has learned to implement attention. The polynomial coefficient comparison, in particular, elevates the evidence from "consistent with attention" to "inconsistent with any function other than attention."

## 5. Experimental Analysis

### Evaluation Methodology

- **Dataset and Data Generation.** The paper uses synthetic data throughout, with no fixed benchmark dataset. In the teacher-student experiments (Section 4), input sequences `$x_t \in \mathbb{R}^d$` are sampled i.i.d. from a normal distribution (specific parameters not stated), with sequence length 32. The teacher linear self-attention layer's weight matrices `$W^V$`, `$W^K$`, and `$W^Q$` are sampled i.i.d. from a normal distribution. In the in-context linear regression experiments (Section 5), each training "episode" generates a unique linear regression problem with weight matrix `$W^* \in \mathbb{R}^{3 \times 3}$` whose entries are sampled i.i.d. from `$\mathcal{N}(0, 1/3)$`, inputs `$x_t \in \mathbb{R}^3$` sampled i.i.d. from `$\mathcal{U}(-\sqrt{3}, \sqrt{3})$`, targets `$y_t = W^* x_t$`, with `$T = 12$` observation pairs followed by one query pair. The associative recall experiment (Appendix D.3) uses one-hot encoded inputs of size `$2T$` with `$T = 8$`.

- **Base Model(s).** The primary model studied is the simplified gated diagonal linear RNN defined in Equation 2, configured with input dimension matching the task (`$|x| = 4$` for teacher-student, `$|x| = 6$` for in-context regression), hidden dimension `$|h| = 100$` (teacher-student) or 80 (in-context regression), and output dimension matching the task. For architecture comparisons, the paper evaluates LSTMs, GRUs, and LRUs (Orvieto et al., 2023b) with matched input/output/hidden dimensions. The LRU is evaluated in three variants: standard (output GLU gating only), LRU+ with added input GLU gating, and LRU+ with the GLU replaced by a 1-hidden-layer MLP of matched parameter count. All architectures use a linear embedding layer before the recurrent layer(s) and a linear readout after, with no layer normalization, dropout, or skip connections. The recurrent layer is stacked once or twice depending on the architecture's theoretical requirements (Table 3).

- **Metrics.** For teacher-student experiments, the primary metric is **mean squared error (MSE) loss** between the student RNN's output and the teacher attention layer's output, reported as training loss (see Table 1: `$4.97 \times 10^{-8}$`). For functional equivalence verification: **(1) Score KV** is one minus the R² score of linear regression predicting the true key-value matrix entries from the activations of `$\lambda = 1$` neurons; **(2) Score Q** is one minus the R² score predicting the true query from `$\lambda = 0$` neurons; **(3) Polynomial distance** is the normalized Euclidean distance between the coefficient vectors of the degree-4 polynomial describing the RNN's instantaneous function and the target attention layer's degree-3 polynomial (averaged over output units). For in-context regression, the metric is **squared error loss** on the query prediction `$\|\hat{y}_{T+1} - W^* x_{T+1}\|^2$`, compared against the analytically derived optimal loss of `$0.0947$` (Appendix D.2).

- **Baselines.** In the teacher-student experiments, the baseline is the **teacher linear self-attention layer's output** — the objective is to match it exactly, so the "baseline" is the target itself. In the in-context regression experiments, the primary baseline is **one optimal step of gradient descent** with analytically derived learning rate `$\eta^* = 1/(T + d_x - 1/5)$` (Appendix D.2), which achieves loss `$0.0947$` and represents the provably optimal performance achievable by a single linear self-attention layer (Mahankali et al., 2023). The paper also uses the **construction of Section 3** as a conceptual baseline for the required neuron count.

- **Generation Budget / Compute Accounting.** The paper does not use "generation budget" in the sense of sampling multiple solutions. Instead, compute cost is measured by: **(1) number of hidden neurons** in the RNN (varied as a control parameter in Figures 3A, 3B, 3C to identify phase transitions); **(2) number of parameters** (used in the architecture comparison in Appendix Figure 6 to control for model size); and **(3) number of recurrent layers** (1 vs. 2 layers in architecture comparison). Training is single-pass — each sequence is presented once, so there is no resampling or best-of-N selection.

- **Cross-Validation / Statistical Protocol.** For the teacher-student experiments, the paper trains a single network to convergence, then analyzes it using the reverse-engineering pipeline described in Section 3.4 and Appendix C.2. The Score KV, Score Q, and Polynomial Distance metrics are computed on data sampled from the training distribution. For the in-context regression experiments, validation uses a shifted distribution where `$W^*$` entries are drawn from `$\mathcal{N}(0, 2/3)$` (double the training variance), testing generalization to harder regression problems. The loss values reported in Table 2 are averaged over 4 seeds; error bars on polynomial coefficients show standard deviations. The paper does not report confidence intervals or statistical significance tests for the main comparisons.

### Main Quantitative Results

#### Teacher-Student Mimicry: The Simplified Gated RNN Successfully Identifies the Teacher Function

The central quantitative result of Section 4 is that a gated RNN with sufficient hidden neurons can match a randomly initialized linear self-attention layer to near-machine precision, and the evidence for functional equivalence — not just output matching — is compelling across multiple independent metrics. The training loss of `$4.97 \times 10^{-8}$` (Table 1) confirms that on in-distribution inputs, the student's outputs are essentially identical to the teacher's. This would be a weak claim by itself, since many different functions could achieve low MSE on a finite sample. The reverse-engineering results in Table 1 make the stronger case:

- **Score KV of `$4.52 \times 10^{-8}$` and Score Q of `$2.06 \times 10^{-10}$`.** These near-zero values mean that the key-value matrix `$\sum_{t' \leq t} v_{t'} k_{t'}^\top$` and the query vector `$q_t$` can be **linearly reconstructed with essentially perfect fidelity** from the activations of the memory (`$\lambda = 1$`) and query (`$\lambda = 0$`) neurons respectively. This is not a trivial consequence of having many neurons — if the network were implementing a different function that merely matched outputs, there is no reason to expect its internal activations to encode these specific intermediate quantities. The near-perfect linear decodability strongly suggests the network is representing key-values and queries explicitly, as the construction prescribes.

- **Polynomial distance of `$3.73 \times 10^{-4}$` (averaged over 4 output units).** This is the strongest single piece of evidence for functional equivalence. The polynomial comparison covers the entire input domain, not just the training distribution. A distance near zero means that the degree-4 coefficients in the RNN's polynomial (which the attention layer lacks) are essentially zero, and that the degree-0-through-3 coefficients match those of the teacher. If the network had learned a different function that merely approximated the teacher on Gaussian inputs, the polynomial coefficients would diverge. The fact that they match globally confirms **exact functional equivalence**.

- **Post-pruning neuron count matches theoretical minimum.** After pruning neurons with zero input or output gating weights, the network retains exactly `$d(d+1)/2 = 10$` neurons with `$\lambda = 1$` (key-value accumulators) and `$d = 4$` neurons with `$\lambda = 0$` (query relays), for a total of 14 functionally relevant neurons — precisely the count prescribed by the symmetric construction of Section 3.2, not the naive `$d^2 + d = 20$` of the uncompressed construction. This confirms the prediction that the network discovers the more efficient symmetric representation rather than storing redundant matrix entries.

**Weight structure visualization (Figure 2).** The post-processed weight matrices in Figure 2B exhibit the expected block structure: the input gating's key-value rows have zero in their last column (no constant-term linear component) and the query rows have the constant term active to produce linear queries. The `$\lambda$` values are binary (0 or 1) with no intermediate values influencing the output. The output gating and readout show the selector-matrix structure needed to multiply key-values with queries and sum across query dimensions. The three anomalous rows in the output gating (rows 11–13) are shown in Figure 2C to be functionally equivalent to a single row: their combined contribution to each output dimension `$i$` forms a rank-1 kernel `$\sum_{j=11}^{13} D_{i,j} W^{\text{out}}_{m,j} W^{\text{out},\top}_{x,j}$` that is proportional across output units, allowing compression to a single structurally-conformant row without changing the function.

**Teacher identification requires mild overparameterization (Figure 3A).** When the number of hidden neurons is varied in the student (`$d=4$`), the loss remains high until approximately 14 hidden neurons, then drops sharply and stabilizes. This transition point matches `$d(d+1)/2 + d = 14$` — exactly the number of neurons required by the symmetric construction. The paper reports this as identification requiring "around twice as many neurons as the actual number of neurons required" — but the data in Figure 3A shows the transition at roughly the theoretical minimum itself, with consistent low loss achieved once the neuron count exceeds this threshold. The "twice as many" characterization appears to be approximate or averaged across experiments not fully shown.

**Low-rank teachers enable further compression (Figure 3B).** When the teacher attention matrices are constrained to rank 6 in `$d=12$` dimensions, the transition from high to low loss shifts dramatically leftward, occurring around `$r_{KQ}(r_V + 1) = 6 \cdot 7 = 42$` neurons rather than the `$d(d+1)/2 + d = 12 \cdot 13/2 + 12 = 90$` neurons that the full-rank symmetric construction would need. This confirms that the network is not just throwing capacity at the problem but is discovering the low-rank structure of the teacher and allocating neurons accordingly — consistent with the compressed construction of Appendix A.4.

#### Architecture Comparison: Only Architectures with the Right Multiplicative Structure Learn Attention

The comparison across recurrent architectures in Figure 4A (`$d=6$`) reveals a clear performance hierarchy that maps directly onto the theoretical analysis of which architectures can implement the necessary multiplicative computations. The key numbers (read approximately from Figure 4A since exact values are not stated in the main text):

- **Simplified gated RNN (diagonal or dense recurrence):** Achieves near-zero training loss, consistent with successful teacher identification. The dense variant performs comparably to the diagonal one, showing that diagonal recurrence is helpful but not strictly necessary.

- **LRU (standard):** Performs substantially worse than the simplified gated RNN. With 2 layers (the minimum theoretically required, per Table 3), the LRU fails to reach the low loss regime achieved by the simplified RNN with 1 layer. This is consistent with the theoretical analysis: the LRU has only output gating (via GLU) and must use the first layer's output gating as implicit input gating for the second layer, which introduces additional nonlinearity and training difficulty.

- **LRU+ (LRU In+Out):** Adding an explicit input GLU gating before the recurrence dramatically improves performance. This single modification — directly motivated by the constructive proof's requirement for input gating to compute key-value outer products — brings the LRU's performance much closer to the simplified gated RNN's. In Appendix Figure 6, the parameter-matched comparison shows that LRU+ with 1 layer achieves comparable loss to LRU with 2 layers despite having fewer parameters, confirming that the input gating provides a stronger inductive bias.

- **LSTM and GRU:** Both perform at chance level, with training loss orders of magnitude above the other architectures. This is noteworthy for different reasons for each: the GRU cannot implement attention at all (Appendix B.4 proves this), so its failure is theoretically expected. The LSTM can theoretically implement attention in a single layer (Appendix B.3, Table 4), but its failure demonstrates the gap between theoretical capability and empirical learnability — gradient descent does not find the extremely constrained weight configuration required. The published figure shows LSTM and GRU curves nearly overlapping, indicating they find similarly poor solutions despite their different theoretical capabilities.

- **LRU+ with MLP replacing GLU:** Significantly degraded performance compared to LRU+ with GLU, confirming that multiplicative interactions specifically — not just nonlinear processing — are necessary. The MLP has matched parameter count but cannot compute elementwise products, which are essential for key-value outer product computation.

**Two-layer vs. one-layer comparison (Appendix Figure 6):** Adding a second layer provides some improvement across architectures but does not qualitatively change the hierarchy — LRU+ with 1 layer still outperforms LRU with 2 layers, and the gated RNN with 1 layer outperforms all others. The parameter-matched curves in Appendix Figure 6 confirm that the differences persist even when controlling for model size.

#### In-Context Linear Regression: Trained RNNs Implement Optimal Gradient Descent

The in-context learning experiments (Section 5, `$d=6$`, `$T=12$`) establish that gated RNNs discover the same optimal strategy as linear self-attention layers when trained on in-context linear regression.

**Loss convergence to optimality.** The trained RNN achieves a training loss of `$0.0945$`, which is essentially identical to the analytically derived optimal loss of `$0.0947$` for one gradient descent step with optimal learning rate (Appendix D.2). This near-perfect match cannot be coincidental — if the RNN were implementing a different algorithm, it would almost certainly achieve either higher loss (if suboptimal) or lower loss (if it found a strategy strictly better than gradient descent, which is impossible given the provable optimality of gradient descent for the linear self-attention architecture; Mahankali et al., 2023).

**Polynomial coefficient evidence (Table 2).** The trained RNN's instantaneous function is analyzed as a degree-4 polynomial in the input variables. For the first output neuron, the only terms with non-negligible coefficients are:
- `$x_{T+1,1}^2 y_{t,1}$`: `$6.81 \times 10^{-2} \pm 8.52 \times 10^{-5}$`
- `$x_{T+1,2}^2 y_{t,1}$`: `$6.82 \times 10^{-2} \pm 6.40 \times 10^{-5}$`
- `$x_{T+1,3}^2 y_{t,1}$`: `$6.82 \times 10^{-2} \pm 5.56 \times 10^{-5}$`

All match the optimal gradient descent coefficient `$\eta^*/T = 6.76 \times 10^{-2}$` (computed as `$1/(T + d_x - 1/5) = 1/14.8$` divided by `$T=12$`). The **residual norm** — the magnitude of all other polynomial coefficients — is `$1.35 \times 10^{-3} \pm 1.97 \times 10^{-4}$`, essentially zero. This means the RNN has learned to compute exactly the gradient descent prediction, with no other systematic structure. The reported standard deviations across 4 seeds confirm this is a robust finding, not an artifact of a particular training run.

**Neuron count transition (Figure 3C).** When the number of hidden neurons in the RNN is varied, the difference between the RNN's loss and the optimal gradient descent loss (delta loss) shows a sharp transition: above approximately 20–30 neurons, the delta loss drops to near zero; below this threshold, it remains significantly positive. The paper notes this transition matches the neuron count prescribed by the low-rank construction, since the optimal gradient descent attention matrices (with `$W_0 = 0$`, `$W^V = W^K = I$`, and specific low-rank structure from the in-context task formulation) require fewer neurons than the full-rank construction would suggest. The exact expected count is not stated, but the observation is that the network compresses to the rank of the effective attention matrices.

**Validation generalization.** The validation set uses `$W^*$` entries drawn from `$\mathcal{N}(0, 2/3)$` — double the training variance. The paper reports that the trained RNN generalizes successfully (Figure 4B shows validation loss for the nonlinear architectures), demonstrating that the learned gradient descent algorithm transfers to regression problems with different weight magnitudes. This is expected for a proper algorithm (as opposed to memorized patterns), since gradient descent with the optimal learning rate depends only on the structure of the task, not on the specific `$W^*$` values.

#### Associative Recall: RNNs Discover an Efficient Variant of the Attention Solution

The associative recall experiment (Appendix D.3, `$T=8$`, one-hot encoded inputs) provides a complementary case study where the RNN discovers a solution that is related to but structurally more efficient than the literal attention implementation.

**Input-output gated RNN solution.** The trained RNN with input-output gating implements a **content-addressable memory** that differs from the attention construction. It assigns each possible output `$y$` a dedicated recurrent neuron with `$\lambda = 1$` that stores a learned embedding `$v_x$` of the associated input `$x$`. A separate neuron with `$\lambda = 0$` stores the embedding of the current query input. The output gating then computes the negative squared distance between the query embedding and each stored embedding: `$(-(v_{x_{T+1}} - v_{x(y)})^2)_y$`. Taking the argmax recovers the correct output, since the squared distance is zero (maximum value) for the matching pair and negative for non-matching pairs.

**Why this differs from literal attention.** The solution is more efficient because: (1) it stores only a scalar embedding per output class rather than a full matrix; (2) it uses the output gating to compute a similarity metric (negative squared distance) rather than a matrix-vector product. This works because the task is classification with non-repeating one-hot inputs — the structure of the problem allows a more compressed solution than full key-value matrix storage. The RNN discovers this more efficient strategy rather than the construction's approach.

**Side-gated RNN solution.** When the output gating is replaced with side gating (Appendix A.2), the RNN finds a different solution that is closer to the literal attention construction but with additional structure. Analysis of the learned matrices shows that `$W^{\text{in}}_x = W^{\text{side}} = [A | 0]$` and `$W^{\text{in}}_m = [0 | B]$` with `$D = B^\top$`, yielding output:

$$y_{T+1} = \sum_{t \leq T} M(x_t, y_t) \cdot x_{T+1}$$

where `$M(x,y)$` is a bilinear form. Analysis of `$M(u_i, u_j)$` for canonical basis vectors (Figure 7) reveals rank-1 matrices with a positive peak at the correct `$(i,j)$` position and a negative peak of equal magnitude elsewhere. The negative peaks do not affect classification because inputs are one-hot encoded, but they illustrate that the discovered solution contains structure beyond literal attention — binary patterns that exploit the one-hot nature of the inputs to use fewer effective dimensions.

**Assessment.** This experiment demonstrates that the RNN does not rigidly converge to the construction's specific weight pattern but rather discovers **attention-like solutions adapted to task structure** — using compression when the input structure permits it, while preserving the core mechanism of storing and querying associations.

#### Nonlinear Architectures for In-Context Learning: Non-Attention Architectures Can Outperform Gradient Descent

The comparison of nonlinear architectures on in-context linear regression (Figure 4B) reveals a finding that complicates the paper's central narrative: architectures with weaker inductive bias toward attention can actually **outperform** one gradient descent step on this task.

**The key numbers.** The loss achieved by different architectures at their best parameter count (read approximately from Figure 4B, validation set with doubled `$W^*$` variance):

- **GRU** achieves the lowest validation loss, despite being the architecture furthest from attention (theoretically incapable of implementing it). With sufficient parameters, GRUs substantially outperform one step of gradient descent.
- **LSTM** performs nearly as well as GRU.
- **LRU+** outperforms 1-step gradient descent but does not reach GRU/LSTM performance.
- **Standard LRU** (output gating only) performs significantly worse, close to the simplified gated RNN.
- **Simplified gated RNN** converges to near the optimal gradient descent loss and does not significantly surpass it — consistent with its strong inductive bias toward attention-like computation, which both enables and constrains it.

**Interpretation.** The superior performance of GRUs and LSTMs implies they are implementing a **more sophisticated algorithm than single-step gradient descent** — possibly multi-step optimization, learned preconditioning, or adaptive weighting of recent observations. This is possible because their nonlinear gating structure, while hindering the learning of exact linear self-attention (as shown in the teacher-student task, Figure 4A), provides additional computational flexibility that enables learning algorithms beyond what a single linear attention layer can implement.

**Correlation within LRU variants.** Within the LRU family, the paper notes (Appendix Figure 6 discussion) a high correlation between in-context learning ability and closeness to attention: adding input gating (LRU+) improves performance; replacing GLU with MLP (which cannot compute multiplicative interactions) degrades it significantly. This suggests that for architectures with attention-compatible structure, the inductive bias toward gradient-descent-like computation is beneficial in this low-parameter regime.

### Ablation Studies and Robustness Checks

**Diagonal vs. dense recurrence in the simplified gated RNN**: Changing the recurrence connectivity from diagonal to dense does not significantly affect performance in the teacher-student task (Figure 4A, the "dense" variant of the simplified RNN achieves comparable loss). This confirms that diagonal structure, while providing a useful inductive bias, is not strictly necessary for implementing attention — the critical components are the multiplicative gating operations, not the specific form of the recurrent connectivity. This is consistent with the construction: the `$\lambda$` vector controls per-neuron decay, and dense connectivity would require a full matrix that could be made equivalent to diagonal through a change of basis.

**Replacing multiplicative gating with an MLP (LRU In+Out MLP variant)**: When the GLU in the LRU is replaced by a 1-hidden-layer MLP with matched parameter count, performance degrades substantially in both the teacher-student task and the in-context regression task (Figures 4A, 4B, and Appendix Figure 6). This confirms that multiplicative interactions specifically — not just nonlinear processing capacity — are essential for implementing attention-like computation. An MLP can approximate multiplication given enough capacity, but the inductive bias toward discovering and using multiplicative structure is far weaker.

**Single-layer vs. two-layer configurations**: The architecture comparison tests recurrent layers stacked once or twice (Figure 4A, Appendix Figure 6). Adding a second layer universally improves or maintains performance, but does not qualitatively change the architecture hierarchy. Notably, LRU+ with 1 layer outperforms LRU with 2 layers despite having fewer parameters, confirming that architectural inductive bias matters more than raw capacity for this task.

**Parameter-matched comparison (Appendix Figure 6)**: To control for model size, the appendix compares architectures at matched parameter counts by varying hidden dimension. The hierarchy observed in Figure 4A persists: the simplified gated RNN and LRU+ variants achieve lower loss than LRU, LSTM, and GRU at comparable parameter counts. This rules out the alternative explanation that the simplified gated RNN succeeds simply because it has more parameters.

**Training vs. validation loss for in-context regression (Appendix Figure 6)**: The paper reports both training and validation losses for the in-context learning comparison, with validation using a shifted `$W^*$` distribution (double variance). The gap between training and validation is moderate for all architectures, confirming that learned solutions generalize beyond the training distribution. The GRU, LSTM, and LRU+ maintain their performance advantage on validation data, suggesting their learned algorithms are robust distribution-general strategies, not overfitted heuristics.

**Complex-valued vs. real-valued recurrence**: The LRU's recurrence is complex-valued by default; the paper uses only the real part (Section 3.3). This is a de facto simplification relative to the original LRU architecture and represents an implicit ablation: complex-valued recurrence is not needed for attention compatibility, since the construction uses real-valued perfect integration and forgetting.

**Sigmoid linearization assumption in theoretical LSTM construction**: The paper's LSTM construction (Appendix B.3, Table 4) requires linearizing the tanh and sigmoid nonlinearities, which demands small weights in certain matrices compensated by large weights elsewhere. The poor empirical performance of LSTMs in the teacher-student task (Figure 4A) can be viewed as an implicit ablation confirming that this linearization regime is not practically accessible via gradient descent — the theoretical capability exists, but the inductive bias toward it is too weak.

**ReST-EM revision model (Appendix K, Figure 16)**: Not applicable to this paper, which does not involve the iterative revision training described in the reference example's Section 6. The paper does not include reinforcement learning or EM-based optimization of its recurrent models.

**Number of neurons sweep (Figures 3A, 3B, 3C)**: Varying the hidden neuron count in the simplified gated RNN reveals sharp transitions at theoretically predicted values — `$d(d+1)/2 + d$` for full-rank teachers (Figure 3A), `$r_{KQ}(r_V + 1)$` for low-rank teachers (Figure 3B), and an intermediate count (approximately 20–30 neurons for `$d=6$`) for the in-context regression task (Figure 3C). These transitions are not gradual — the loss drops abruptly once the capacity threshold is crossed, suggesting that identification is a threshold phenomenon: below the required neuron count, gradient descent cannot find the attention solution; above it, the solution is reliably discovered.

**One-hot vs. distributed input encoding (Appendix D.3)**: The associative recall experiment uses one-hot encoded inputs, which the RNN exploits by learning binary embedding patterns (Figure 7). This is not presented as an ablation but effectively tests whether the RNN's solution adapts to sparse input structure — it does, finding a more compressed representation than the construction would prescribe. This suggests the RNN does not rigidly follow the construction blueprint but discovers structure-adapted variants.

### Critical Assessment

**Claim 1: "Gated RNNs can exactly implement linear self-attention."** This claim is **conclusively established theoretically** by the constructive proof in Section 3 and Appendix A.1, which provides explicit weight values for every parameter. No experiment is needed to verify the construction's correctness — it is a mathematical proof. However, the paper goes further and provides **strong empirical evidence** that the construction is discovered by gradient descent. Table 1's metrics (loss, Score KV, Score Q, Polynomial Distance) plus the post-pruning weight structure in Figure 2 provide multiple independent lines of evidence that the trained RNN has converged to a configuration functionally equivalent to the construction.

A genuine weakness is that this verification is performed for a single teacher attention layer and a single input dimension (`$d=4$`) in the main text. The low-rank experiments (Figure 3B, `$d=12$`) show the transition at the predicted neuron count, which is consistent with the construction being discovered at larger scales, but the full reverse-engineering analysis (polynomial coefficients, weight visualization, pruning to exact construction counts) is not repeated at `$d=12$`. This is partly understandable — the polynomial analysis at `$d=12$` would involve `$O(d^4)$` coefficients and be computationally intensive — but it means the most detailed verification is limited to a small scale. The paper does not discuss whether the same level of functional equivalence holds at `$d=12$` or whether identification becomes harder at scale.

Additionally, the construction requires the appended constant to produce pure-linear query neurons. This is an architectural detail that distorts the claim slightly: the gated RNN with the constant appended can implement attention, but a gated RNN *without* this constant would lack the ability to produce purely linear terms (everything would be bilinear in the input). This subtlety is handled in Appendix A.1 but not foregrounded in the main text's claim.

**Claim 2: "Gradient descent discovers the construction in practice, and the network compresses to the symmetric construction using `$d(d+1)/2$` neurons."** This claim is **strongly supported** by the teacher-student experiments. The post-pruning neuron count of exactly 10 memory neurons + 4 query neurons for `$d=4$` (matching `$d(d+1)/2 + d = 14$`) is a precise quantitative prediction confirmed by measurement. The binary `$\lambda$` distribution (only 0 and 1 affecting output) is another specific prediction confirmed. The polynomial distance near zero confirms that the learned function matches attention globally, not just on the training distribution.

A limitation is that this result is established for a single random teacher. The paper does not test across multiple teacher initializations, different distributions of teacher weights, or structured teacher matrices (e.g., orthogonal, sparse). The consistency across seeds is not reported for the teacher-student task — Table 1 lacks error bars, and the text does not state how many seeds were used. If the result holds only for some teacher initializations, the claim would need qualification.

**Claim 3: "When teacher attention matrices are low-rank, RNNs learn more compressed representations."** This is **supported by the transition experiment** in Figure 3B, where the loss drops at approximately `$r_{KQ}(r_V + 1) = 42$` neurons for a rank-6 teacher in `$d=12$` dimensions, rather than at `$d(d+1)/2 + d = 90$`. This is a clean demonstration that the network discovers and exploits low-rank structure. However, the experiment uses artificially constructed low-rank matrices (random matrices with singular values artificially set to zero). It does not test whether the compression occurs with naturally low-rank attention matrices, with approximately low-rank matrices (small but non-zero singular values), or at scales where the low-rank structure interacts with finite-precision training. The claim would be strengthened by showing compression with attention matrices that are low-rank due to the task structure (as in the in-context regression case, Figure 3C) rather than artificially constructed ones.

**Claim 4: "LSTMs and GRUs fail to learn attention, even though LSTMs theoretically can."** This claim is **supported by the architecture comparison** in Figure 4A, where LSTM and GRU losses are orders of magnitude above the gated RNN. For GRUs, this is theoretically expected (they cannot implement attention). For LSTMs, the result demonstrates a genuine gap between theoretical capability and practical learnability — an important negative result.

However, the experiments do not fully explore whether this gap can be bridged. The LSTM training uses the same hyperparameters (learning rate schedule, optimizer, batch size) as the simplified RNN. It is possible that different optimization settings — specifically, very large forget gate biases to push `$\sigma(b_f) \to 1$`, or specialized initialization that places the LSTM closer to the attention-compatible regime — could enable LSTMs to learn attention. The paper's theoretical LSTM construction (Appendix B.3) requires the forget gate bias to be `$+\infty$` (large positive) to achieve `$f_t \approx 1$`. Standard initialization (zeros or small values) places the forget gate at `$\sigma(0) = 0.5$`, far from the required regime. If the optimizer never finds the path to large forget gate biases (due to vanishing gradients in the saturation region), the LSTM will never discover attention. The paper does not test whether explicit initialization near the attention-compatible regime enables LSTM identification. This is an important missing experiment — without it, the claim that LSTMs "fail" might be a claim about standard initialization and optimization, not about the architecture's fundamental learnability.

**Claim 5: "Multiplicative interactions, not just nonlinearity, are necessary for attention."** This is **strongly supported** by the LRU+ (MLP) ablation (Figures 4A, 4B, Appendix Figure 6). Replacing the GLU's elementwise product with a 1-hidden-layer MLP of matched parameter count significantly degrades performance. However, there is a subtlety: the MLP can approximate multiplication given enough capacity (multiplication is a continuous function on compact domains). The experiment tests only one MLP hidden-layer size. A larger MLP might succeed where the matched-parameter MLP fails. The claim would be stronger with a scaling experiment showing that MLP performance does not catch up even with increased capacity, or with a theoretical argument about the number of parameters needed for an MLP to approximate the required outer products.

**Claim 6: "Gated RNNs trained on in-context linear regression implement optimal gradient descent."** This claim is **compellingly supported** by the loss convergence (`$0.0945$` vs. `$0.0947$` optimal), the polynomial coefficient match (Table 2), and the neuron count transition (Figure 3C). The polynomial analysis is particularly convincing because it rules out alternative algorithms that would produce similar outputs on the training distribution but differ in their functional form.

A limitation is that the verification is performed for a single task configuration (`$d=3$`, `$T=12$`, specific data distributions). The paper does not test whether the RNN learns gradient descent with different `$T$`, different `$d$`, different input distributions, or non-zero weight initialization (in the construction, `$W_0 = 0$`; von Oswald et al. (2023) showed Transformers can learn gradient descent from non-zero initial weights as well). The optimal learning rate formula depends on `$T$` and `$d_x$` (Appendix D.2); testing whether the RNN adapts its learned coefficients accordingly at different `$T$` would provide stronger evidence that it has learned a general algorithm rather than a specific set of coefficients.

Additionally, the claim that the RNN implements *exactly* gradient descent (as opposed to a close approximation) rests on the polynomial coefficients matching to high precision. While the match is impressive (`$6.81 \times 10^{-2}$` vs. `$6.76 \times 10^{-2}$`), the residual norm of `$1.35 \times 10^{-3}$` is not zero — it is small but measurable. Whether this represents optimization noise, numerical precision limits, or small systematic deviations from pure gradient descent is not explored. A more detailed analysis of the residual components might reveal whether the RNN has learned gradient descent plus a small correction term.

**Claim 7: "The side gating construction (Appendix A.2) reduces parameter cost from `$O(d^4)$` to `$O(d^3)$`."** This is a **theoretical claim** established by counting parameters in the alternative construction. It is not empirically tested — the paper does not train a side-gated RNN on the teacher-student task and verify that it learns the attention solution. The associative recall experiment uses side gating and finds a solution related to but different from the construction (Appendix D.3, Figure 7), but this is on a different task with one-hot inputs. The claim that side gating reduces parameter cost while preserving representational capacity is mathematically correct based on the construction but lacks empirical verification of learnability.

**Missing experiments that would have strengthened the paper:**

- **Teacher-student scaling**: Testing whether identification succeeds for larger `$d$` (e.g., `$d=8, 16, 32$`) and characterizing how the required overparameterization scales. At `$d=32$`, the symmetric construction requires `$d(d+1)/2 + d = 560$` neurons; does gradient descent find this with `$O(1000)$` hidden neurons, or does the optimization problem become harder at scale?

- **Multiple teachers**: Testing the same teacher-student protocol with multiple random teacher initializations to verify that identification is robust, not dependent on a particular teacher's weight values.

- **LSTM with attention-biased initialization**: Initializing the LSTM's forget gate bias to a large positive value (to start near `$f_t \approx 1$`) and testing whether this enables identification. This would clarify whether the LSTM's failure is due to optimization difficulty or a more fundamental limitation.

- **Parameter-matched scaling for the simplified RNN vs. attention**: Comparing the simplified gated RNN's parameter count at the identification threshold to the teacher attention layer's parameter count, to quantify the overhead of implementing attention in an RNN. Since the construction uses `$O(d^4)$` parameters vs. `$O(d^2)$` for attention, the paper could measure how much this gap shrinks when the network discovers compressed representations.

- **Varying `$T$` in in-context regression**: Testing whether the learned coefficients adapt to different numbers of in-context examples (different `$T$`), with the optimal learning rate changing according to the formula `$\eta^* = 1/(T + d_x - 1/5)$`. This would distinguish between learning a general algorithm and memorizing coefficients for the specific `$T=12$` setting.

- **In-context learning with a linear self-attention baseline trained identically**: Training an actual linear self-attention layer on the same in-context regression task with the same optimizer and data, and comparing the learned weights and polynomial coefficients to the RNN's. This would directly test the claim that both architectures converge to the same solution, rather than comparing the RNN to the analytically optimal solution.

**Overall assessment of the experimental evidence.** The paper's experiments are **well-designed to test its specific claims** and the evidence for the central results — that the simplified gated RNN discovers an attention-equivalent solution in the teacher-student task and that it learns optimal gradient descent in the in-context regression task — is strong and multi-faceted. The reverse-engineering methodology is a genuine strength, providing evidence at multiple levels (loss, internal representations, functional form) that converges on the same conclusion.

The main weaknesses are **scale** (experiments are at small `$d$` — 4, 6, 12), **completeness of architecture exploration** (the LSTM's failure is not fully characterized — is it an optimization or representation issue?), and **generality across task configurations** (the in-context learning result is shown for one specific `$T$, $d$`, data distribution). These are appropriate limitations for a paper whose primary contribution is theoretical (the constructive proof) with empirical validation of its practical relevance. The experiments convincingly demonstrate that the theoretical equivalence is not a formal curiosity but manifests in what gradient descent discovers, while leaving open questions about scaling, optimization sensitivity, and generalization across architectures that seed productive future work.

## 6. Limitations and Trade-offs

### The Parameter Cost of Exact Equivalence Is Prohibitively Large — Naively `O(d⁴)` and Still `O(d³)` with Side Gating

**The assumption or constraint.** The paper's constructive proof establishes that a gated RNN *can* exactly implement any linear self-attention layer, but at a steep parameter cost. The naive construction (Section 3.1, Appendix A.1) requires `d² + d` hidden neurons to store all key-value matrix entries plus the query vector, and `d²` output gating neurons. The input gating matrices each have size `(d² + d) × (d + 1)`, the output gating matrices each have size `d² × (d² + d)`, and the readout has size `d × d²`. The total parameter count is therefore `O(d⁴)` — specifically, dominated by the `~d⁴` entries in each output gating matrix. This is dramatically more than the `3d²` parameters of the linear self-attention layer being implemented. The alternative side gating construction (Appendix A.2) reduces this to `O(d³)`, but even this is a factor of `d` overhead. The paper acknowledges this explicitly (Section 6):

> "Our results partly serve as a negative result: implementation of attention is possible but requires squaring the number of parameters attention has."

The paper also states that "the RNN thus requires `O(d⁴)` parameters in total, with a lot of redundancy" (Section 3.2).

**The consequence.** For a practitioner considering whether to replace a linear self-attention layer with an equivalent gated RNN: at `d=64` (a modest attention head dimension in practice), the naive construction would require `d⁴ = 64⁴ ≈ 16.8` million parameters in each output gating matrix alone, versus `3d² ≈ 12,288` parameters for the attention layer — an overhead factor of over 1000×. Even the compressed symmetric construction with side gating, scaling as `O(d³)`, would require millions of parameters where the attention layer requires thousands. This is not merely a constant-factor overhead — it means that for realistic input dimensions, the equivalent RNN would be impractically large. The paper's identification experiments operate at `d=4` (where the overhead is manageable: `4⁴ = 256` vs. `3·16 = 48`) and `d=12` (where the construction requires ~90 neurons in the symmetric case). These are far below the dimensions used in practical attention layers. The theoretical equivalence therefore does not translate to a practical deployment strategy — nobody would replace a 12K-parameter attention layer with a multi-million-parameter RNN to achieve the same function.

**What evidence exists in the paper.** The parameter scaling is derived in Section 3.2 and Appendix A.1, not measured empirically — and no experiment at realistic input dimensions (`d > 12`) is attempted. The paper's experiments use `d=4` (Section 4.1), `d=6` (Section 5, architecture comparison), and `d=12` (low-rank teachers in Figure 3B). The absence of larger-scale experiments is consistent with the `O(d⁴)` scaling making such experiments computationally infeasible. The paper does not report parameter counts for the trained networks or compare them to the teacher attention layer's parameter count — a notable omission given the centrality of the overhead argument.

**Mitigation status.** The paper identifies two compression mechanisms that reduce the overhead in specific circumstances: symmetry of the key-value matrix when key and value matrices are equal (Section 3.2, reducing required neurons from `d²` to `d(d+1)/2`), and low-rank structure in the attention matrices (Appendix A.4, reducing required neurons to `r_KQ · r_V + r_KQ` where `r` denotes rank). The paper shows empirically that trained networks discover these compressed representations (Figures 3A, 3B). However, neither mechanism fundamentally changes the asymptotic scaling: symmetry reduces the constant but preserves `O(d²)` neurons and `O(d⁴)` total parameters; low-rank compression helps only when the ranks are sub-linear in `d`. The paper acknowledges this as an open question (Section 6):

> "We have shown that gated RNNs can leverage possible compression, but understanding whether real-world attention mechanisms lie in this regime remains an open question."

This is a candid admission that the practical relevance of the construction depends on how much compression is possible for realistic attention heads — an empirical question the paper does not answer. The paper does not propose any mechanism (architectural modification, structured parameterization) that would reduce the asymptotic scaling.

### The Equivalence Applies Only to Linear Self-Attention — Not to Standard Softmax Attention as Used in Transformers

**The assumption or constraint.** The entire constructive proof, all teacher-student experiments, and all in-context learning analysis are restricted to **linear self-attention** — the variant obtained by removing the softmax nonlinearity from standard attention. The paper explicitly defines its target function (Section 2.1, Equation 1) as:

> "We study causally-masked linear self-attention layers that process input sequences `(x_t)_t` with `x_t ∈ ℝᵈ` as follows: `y_t = (∑_{t'≤t} (W^V x_{t'})(W^K x_{t'})^⊤) (W^Q x_t)`"

The softmax-based attention used in Transformers computes instead:

$$y_t = \sum_{t' \leq t} \frac{\exp(q_t^\top k_{t'})}{\sum_{t'' \leq t} \exp(q_t^\top k_{t''})} v_{t'}$$

where the normalization over all previous keys introduces a **nonlinear, non-additive memory mechanism** — the contribution of each past value depends not only on its own key but on all other keys in the sequence through the partition function. The paper states (Section 2.1) that:

> "Such linear self-attention layers can be understood as a linearized version of the softmax attention mechanism. Yet, they operate in a very different regime than softmax layers, which have unbounded memory."

**The consequence.** The paper's title ("Gated recurrent neural networks discover attention") and framing suggest a connection to attention mechanisms broadly, but the proven equivalence covers only the linearized variant. Softmax attention has fundamentally different computational properties that the RNN construction cannot replicate: (1) the softmax normalization requires access to all previous keys to compute the partition function, meaning the memory cannot be purely additive — you cannot simply accumulate key-value outer products and later divide by an accumulated normalization factor because the normalization is query-dependent; (2) softmax attention's effective memory is selective and input-dependent in a way that defies the linear accumulator model; (3) the inductive bias of softmax attention for tasks requiring sharp discrimination between attended and non-attended tokens (which the softmax provides through exponential scaling) is absent in both linear attention and the equivalent RNN.

This matters profoundly for the claim that RNNs "might be unexpectedly implementing attention under the hood" (Abstract). If a practitioner trains an RNN and finds it performs well, the paper's results provide evidence that it might be implementing **linear** attention. But for the vast majority of deployed Transformer models, "attention" means **softmax** attention, and the paper's equivalence proof says nothing about whether RNNs can implement that more powerful mechanism. The distinction between linear and softmax attention is not a minor technical nuance — it is the difference between a mechanism that can sharply focus on a single token (softmax) and one that computes a distributed weighted average (linear). Conflating the two overstates the paper's contribution to understanding practical Transformers.

**What evidence exists in the paper.** No experiments involve softmax attention as a teacher. No theoretical analysis attempts to extend the construction to approximate or bound the softmax case. The paper does not discuss what would be required to implement softmax attention in an RNN (e.g., whether an RNN could approximate the softmax normalization by storing additional running statistics, or whether the exponential nonlinearity introduces fundamental barriers). Section 6 mentions only "Transformers" and "attention" broadly when discussing implications, without acknowledging the linear-vs-softmax distinction as a limitation of the transfer.

**Mitigation status.** Not addressed. The paper's framing ("These modern RNNs feature a prominent design pattern: linear recurrent layers interconnected by feedforward paths with multiplicative gating. Here, we show how RNNs equipped with these two design elements can exactly implement (linear) self-attention" — Abstract, emphasis in original) parenthetically acknowledges "linear" but the broader narrative consistently refers to "attention" without qualification. A reader skimming the abstract and introduction would reasonably conclude the paper establishes an RNN-attention equivalence without realizing the crucial linearity restriction. The paper would be strengthened by explicitly discussing what properties of softmax attention are captured and what are lost in the linear case, and whether any path exists for extending the construction to approximate softmax attention.

### The Difficulty Estimation and Difficulty-Conditioned Analysis Framework Is Absent — There Is No Adaptive Mechanism

**The assumption or constraint.** The paper's experimental protocol treats all input sequences uniformly — the same network architecture with the same weights processes every sequence identically. There is no difficulty estimation, no adaptive compute allocation, and no mechanism for varying the amount of computation based on the properties of the input. This is a deliberate choice appropriate for the paper's goal of establishing functional equivalence, but it means the paper does not engage with a question that the reference example's framework highlights as critical: **does the RNN's attention-like computation have the same difficulty-dependent scaling properties as attention itself?**

In the reference example, the key innovation is compute-optimal test-time scaling: allocating more or different computation based on estimated prompt difficulty, achieving 4× efficiency gains. The present paper asks only whether the RNN *can* implement attention, not whether it should implement attention *for every input* or whether the implementation's quality varies with input properties.

**The consequence.** Several important practical questions are unaddressed:
- **Does the quality of the RNN's attention approximation degrade for certain inputs?** The polynomial coefficient comparison (Table 1, Section 4.1) establishes global functional equivalence, but this was demonstrated for `d=4` with a randomly initialized teacher. For larger `d` or more structured inputs, the RNN might faithfully implement attention on some inputs but fail on others — there is no difficulty-conditioned analysis to detect this.
- **Is the required neuron count difficulty-dependent?** The paper shows (Figures 3A, 3B, 3C) that neuron count thresholds exist for successful identification, but these are averaged over all inputs. It is possible that some input distributions are "harder" to represent with fewer neurons, requiring more capacity for equivalent fidelity. The paper's neuron-sweep experiments average over the entire input distribution, potentially masking such heterogeneity.
- **Could an adaptive architecture switch between attention-like and non-attention modes?** If attention is beneficial for some inputs but not others, a network that rigidly implements attention on all inputs might be suboptimal. The paper's framework does not explore dynamic allocation of computation.
- **In the in-context learning setting**, does the RNN's gradient-descent implementation break down for out-of-distribution inputs (larger `‖x‖`, correlated features, non-Gaussian inputs)? The validation test uses doubled `W*` variance but fixed input distribution — it does not probe the robustness of the attention implementation to distribution shift in the inputs themselves.

**What evidence exists in the paper.** The paper does not include difficulty estimation, per-input analysis of approximation quality, or adaptive compute allocation. The closest it comes is the architecture comparison for in-context learning (Figure 4B), where validation uses a shifted `W*` distribution — but this tests generalization of the learned *algorithm*, not difficulty-dependent scaling of the *implementation*. The polynomial coefficient comparison in Table 1 is a global test (distance averaged over the full polynomial), not a per-input test that would reveal input-dependent failures.

**Mitigation status.** Not addressed and not identified as a limitation. This is not a flaw in the paper per se — the paper's goals are theoretical and demonstrative, not to build a practical system — but it represents a significant gap for anyone seeking to deploy attention-mimicking RNNs. Without understanding when the equivalence degrades (if at all), a practitioner cannot reliably substitute an RNN for an attention layer in a critical application.

---

### All Experiments Use Synthetic Data and a Single Model Family — Generalization to Real Tasks and Other Architectures Is Unverified

**The assumption or constraint.** Every experiment in the paper uses synthetic data generated from simple distributions: i.i.d. Gaussian or uniform inputs for teacher-student mimicry (Section 4), i.i.d. Gaussian `W*` matrices and uniform inputs for in-context regression (Section 5), and one-hot encoded inputs for associative recall (Appendix D.3). The models studied are the authors' own simplified gated RNN architecture (Equation 2), plus standard implementations of LSTMs, GRUs, and LRUs (Orvieto et al., 2023b) — all from a single research lineage and codebase. The paper states (Section 4):

> "We believe this model is representative of the capabilities of many contemporary LLMs"

but this claim refers specifically to the **architecture**, not to the tasks or data. No real-world benchmark (e.g., Long Range Arena, language modeling, translation) is evaluated, and no model outside the authors' control is tested.

**The consequence.** The paper establishes that gated RNNs can implement linear attention on synthetic data where the data distribution is stationary, the sequence length is moderate (32 timesteps for teacher-student, 13 for in-context regression), and the target function is exactly a linear self-attention layer. Whether the same phenomena manifest under more realistic conditions is entirely untested:

- **Distribution shift and non-stationarity:** Real NLP and vision sequences are not i.i.d. Gaussian. If the input distribution is heavy-tailed, multimodal, or contains structured dependencies (grammar, scene geometry), the RNN might fail to learn an attention-equivalent function, or the learned equivalence might degrade on certain subsequences.
- **Long sequences:** The experiments use sequence lengths of 32 (teacher-student) and 13 (in-context regression). One of the primary motivations for studying RNNs is their advantage on very long sequences (constant memory cost). Whether the construction remains learnable at sequence lengths of thousands or millions of tokens, where gradient-based optimization of recurrent networks is notoriously difficult, is unknown.
- **Discrete tokens and embeddings:** Real language models operate on discrete token sequences embedded in learned continuous spaces. The multiplicative gating construction relies on precise numeric relationships that might be disrupted by the embedding layer's learned geometry.
- **Interaction with other architecture components:** Production Transformers and RNNs use layer normalization, residual connections, multi-head attention, feedforward layers, and dropout — all absent from this paper's minimal architectures. Whether the attention-equivalence construction survives or remains learnable when these components are present (e.g., layer normalization altering the effective input distribution) is unexplored.
- **Multiple attention heads:** The paper studies a single attention head. Whether multi-head attention can be implemented by stacking the construction, and whether gradient descent would discover multi-head solutions in a deeper RNN, is not addressed.

**What evidence exists in the paper.** The paper's experiments cover only synthetic data. The teacher-student task (Section 4) uses Gaussian inputs and Gaussian teacher weights. The in-context regression task (Section 5) uses uniform inputs and Gaussian `W*`. The associative recall task (Appendix D.3) uses one-hot encodings — a maximally sparse, structured input that permits shortcuts (as the RNN exploits with binary embeddings). The paper does not include experiments on natural language, images, audio, or any standard benchmark. The architecture comparison (Figure 4A) is limited to models implemented by the authors in their codebase.

**Mitigation status.** The paper does not claim to have demonstrated the equivalence on real-world tasks and does not overstate the generality of its empirical results. The abstract carefully qualifies "on certain sequence modeling tasks" in reference to prior work, and Section 6 states:

> "This highlights the need for further investigations on the differences between RNNs and Transformers in controlled settings, as also advocated by (Garg et al., 2022)."

However, the paper's framing — particularly the title and abstract's suggestion that RNNs "might be unexpectedly implementing attention under the hood" — implies a generality that the experiments do not support. The "under the hood" finding is demonstrated for synthetic Gaussian data in small dimensions, not for any realistic deployment scenario. A practitioner reading the paper should understand that the attention equivalence is an in-principle capability of the architecture, not a demonstrated property of trained RNNs on practical tasks.

---

### The LSTM's Theoretical Capability to Implement Attention Is Not Reconciled with Its Empirical Failure — The Limitation Is in Optimization, Not Architecture, and the Paper Does Not Distinguish These

**The assumption or constraint.** One of the paper's central empirical claims is that LSTMs fail to learn attention despite theoretically being capable of doing so (Section 4.3, Figure 4A). The paper's theoretical analysis (Appendix B.3, Table 4) provides explicit LSTM weights that implement linear self-attention in a single layer, requiring that: (1) the forget gate `f_t = σ(U_f x_t + V_f h_t + b_f)` saturates at `σ(b_f) ≈ 1` (meaning `b_f` must be large positive); (2) the tanh in the candidate cell state and the sigmoid in the input gate are effectively linear, requiring small weights `U_c` and `U_g` compensated by large downstream weights; and (3) the output gate encodes the query.

The paper trains the LSTM with standard initialization and the same optimization hyperparameters as the simplified gated RNN. It does not test whether an LSTM initialized near the attention-compatible regime — with large positive `b_f` and small `U_c`, `U_g` — can learn to implement attention.

**The consequence.** The paper's claim that "gradient descent does not find such a solution and the performance of LSTMs is close to that of GRUs that cannot implement attention" (Section 4.3) conflates two distinct failure modes: **(a)** the LSTM architecture lacks the capacity to represent attention (false — Appendix B.3 proves it does), and **(b)** standard gradient-based training from standard initialization fails to discover the representing weights. These are fundamentally different. If the failure is due to (b), it might be fixable with better initialization, different optimization (e.g., higher learning rate on the forget gate bias, curriculum learning), or architectural modifications (e.g., removing the tanh nonlinearity from the candidate cell state, or using a hard sigmoid for the forget gate). The paper does not attempt any of these.

This matters because the paper's architectural recommendation — that "the inductive bias towards attention-compatible configurations might be weaker for [LSTMs] than for deep gated linear RNNs" (Section 1) — could lead practitioners to dismiss LSTMs for attention-intensive tasks when the real issue might be optimization and initialization, not architecture. If an LSTM with proper initialization can learn attention, then the conclusion is about training methodology, not architectural constraints.

**What evidence exists in the paper.** Figure 4A shows LSTM training loss in the teacher-student task is orders of magnitude above the gated RNN. No experiment varies LSTM initialization, forget gate bias, or optimizer settings. No experiment tests whether an LSTM with a frozen `f_t = 1` (by setting `b_f` large and freezing it) can learn the remaining attention parameters. The paper does not analyze *why* gradient descent fails — whether because it gets stuck in a poor local minimum, because gradients vanish in the saturated forget gate regime, or because the loss landscape does not guide the optimizer toward the attention solution. The paper's theoretical LSTM construction requires `b_f = +∞` in the table (Table 4 in Appendix B), but training with gradient descent cannot reach or navigate `b_f → ∞` due to the sigmoid's saturation.

**Mitigation status.** The paper acknowledges that the LSTM construction "requires a very specific configuration" (Section 1), but treats this as evidence of weak inductive bias rather than as an open optimization problem. No mitigation is attempted, and the limitation is not explicitly identified as a gap between theoretical capability and experimental protocol. Future work is not specifically suggested for bridging the LSTM gap — the paper's outlook focuses on the simplified gated RNN and LRU variants.

---

### The Reverse-Engineering Verification Is Thorough at `d=4` But Not Replicated at Larger Scales — the Identifiability of the Construction at Practically Relevant Dimensions Is Unproven

**The assumption or constraint.** The paper's most detailed reverse-engineering analysis — the full pipeline of pruning, neuron classification by `λ` value, linear reconstruction of key-values and queries (Score KV, Score Q), weight matrix visualization, and polynomial coefficient comparison — is performed only for the teacher-student experiment at `d=4` (Section 4.1, Figure 2, Table 1). At `d=12` (the low-rank teacher experiment, Figure 3B), the analysis is limited to observing the loss transition at the predicted neuron count threshold. At `d=6` (architecture comparison, Figure 4A), only the loss is reported. None of the finer-grained reverse-engineering analyses (polynomial coefficients, neuron classification, weight structure visualization) are replicated for `d=6`, `d=12`, or the in-context regression task (`d=6` except for Table 2's polynomial analysis of the learned algorithm).

**The consequence.** The paper's central empirical claim — that gradient descent discovers the construction — is established with high confidence at `d=4` but only indirectly supported (through loss convergence and neuron count transitions) at larger `d`. Several failure modes become more likely at scale:
- **Partial convergence**: At larger `d`, the optimizer might find a solution that approximates attention well on the training distribution (achieving low loss) but does not have the exact binary `λ` structure, the perfect linear decodability of key-values, or the degree-4-coefficient cancellation of the construction. The loss-based verification at `d=6` and `d=12` would not detect this — it would report "identification succeeded" while the network implements a different function that happens to match the teacher on the training data.
- **Incomplete pruning**: The exact-zero pruning used at `d=4` might not apply at larger scales if weight decay does not drive unused weights to exactly zero, only to small magnitudes. Magnitude-based pruning changes the function, so one cannot distinguish between approximately-zero weights (the network slightly deviating from the construction) and exactly-zero weights (the construction was discovered).
- **Degraded internal representations**: The Score KV and Score Q metrics might degrade from near-perfect (10⁻⁸ at `d=4`) to moderate values at larger `d`, indicating the network is representing key-values approximately but not exactly — a weaker form of equivalence that the paper's "exact implementation" framing does not encompass.
- **The polynomial analysis at `d=6` for in-context regression** (Table 2) covers the learned *algorithm* (confirming gradient descent) but does not verify that the RNN's *implementation architecture* matches the construction — it verifies the functional form of the output, not the internal organization of the network (neuron types, key-value encoding structure, gating structure).

**What evidence exists in the paper.** The loss transition at the predicted neuron count threshold is observed at `d=12` (Figure 3B) and for the in-context regression task (Figure 3C). These transitions are **consistent with** the construction being discovered but do not **confirms** it. An alternative explanation: when the RNN has too few neurons, it cannot achieve low loss regardless of what function it implements; when it has enough neurons, it can achieve low loss through some other function class that happens to include an approximation to the teacher. The neuron count being *necessary* for the construction is established by the theory; the neuron count being *sufficient* for identification (and thus for the construction being the discovered solution) is what the experiments test — but the transition could also reflect a generic capacity threshold for a different function class.

**Mitigation status.** The paper does not discuss the scalability of its reverse-engineering methodology or acknowledge that the `d=4` analysis is not replicated at larger dimensions. This is a practical limitation — the polynomial coefficient analysis scales exponentially with `d` (the number of degree-4 monomials is `O(d⁴)`), making it computationally infeasible for large `d`. The paper does not propose approximate or scalable alternatives. A practitioner reading the paper should understand that the strongest evidence for the construction's learnability comes from the smallest-scale experiment, and that the larger-scale evidence is consistent with but does not confirm the construction.

## 7. Implications and Future Directions

### How This Work Changes the Landscape

This paper shifts the conceptual relationship between recurrent neural networks and attention mechanisms from one of architectural competition to one of **computational equivalence under specific conditions**. Before this work, RNNs and Transformers were typically understood as distinct architectural families with different inductive biases, different training dynamics, and different suitability for various tasks. The present paper demonstrates that this distinction is, in an important sense, **artifactual rather than fundamental**: a gated RNN with the right multiplicative interactions can encode exactly the same computation as a linear self-attention layer, and gradient descent discovers this encoding when trained on appropriate data.

**The magnitude of this shift is best characterized as a reframing rather than a paradigm shift.** The paper does not propose a new architecture, training method, or application. Instead, it provides a **precise, mechanistic bridge** between two previously disconnected model classes. This bridge transforms how researchers should think about the relationship between recurrence and attention:

- **Before**: "RNNs and Transformers are different architectures with different computational properties — choose based on your constraints (memory, sequence length, task modality)."
- **After**: "Gated RNNs with multiplicative interactions and linear recurrence can implement linear self-attention exactly. Therefore, when such an RNN performs well on a task, it may be doing so by discovering an attention-like algorithm encoded in its weights, not by leveraging some fundamentally different recurrent computation. The architectural choice is less about what computations are *possible* and more about what computations are *easily discoverable* through gradient-based learning."

This reframing has several concrete consequences for how the field thinks about architecture design:

**It resolves the apparent contradiction in recent architectural trends.** The paper notes (Section 1) that two seemingly unrelated lines of work — deep linear RNNs achieving Transformer-competitive performance, and efficient linearized attention models achieving RNN-like inference — have been progressing in parallel. This paper shows that this convergence is not coincidental: both are converging on architectures that can express attention-like computation, because linear recurrence plus multiplicative gating is precisely what is needed. The contradiction dissolves when you recognize that these "different" architectures are capable of implementing the same underlying algorithm. The practical question becomes not "which architecture is better?" but "which architecture's inductive bias and parameter efficiency make it easier to learn attention-like computation for a given task?"

**It redirects architecture research from capability questions to learnability questions.** A major intellectual contribution of this paper (discussed in Innovation 2 of Section 4) is demonstrating that theoretical capability and empirical learnability can be sharply decoupled. LSTMs *can* implement attention (Appendix B.3, Table 4) but gradient descent from standard initialization does not find this solution (Figure 4A). GRUs *cannot* implement attention at all (Appendix B.4). This tells architecture designers that the relevant question is not "can my architecture express function X?" — universality theorems answer that in the affirmative for most architectures — but rather "does my architecture's parameterization and optimization landscape guide gradient descent toward solutions that implement function X when that function is useful for the task?" This is a more nuanced and practically relevant question, and the paper provides a template for investigating it: **(1)** establish constructive mappings between architectures and target computations, **(2)** identify the weight configurations needed, **(3)** test whether those configurations are reachable through standard training, and **(4)** characterize the gap between theory and practice when it exists.

**It provides a unifying mechanistic account of in-context learning across architectures.** The finding that gated RNNs trained on in-context linear regression converge to the same gradient-descent-based algorithm that Transformers learn (Section 5, Table 2) connects two previously separate literatures. Prior work (von Oswald et al., 2023; Mahankali et al., 2023; Ahn et al., 2023; Zhang et al., 2023) characterized what linear self-attention layers learn when trained on in-context tasks. The present paper shows that this is not a Transformer-specific phenomenon — it is a consequence of the task structure plus the availability of computational primitives for storing and querying pairwise input-output associations. Any architecture that can accumulate outer products (as gated RNNs do) and query them with new inputs (as gated RNNs do through output gating) can discover the same algorithm. This reframes in-context learning research from "what algorithms do Transformers learn?" to "what algorithms do architectures with associative memory primitives learn, and under what conditions?" — a more general and potentially more productive framing.

**It makes certain research directions less attractive by clarifying fundamental costs.** The paper's explicit characterization of the parameter overhead — `O(d⁴)` parameters for the naive construction, `O(d³)` with side gating, versus `O(d²)` for the attention layer itself — provides a sobering reality check. If you want to replace a linear self-attention layer with an equivalent gated RNN, you pay a quadratic-to-quartic overhead in parameter count. This makes the literal "replace attention with an equivalent RNN" research direction unattractive for practical applications at realistic dimensions. However, the paper's compression results (symmetric key-value matrices reducing neurons from `d²` to `d(d+1)/2`, low-rank attention matrices reducing to `r_KQ · r_V`) suggest that the overhead might be much smaller when attention heads have structure — as they often do in practice. Research on **when and how much compression is possible** for real-world attention patterns becomes much more attractive than research on architecture designs that try to directly implement the construction.

**It strengthens the case for multiplicative gating as a critical architectural primitive.** The paper's ablation showing that replacing multiplicative gating (GLU) with a matched-parameter MLP significantly degrades performance on both teacher-student mimicry and in-context learning (Figures 4A, 4B, Appendix Figure 6) provides a principled explanation for the ubiquity of gating mechanisms in modern architectures. It is not just that gating "works well empirically" — it is that gating enables a specific class of computations (outer product accumulation and query) that underlies attention-like processing. This insight can guide future architecture design: when you want a network to learn associative memory and in-context learning, include multiplicative interactions; when you don't need these capabilities, simpler nonlinearities may suffice.

**It opens a new front in mechanistic interpretability for recurrent networks.** The reverse-engineering methodology developed in this paper — exact-zero pruning, neuron classification by decay factor, linear decoding of intermediate quantities, and polynomial coefficient comparison — provides a template for understanding what trained RNNs are actually computing. This is important because RNNs have historically been more opaque than Transformers (attention weights provide a natural interpretability hook that hidden state vectors do not). The paper shows that with the right theoretical framework (the constructive mapping to attention), it is possible to decode the function implemented by a trained RNN with high precision. This makes RNN interpretability research more attractive and suggests that future work on understanding trained RNNs should start by asking "what attention-equivalent function is this RNN implementing?" rather than trying to interpret individual neuron activations in isolation.

### Follow-Up Research This Work Enables

**Characterizing when real-world attention heads are compressible enough for practical RNN implementation.** The paper shows that gated RNNs can implement attention with far fewer neurons when the attention matrices are low-rank (Figure 3B) or symmetric (Section 3.2). But these experiments use artificially constructed low-rank matrices. A natural and high-impact follow-up would analyze the **effective rank and symmetry of attention heads in trained Transformer models** across a range of tasks and scales. For a trained language model (e.g., GPT-2, Pythia, or Llama), one could: (1) extract the attention head parameters, (2) compute the SVD of the value and key-query product matrices, (3) determine what fraction of singular values are needed to explain 95% or 99% of the variance, (4) compute the asymmetry of the effective key-value matrix, and (5) estimate the minimum neuron count an equivalent gated RNN would require. If typical attention heads are highly compressible (effective rank r << d, common in practice due to the bottleneck structure of multi-head attention), this would substantially narrow the gap between the paper's theoretical overhead and practical feasibility. Conversely, if attention heads are typically full-rank, this would confirm the negative result — exact RNN implementation is impractical — and motivate research on approximate rather than exact equivalence. A strong paper would analyze at least 3–5 model families at multiple scales and report rank distributions across heads and layers.

**Training an LSTM with attention-biased initialization to test whether the failure is optimization or architecture.** The paper's most intriguing negative result is that LSTMs fail to learn attention (Figure 4A) despite having a theoretical construction (Appendix B.3, Table 4). The construction requires large forget gate bias (`b_f → ∞` for `σ(b_f) ≈ 1`) and effectively linear input and candidate gates. A clean follow-up experiment: **(1)** initialize an LSTM with `b_f = 5` (so `σ(5) ≈ 0.993`, close to the required `f_t ≈ 1`), small `U_c` and `U_g` (scaled so that tanh and sigmoid operate in their approximately-linear regimes), and other weights set to match the theoretical construction as closely as possible; **(2)** train this initialized LSTM on the teacher-student task from Section 4 and measure whether it (a) maintains the attention-equivalent configuration, (b) drifts to a different but still low-loss configuration, or (c) drifts to a high-loss configuration; **(3)** compare to a standard-initialized LSTM as a baseline. If the initialized LSTM succeeds where the standard one fails, this demonstrates that the LSTM's theoretical capability is genuine but its inductive bias from standard initialization is essentially zero for attention — a finding that would shift architecture comparison methodology toward initialization-aware evaluation. If even the initialized LSTM fails, this would suggest additional barriers (perhaps the required linearization regime is unstable under gradient descent for reasons beyond initialization).

**Scaling the teacher-student experiment to larger d to identify where identification breaks down and why.** The paper's most detailed reverse-engineering is at `d=4` (Table 1, Figure 2). A natural stress test: **systematically scale d from 4 to 8 to 16 to 32** (or as far as computational constraints allow) and determine whether gradient descent continues to discover the construction. At each scale: (1) measure training loss to confirm identification succeeds or fails, (2) if it succeeds, verify using the paper's reverse-engineering pipeline (pruning, λ classification, Score KV / Score Q) that the discovered solution matches the construction, (3) if it fails, characterize the failure mode — does the network find a non-attention function that approximates the teacher? Does it fail to converge entirely? Does it partially converge (some attention-like structure but imperfect)? This experiment would produce a **scaling law for identifiability** — a curve showing how the probability or quality of identification degrades with d — and would identify the practical ceiling beyond which exact attention implementation is not learnable. A strong version would also measure the compute budget (training iterations × batch size) needed for identification at each scale to quantify how the optimization difficulty scales, not just the capacity threshold.

**Testing whether gated RNNs learn attention on language modeling data, not just synthetic teachers.** The paper establishes that gated RNNs discover attention when explicitly trained to mimic an attention teacher on Gaussian data (Section 4) and when trained on an in-context regression task where gradient descent is optimal (Section 5). A critical real-world test: **train a gated RNN (or an LRU+ variant) on a standard language modeling corpus** (e.g., WikiText-103, the Pile) and analyze whether the trained model's internal representations encode attention-like mechanisms. Concretely: (1) after training, extract the RNN's hidden state activations on held-out sequences; (2) for a set of probe positions, attempt to linearly decode the "attention pattern" that a Transformer would compute at that position — that is, can you predict which previous tokens the RNN is "attending to" from its hidden state? (3) Compare decodability for gated RNNs vs. standard LSTMs/GRUs — the paper predicts gated RNNs should show stronger attention-like structure. A null result (no decodable attention patterns in any architecture) would suggest that the attention equivalence is specific to the controlled synthetic settings and does not manifest in natural language processing. A positive result (decodable attention patterns in gated RNNs but not GRUs) would substantially strengthen the paper's practical relevance.

**Extending the constructive proof to approximate softmax attention and characterizing the approximation error.** The paper's entire equivalence analysis is restricted to linear self-attention. Standard Transformers use softmax attention, which is fundamentally nonlinear and non-additive (the normalization depends on all keys). A theoretical follow-up: **can a gated RNN with additional neurons approximate softmax attention to within bounded error?** The natural approach: (1) store not just the key-value outer products but also running statistics needed to approximate the partition function (e.g., exponential moving averages of key magnitudes, or kernelized approximations to the softmax); (2) prove a bound on the approximation error as a function of the number of additional neurons and sequence properties; (3) empirically test whether an RNN with these additional components, trained on a teacher-student task with a softmax attention teacher, can achieve low approximation error. This would bridge the gap between the paper's theoretical results (which cover only linear attention) and the practical reality that nearly all deployed attention models use softmax. Even a negative result — proving that softmax attention requires fundamentally different memory mechanisms that linear RNNs cannot efficiently approximate — would be valuable for clarifying the scope of the RNN-attention equivalence.

**Combining the RNN-attention equivalence with compute-optimal test-time scaling.** A synthesis of this paper's framework with the adaptive compute allocation approach studied in recent work on test-time compute scaling (e.g., the reference example's compute-optimal strategy) could be productive. The key question: **can a gated RNN dynamically adjust its effective attention implementation based on input difficulty?** For instance, an RNN could learn to vary its effective `λ` values (integrating more or less of the past) or selectively activate different subsets of its hidden neurons depending on whether the current input requires detailed attention-like processing or simple recurrent updating. The paper's finding that the construction compresses under low-rank conditions (Figure 3B) suggests that difficulty-dependent allocation is natural: hard inputs might require more of the key-value matrix to be represented, while easy inputs can be handled with a compressed representation. A follow-up could: (1) design an architecture where the gating mechanism includes input-dependent modulation of the recurrence strength (similar to the input-dependent `B(x)` in Mamba), (2) train it on tasks where some sequences require attention and others don't, and (3) analyze whether the network learns to allocate more "attention neurons" to harder inputs. This would combine the architectural insights of the present paper with the compute-optimal allocation framework to produce RNNs that are both attention-capable and resource-efficient.

### Practical Applications and Downstream Use Cases

**Inference-efficient deployment of attention-based models on memory-constrained devices.** The paper establishes that gated RNNs can implement linear self-attention, which means that for tasks where linear attention is sufficient, an RNN can serve as a drop-in replacement for an attention layer while providing constant rather than linear inference memory. A concrete deployment scenario: a smartphone keyboard language model that processes user text autoregressively. A Transformer-based model requires storing key-value caches that grow with the text length; on a device with limited RAM, this caps the usable context length. An equivalent gated RNN (or LRU+ architecture) with hidden dimension scaled according to the effective rank of the attention heads (per the paper's compression results) could process arbitrarily long text at fixed memory cost. The paper's finding that `d(d+1)/2 + d` neurons suffice for full-rank attention (Section 3.2) and fewer for low-rank (Figure 3B) provides a concrete sizing guideline: analyze the effective rank of the Transformer's attention heads on a representative task, then provision the RNN's hidden dimension accordingly. The tradeoff is the parameter overhead discussed in Section 6 — for modest input dimensions or compressible attention patterns, this is manageable; for large d, it becomes prohibitive.

**Guided architecture design for long-sequence processing.** The paper's identification of multiplicative gating and linear diagonal recurrence as the minimally sufficient components for attention-like computation provides an actionable design principle for practitioners developing models for long-sequence tasks (genomics, audio processing, time-series forecasting). The architecture comparison (Figure 4A) shows that adding input gating to the LRU (creating LRU+) dramatically improves its ability to learn attention. A practitioner starting from a standard LRU for a long-sequence task can apply this insight directly: **(1)** add an input GLU before the recurrent layer (exactly the LRU+ modification); **(2)** if the task requires explicitly querying stored associations, consider side gating (Appendix A.2) for its `O(d³)` rather than `O(d⁴)` parameter scaling; **(3)** use the paper's neuron count formula (`d(d+1)/2 + d` or the rank-based compression count) to estimate the minimum hidden dimension needed for the attention-like computation the task demands, rather than treating hidden dimension as a hyperparameter to be tuned blindly. The paper does not provide a trained LRU+ checkpoint for practitioners to download, but the architectural recipe is specific enough to implement directly.

**Improved initialization and training strategies for recurrent models on associative tasks.** The paper's analysis of why LSTMs fail to learn attention (Section 4.3, Appendix B.3) provides diagnostic criteria that practitioners can use when training recurrent models on tasks requiring associative memory. The LSTM construction requires `f_t ≈ 1` (large forget gate bias) and effectively linear input/output gates. A practitioner training an LSTM on a task suspected to require attention-like processing should: **(1)** initialize the forget gate bias to a large positive value (e.g., `b_f = 3`–`5`) rather than the standard zero, so the network starts in the high-memory regime; **(2)** monitor whether the learned `λ` values (or effective decay rates, in the case of LSTMs) converge to binary 0-or-1 configurations — if they spread across intermediate values, the network is not implementing the attention construction and may be using a suboptimal strategy; **(3)** if the task requires attention but the LSTM fails to converge to a low-loss solution, consider switching to an LRU+ or simplified gated RNN architecture with stronger inductive bias toward attention, as Figure 4A suggests these architectures discover attention solutions more reliably. The paper does not provide a systematic study of how initialization affects LSTM attention learning, so these recommendations are extrapolations from the theoretical analysis rather than experimentally validated guidelines — but they represent actionable hypotheses a practitioner could test on their specific task.

**Interpreting trained RNNs through the lens of their effective attention patterns.** The paper's reverse-engineering methodology (Section 4.1, Table 1, Figure 2) provides a template for practitioners who train RNNs and want to understand what their models learned. Specifically: **(1)** after training, prune neurons with zero input/output gating weights to identify the functionally relevant subset; **(2)** classify the remaining neurons by their effective integration timescale (for gated RNNs, the learned `λ` values; for LSTMs, the average forget gate activation); **(3)** attempt to linearly decode the "attention pattern" (which past inputs the network is weighting) from the hidden state at each timestep, using the fact that attention-equivalent RNNs should store key-value products linearly in their `λ≈1` neurons; **(4)** if the decoding is high-fidelity (high R² score as in Table 1's Score KV), the network is implementing linear attention and its internal representations can be interpreted as accumulated key-value matrices — providing a more interpretable window into the RNN's computation than raw hidden state vectors. This methodology requires the practitioner to have access to the internal activations and weights (not just model outputs) and to implement the linear decoding analysis, but it does not require training a separate probe model — just running linear regression on collected activations, which is computationally cheap.

### When to Prefer This Method

The paper does not propose a specific method to be preferred over named alternatives. It establishes an equivalence relationship between gated RNNs and linear self-attention, and characterizes the conditions under which this equivalence is learnable and compressible. The practical decision it informs is not "should I use method A or method B?" but rather **"when I observe a gated RNN performing well on a task, should I interpret its computation as attention-like, and when should I expect it to be able to learn attention-like computation in the first place?"** The conditions that emerge from the paper's analysis are:

- **Prefer interpreting a trained gated RNN as implementing attention when:** (1) the RNN architecture includes both input and output multiplicative gating (or side gating); (2) the task requires associative memory where pairwise input-output relationships must be stored and later queried (as in in-context learning); (3) post-training analysis reveals that functionally relevant neurons have binary decay factors (`λ=0` or `λ=1`) rather than a continuous distribution; (4) the effective number of neurons used matches the rank-based compression formula rather than being uniformly distributed across the hidden state.

- **Prefer gated linear RNNs over LSTMs/GRUs when the task benefits from attention-like processing and you want the architecture to reliably discover attention solutions through standard training.** The evidence in Figure 4A shows the simplified gated RNN and LRU+ discover attention, while LSTMs and GRUs do not under standard training. If your task is known to benefit from attention (e.g., in-context learning, associative recall, tasks with long-range dependencies where content-based retrieval is needed), the paper's results suggest gated linear RNNs have a stronger inductive bias toward useful solutions.

- **Do NOT attempt to literally replace a trained Transformer's attention layers with equivalent RNNs at scale.** The paper's parameter overhead (`O(d⁴)` or `O(d³)` vs. `O(d²)`) makes this impractical at realistic dimensions (`d=64` or `d=128` in typical Transformers) unless the attention heads are demonstrated to be highly compressible (low effective rank). The paper establishes in-principle equivalence, not a practical model compression technique.

- **Do NOT assume that softmax attention and linear attention are interchangeable.** All of the paper's theoretical and empirical results apply to linear self-attention only. If your application uses softmax attention (as nearly all deployed Transformers do), the paper's equivalence provides conceptual insight into what RNNs *might* be computing under the hood, but does not guarantee that an RNN can replicate softmax attention's behavior, especially for tasks where sharp token selection (a softmax strength) matters.
